# 配置边界

适用于定位既有安装、导入技能和配置原生扩展。

| 对象 | 处理 |
|---|---|
| 用户已有九问 | 保留安装、模型、权限和现有技能；先询查明确提供的命令/工作区，通过公开能力检查兼容性，缺能力明确未就绪 |
| 项目新建实例 | 独立环境、工作区和端口，可固定复现实验版本；不把实验安装流程当成普通用户接入要求 |
| SDK/适配包 | 安装在接入组件自己的环境，避免向九问环境追加或强制重装依赖 |
| 产品接入 Skill | 通过原生导入/选择入口使用；账号配置与密钥留本机受限文件，主SKILL.md只写通用操作 |

已核对的 workSwarm 0.2.5b1 应用扩展机制：ExtensionManager 扫描工作区 `application_plugins/`；每个应用使用独立子目录，入口为 `extension.py` 与 `extension.yaml`。这与网页“我的扩展”、技能库和模型工具列表不是同一概念。其他版本先核对自己的公开支持。

扩展只带必要源码及清单，尽量不声明向宿主环境安装依赖。私有设置放本扩展命名空间；同件复用，异内容/身份先核对，不能覆盖旧回执。文件准备、扩展加载、能力就绪与真实消息可见分别判断；需要重启时由用户使用原生入口，不顺手重启其已有进程。

已核对的原生网页导入路径是“技能→我的技能→创建→上传技能”，支持含SKILL.md的ZIP；导入后“去试试”将技能放入当前输入。上传控件隐藏时点击实际可见的上传区域并使用文件选择器；该版本覆盖导入会替换技能目录，运行配置应外置，更新前保留本机文件。验证完整资源是否保留，并检查skill_tool及实际流程页读取；不能假定首轮选中或读取后，每轮都会正确继续使用。

路径来自实际原生加载结果、明确配置或安装元数据；不假设当前仓库、个人目录和安装目录相邻。只检查本次需要的配置，不遍历其他凭据文件或输出密钥。
