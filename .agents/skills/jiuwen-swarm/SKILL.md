# 九问 Swarm 开发与接入

先读当前项目约定，确定本次操作的是用户已有九问，还是项目新建的独立实验实例。复用既有安装；接入通过原生配置和公开接口完成，不为适配修改源码、覆盖安装或改全局指令。

| 当前任务 | 按需阅读 |
|---|---|
| 安装定位、原生技能或扩展配置 | [配置边界](references/configuration.md) |
| Process 调用、会话、用户确认或网页消息 | [接口与会话](references/interfaces.md) |
| 能力缺失、运行异常或交付核验 | [排错与证据](references/verification.md) |

先用当前项目的已安装版本及公开能力判断兼容性；参考页记的是核实过的机制，不能据此要求所有用户换到同一版本。

基础定位可运行 `python scripts/inspect_workspace.py --workspace <用户明确指定的九问数据目录> [--python <既有九问Python>]`。只检查目录与发行版本，不创建工作区、不读取凭据、不证明业务就绪。

开发时将用户配置不足、宿主能力缺失和项目代码缺陷分开处理。完成后报告真实证明范围；用户反馈或实际故障形成可复用经验时，修正所属参考页，不堆积逐次日志。产品行为仍归当前项目设计。
