# 文档编辑

修改文档结构、术语或表达时阅读。版本与变更登记规则只在[交付](../../develop/references/delivery.md#提交标题与版本)；改动类型判据只在 [design](../SKILL.md#先判断改动类型)；模块文件夹的文件、模板与阅读预算只在[模块文件夹格式](module-format.md)，本页不复述。

## 分层

| 层 | 位置 | 只写 |
|---|---|---|
| 整体 | `设计/核心理念.md`、`术语.md`、`架构.md` | 目标与原则；跨模块共享术语与归属表；模块表、依赖图、跨模块不变量、交付与数据归属 |
| 模块 | `设计/组件/<模块>/` | 接口、依赖、实现、术语、决策、进展六件 |
| 流程 | `设计/流程/<流程>.md` | 参与方与前置、时序、步骤表（调用方、被调模块接口锚点、持久结果、推进条件）、异常分支、端到端验收；不写模块内部 |
| 场景 | `设计/流程/场景/<场景>.md` | 业务场景的配置值与约束；通用模块不反向依赖场景 |
| 工程 | `设计/工程/` | 部署.md 人类教程；测试.md 检查层级与验收条件位置；进展.md 索引；专题/ 跨模块工作的方案与票据顺序；实施资料/ 验证摘要与手册 |
| 决策 | `设计/决策/`、`<模块>/决策/` | ADR |
| 变更 | `设计/变更/README.md` | 一版一行；取舍链向 ADR，不再写详情文件 |

## 编写

- 一条规则只在一处写全，其他位置链接；页面移动同步当前引用，根索引只列父页与模块表。
- 每篇先写目的与范围，主体用表格一行一条，段落不超过三句；术语说明用途与边界并映射代码标识；具体产品用具体名称，区分接入技能、业务技能、开发技能。
- 单页超过约 1.5 万字按子主题拆 `<页名>/<子页>.md`：父页留目的、子页表和相关文档，子页首行链回父页；拆页只搬运原文与重算链接，不顺带改规则。
- “必须/不得”表示不变量，“默认”表示可配置初值；规划中的能力写进票据，不写成已实现。
- 实施事实归工程：部署操作只在部署.md；实测记录归 `.agents/data/`，公开结论只在实施资料摘要维护；差距只在票据与进展索引，不把计划或旧验收结果升级为规则。
- 迁移或合并资料时保留代码依据与未验证范围，删除第二份维护入口；历史保留当年路径与事实，通过现行路径映射定位，不伪改旧结论。
- 设计 VERSION 是三段当前规范入口；README、docstring 与正文不散写平台版本号；A2C 依据只在设计入口标记并匹配 `vendor/wheels/SOURCE.json`；产物 VERSION 归属从架构交付表读取。场景专属值进场景页，付款与授权边界从术语、支付中心及界面页读取。
