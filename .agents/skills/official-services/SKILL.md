# 官方预置服务方

用于新增服务类别或扩展现有候选。先读根 AGENTS.md、[设计索引](../../../设计/README.md)、[官方服务 · 预置服务与启动器](../../../设计/组件/官方服务/接口/预置服务与启动器.md)和本次业务职责页；本技能保存创建方法，不另定义产品规则。

1. 区分账号、服务身份与候选。按现有目录先判是否复用领域账号；同类候选复用同一提供者账号，各自保留身份、模板与履约状态。创建前填写下方参考中的决策表。
2. 按[资产与归属](references/assets-and-ownership.md)确认唯一规则/数据/状态 owner，列出精确文件和依赖。规则变化交 design 先修职责页；纯资产扩展依现行设计实施，不为新显示名增加协议或核心分支。
3. 同步能力声明、规格、材料、价格、生产说明、工具与宿主、交付文件和验收依据。专业能力归官方资产/工具/业务 Skill，通用 SDK 负责协议及运行时；样件不能成为实际生产输出。
4. 按[验证与发布](references/validation-and-publication.md)选择有意义的成功、拒绝、恢复、归属及安装检查。核对助手先筛合格再比较；无足够候选时说明缺口，不凑比价或固化推荐。
5. 生成同源初始化清单，按实际影响更新打包与产物依据，交接候选 diff、摘要、真实检查结果和未验证范围。公开发布、模型或真实业务仅在本次任务授权范围内执行；仅写资产不代表已上线。

具体部署交 [deployment](../deployment/SKILL.md)，模型开发工具交 [llm](../llm/SKILL.md)，检查统一交 [testing](../testing/SKILL.md)。不另建运行器、发布脚本或配置权威。
