# Demo 视频制作

先读根 [AGENTS.md](../../../AGENTS.md)、[制作入口](../../../demo/README.md)和[当前验证记录](../../../demo/verification/README.md)，再按本片涉及的流程读取[设计职责页](../../../设计/README.md)。旧影片、后台实验、当前待录稿分别核对。

## 工作顺序

1. 明确观众、产品形态、录制范围与现有素材；完整中文台词、旁白和镜头先交用户确认，以内容摘要绑定批准版本。
2. 按镜头列出所需画面与业务证据，复用已经成立的原交易、会话和授权。先准备配音、布局与录制工具，再触发获准的真实业务。
3. 原生操作和后台独立核验分别留证；实际结果未知时先核原记录，保持原操作可恢复。遇到产品缺陷交由 develop 处理，规则问题交由 design 处理。
4. 按实测音长剪辑，标记等待压缩及讲解叠层。逐镜头检查最终 MP4，将画面、音轨和公开摘要绑定同一成片哈希，再发布。

用户已明确授权的隔离仿真，可由 Codex 操作真实确认入口；记录自动化确认身份及获准对象、动作和额度，不冒称真人，不扩大已有授权范围。
