# 剧本与证据

写新稿、修改旁白或恢复旧录制前阅读。

## 先批准内容，再制作

确认本片面向谁、展示什么产品形态、哪些是机制示意、哪些要实际录到。完整稿应同时包含台词、旁白、镜头操作、所需证据和未录条件；尚无事实的镜头保留待录，不预填成功结果。用户指定的产品形态、合同方式与结尾在各处保持一致，场景值归设计示例及场景源。

当前新稿源为 [review_story.py](../../../../demo/review_story.py)，[script_documents.py](../../../../demo/script_documents.py) 的 `--drafts` 生成三稿；其批准状态绑定规范化内容的 SHA-256。修改旁白、产品形态或关键展示范围时，取得对改动的确认并更新绑定，不把状态文字沿用为新稿批准；真实操作中的自然措辞、按需追问及不改变主要流程的顺序变化，不要求逐句复演或重新批准。旧影片的 `case_story.py`、`global_story.py` 及发布记录仍是各自版本的来源，不能因新稿获准就改写旧片。

生成物不手改。先用当前入口的只读检查核对：

```powershell
.venv/Scripts/python.exe -X utf8 demo/script_documents.py --drafts --check
.venv/Scripts/python.exe -X utf8 demo/approved_voice.py --check
```

批准稿、配音计划就绪只证明内容准备，不能写成已录制、已履约或已发布。准备配音时使用 [approved_voice.py](../../../../demo/approved_voice.py) 保留批准内容摘要、音频摘要和 `recorded: false`；真实镜头完成后另核录制证据。

## 自然输入与实际流程

用户首句使用简短自然的业务需求，只保留必要目标和约束，不预先塞入冗长的场景说明、SDK命令、技术路径或指定服务选择。让助手自行识别流程、发现服务并按需追问；等实际问题出现后再自然回答，不预排整串补充条件或以救援提示强推结果。

剧本用于确保接入、发现与比选、真实授权、合同、交付、验收付款等本片主要流程清楚可见，不是逐句用户输入或固定提问次数的执行程序。助手的澄清、合理默认值和步骤顺序可随本轮实际情况变化；保留真实追问与答复，按取得的事实组织镜头，不为贴合原稿隐藏分支或编造结果。流程变化不代替独立授权，也不放宽下述证据边界。

## 画面事实与后台事实

| 证据 | 能说明什么 |
|---|---|
| 原生页面、真实提交和对应回执 | 用户实际可见、可操作的本轮流程 |
| 公开 SDK 的独立只读核验 | 实际身份、运行状态、签名、交付、付款等业务事实 |
| 模型回复、后台 completed、单元测试 | 相关执行或实现信息；单独不足以证明原生成功 |
| 概念动画、讲解图和模拟界面 | 明确标注的机制说明；不作为真实操作回执 |

每个关键镜头关联原会话/交互标识、操作引用、合同摘要或消息 UUID，以及当次实际结果。比选后在工作台选中本单，逐镜头核合同、金额、交付期和回执；同名服务或相近时间不等于同一单。消息的提交、送达、处理、接受和入历分别取证，所用工具是本地模拟还是外部系统也分别标明。

原生技能的文件导入、宿主索引、菜单选择、模型实际读取正文与业务执行是不同事实；核实际调用及生效摘要。首次接入教程还须覆盖平台注册，以及将平台地址、账号和密码私下保存到本机外置配置的实际步骤；预填文件只证明环境准备，不能据后续“已接入”回复补算这段用户操作。凭据用正常产品入口的掩码字段处理；沿用配置文件方式时说明真实填写方法及保密省略范围，不用占位示例冒称已保存，不向模型或录屏展开配置正文。直接读改账号文件的技术救援不能包装成正常教程通过。

只公开脱敏摘要与必要标识、哈希。原始私人消息、账户配置、密钥、浏览器状态和运行数据库按根约定留在本机，不复制进脚本或技能。

## 保持原单与授权边界

用户对委托、具体合同、独立业务环节和验收/付款的授权按当前设计分别核对；前一步同意不自动覆盖后一步。自动化确认须绑定真实页面对象及本轮明确授权，记录实际答复与回执；空答、取消、跳过或只出现“准备确认”的分析文字均不足以继续。

超时、任务未完成、付款结果未知或页面与后台不一致时，保存原操作及证据，按公开查询与恢复入口核对。不得为拍齐镜头重新签约、重复拟卡/付款、发送邀请或清空任务；技术提示、人工给出的摘要、重试及修复如实记录，不能据此称自主整单通过。

新一轮隔离演示与原单接续先作选择：确需新业务时明确获准范围并使用独立场景数据；原单补录则保留原身份、合同、消息与有效授权，核实际期限及既成效果。不能仅换录像目录就宣称业务隔离，也不为重拍删除原数据。
