# 声画与交付

制作旁白、字幕、编码或发布前阅读。

## 复用官方 TTS 链路

现有 [build_voice.py](../../../../demo/build_voice.py) 通过操作者提供的 Aliyun helper 调用官方 `QwenTtsRealtime` 链路；新批准稿由 [approved_voice.py](../../../../demo/approved_voice.py)复用它。使用当前支持的 `qwen3-tts-flash-realtime`、音色与语气配置，先核 helper 当前实现，不另手写 WebSocket 客户端。凭据只由获准 helper 在本地加载，不为配音读取或回显账号文件。

合成前检查批准内容摘要；以台词、音色、风格、语速、后处理配置决定缓存是否可复用，并保留实际音频摘要。缓存来源或配置不一致时先核对，不将文件名相同当成音频相同。复用当前会话已明确的供应商与内容授权，不对同范围调用反复请示；不把某位用户的宽授权变成所有任务的许可。超时保留失败元数据，有限重试完整句子，不无限重试或打印提供方可能含秘密的错误正文。

用户已允许主要流程不变的顺序调整时，保留原批准源与摘要，明确记录该场景的调整依据和差异，不改全局摘要使其他影片失效。旁白文字、镜头集合与单镜时长未变，在已有Demo媒体环境用`python demo/approved_voice.py --scene <场景> --reindex-cached`按稳定ID重排五类索引并重算计划at；工具按文件摘要及有界媒体头探测核时长、合计，缺件、文本、设置、摘要或时长不匹配即在写入前停止，不补调TTS。索引输出固定UTF-8/LF，公开摘要另核实际入库字节。逐句音频与旧预览保留，新顺序试听另建文件，成片仍按实测音长排期。

语速以清晰自然为先，服务端 speech rate 与后处理 tempo 分开记录；不要复制某一旧片的固定倍率作为所有新片标准。每句实测音长并试听专名、数字、尾音和停顿。音长超过镜头时调整画面或剪辑；后处理只在现有脚本允许范围内适度使用，不能截句硬塞。

字幕短于旁白，跟随镜头重点，不重复堆满同一事实；在最终分辨率核字号、换行、底色与安全边距。完整旁白和字幕各有唯一源，生成物与源不一致先重建，不在最终视频中临时改口。

## 验收最终 MP4

复用现有检查：`demo/check_recording.py`核尺寸、音轨、实测旁白与总时长；`demo/review_cases.py`依据编辑决策表逐镜头抽帧并按旁白窗口检测音量。新版剪辑按 `voice-paced.json` 的实测音长重算时间轴，不沿用计划起点；入口和素材映射见[录制与剪辑](native-recording.md)。全景对应使用其已有检查入口，其他稿先确认契约适配，不能只换文件名就沿用旧片通过摘要。

对最终编码逐镜头核查：

- 字幕、原生界面、选中合同/消息与旁白结论一致；讲解叠层清楚标记，不伪装成网页按钮、报告或回执。
- 各句旁白完整，无意外静音、重叠、截尾；抽帧与音量窗口都来自最终 MP4，必要处实际试听。
- 拟卡费、合同款和实际已付分别核；未付、拒绝、未知或未闭单不写成完成。外部邀请、本人接受、日历可见等结论各需对应实录。
- 封面、过渡、缩放、滚动和四宫格在最终尺寸可读，无凭据、私人消息或无关账户资料泄露。

[artifacts.py](../../../../demo/artifacts.py) 与 [publish_cases.py](../../../../demo/publish_cases.py)要求 `qa.json`、`shot-review.json`和成片摘要一致。每次重编码后重新检查最终字节，不能复用旧 MP4 的截图或通过记录。现有审阅拼图没有独立哈希绑定，新版发布不复制该本机图片；公开镜头摘要只投影已知字段，不复制私人审计文件。公开证据说明实录范围、讲解范围、原生与后台验证、自动化确认及未完成项；避免把技术指导后的通过写成自主使用成功。

新版发布使用 `publish_cases.py --native <目录> --scene <场景> --date <日期>`；完成试听和逐镜 QA 后，由当前获准操作者通过 `--approve-video-sha256` 绑定实际审阅的最终 MP4 字节。Codex 可在已有制作授权内完成此技术绑定，不另起用户批准流程，也不替代剧本批准或业务授权；候选片不能经此参数变为可发布成片。

## 交付与维护

发布时核正式链接、视频 SHA-256、时长、画面/声轨验收摘要和对应稿源。保留旧影片与历史摘要；新批准稿、预览、失败 take、已发布片分别标识。媒体先在同目录完成临时文件并核摘要后再替换，避免播放器占用时截断原片；相同摘要不重复覆盖，占用只作有限重试。当前事实写入既有验证记录，制作方法合并到本技能；不把逐轮事故、账号或临时输出目录累积成通用规则。

本技能维护按根 AGENTS 的 A 层及 skill-creator 结构检查；改动现有媒体脚本再按行为补定向测试。脚本检查通过、配音完成、后台业务通过和视频完成分别报告，不自动触发真实业务、模型、TTS或全量测试。
