# 异常与专项

仅在常规教程无法继续、旧配置迁移或显式专项验收时阅读。先保存实际阶段、来源提交、脱敏回执和原数据状态，再依安装与升级规则处理；不要把源码修复当实机已验。

- 未知Windows Job、孤儿或停止失败：核原安装身份、PID/创建时间/可执行文件及真实Job；正常停止未完成不删除控制记录或数据，不按通用进程名强杀。所有者无法确认即保留现场并报告公开恢复入口缺口。
- Linux停止、初装恢复、连接、TLS或输出格式问题：读[Linux部署诊断](linux.md)，核原单位、invocation、控制组和实际SDK/OS锁；超时、父任务退出或IPC消失不等于空。只用选定发布实际支持的公开入口，不手改父任务绑定。
- 模型组件专项：按[LLM参考](../../llm/references/instance-configuration.md)逐类验证平台、官方和个人助手的实际通路。配置、裸API和hostAvailable不替代组件证明；UI、可信确认、业务及资源隔离分别验收，不为探针发送邮件、签约或付款。
- 构建/环境专项：按[工具索引](../../../../tools/README.md)选择既有探针，按[testing](../../testing/SKILL.md)协调检查窗口，保留真实退出码。历史通过只复用于未变输入。

原始日志及操作证据只存本机忽略数据目录；公开必要结论归[部署发行](../../../../设计/工程/实施资料/部署发行.md)，未完成实现差距只归[开发计划](../../../../设计/工程/实施资料/开发计划.md)。不在技能追加逐轮复盘。
