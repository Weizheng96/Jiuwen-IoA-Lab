# 部署入口

先读 [部署规范](../../../设计/工程/部署.md)、[安装与升级](../../../设计/工程/安装与升级.md)和[当前发行说明](../../../设计/工程/实施资料/部署发行.md)。复用 `python -m deploy --help` 与现有发行工具；参数以当前公开帮助为准，不照抄旧会话命令。

Windows 本机由 `deploy/windows_local.py` 持有生命周期，Linux 由 `deploy/linux.py` 与生成的单位持有；专项探针见[工具索引](../../../tools/README.md)。脚本存在或安装准备完成不证明整体验收；分别报告当前平台、真实模型、原生九问和业务的实测范围。

服务器连接直连，SSH 不使用 ProxyCommand/ProxyJump，HTTP 显式绕过代理；路由/TUN 改变后重核实际路径，NO_PROXY 本身不是直连证据。不改系统全局代理。私有连接配置由操作者提供，不固化口令或会话取凭据逻辑。

升级、排空、备份和恢复使用原部署身份与任务；未知结果先核实际 OS 句柄、锁、控制组及原操作回执，不因超时、IPC消失或PID文件就重启。Windows Job 及完整进程身份不能由通用进程名替代；只控制本任务进程，不删除原运行数据。安装固定来源、许可和摘要的随仓 Git 依赖，不现场 VCS 安装；普通包可选国内镜像。

检查依 [testing](../testing/SKILL.md) 串行执行。具体服务器成功操作经验由完成实测后的服务器技能维护，本技能不宣称尚未完成的上线结果。
