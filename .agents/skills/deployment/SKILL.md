# 部署

常规部署只按[部署教程](../../../设计/工程/部署.md)选择对应平台部分，模型配置也在同一教程完成。教程缺少实际公开入口时先核当前CLI并报告缺口，不编造参数、另建安装链或让普通读者串读多篇。

异常、旧实例恢复、所属进程未知或专项验收时，再按[异常与专项](references/operations.md)选入口。真实规则由[安装与升级](../../../设计/工程/安装与升级.md)和[平台配置](../../../设计/工程/平台配置.md)持有，技能不重复定义。

服务器连接统一读取本机Git忽略的`.agents/server-connection.json`，字段由现有连接工具校验；不从聊天历史提取密码，不输出秘密。Linux公开访问使用该文件指定的公网IP，HTTPS证书须覆盖实际IP；三席原生与可信确认按在线试用规则使用独立HTTPS端口并核Cookie隔离。
