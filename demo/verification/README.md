## 接入与证据边界

- 同一IoA个人助手skill按需读取委托交易/私人交互流程。原生菜单只传名称提示，模型还须实际加载主文件和流程页；两种路由已通过。未预选自动发现仍不稳定。
- 美甲名称、规格和演示答复只在外部场景/录制脚本；SDK核心不包含行业或指定推荐偏好。默认最低询价1，本轮未配置最低三份。
- 真实WASM回归中，同一全局容量故障通过基础五项检查、被扩展检查拒绝。竞争和重试为源码顺序模拟，不代表真实多线程压力或网络故障注入。
- --confirmed是调用方对用户同意的声明，不能单凭它证明用户确实作答。合同、实际环节、每期验收分别确认；实名仅演示授权，不提交真实身份资料，不宣称完成微信注册或上线。
- 内部模板发布起30天、剩余不足7天续期；不延长既有合同、用户授权或单份提案的响应期限。

失败拍摄和原始数据保留于本机忽略目录：包括原生空答、拟卡短超时、未独立询问环节、暂停后提案过期及模型自行重建授权等轮次，均未发布为成功片。正常业务澄清按实际原生记录、剧本和原片时点核对；技术救援提示不得用于正式片。
