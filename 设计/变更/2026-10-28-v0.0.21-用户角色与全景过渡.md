# 用户角色与全景过渡

| 项 | 决策 |
|---|---|
| 角色 | 讲解图独立显示用户与个人助手并逐一对应；真实监控不添加用户节点 |
| 过渡 | 用户先虚化淡出，助手平滑移动到真实网格位置，真实监控渐显；不并排两幅拓扑 |
| 流量 | 降低P2P频率、增加完整委托，以可见传输活动接近为目标；订单数与消息数单独记录 |
| 新组件 | 灰色意图中心，副标题“用户权限白名单管理”；仅UI占位，不涉及旁白和交互 |
| 命名 | 账号与公钥登记改称身份中心；交易中心改称委托中心；标识符和协议边界不变 |
| 核验 | 配对关系、用户淡出、助手位置插值、单画面渐变、真实活动比例及既有无残影检查 |
| 延续 | A2C依赖不变；悬赏与意图均未实现业务API；不伪造授权、心跳或履约证据 |
