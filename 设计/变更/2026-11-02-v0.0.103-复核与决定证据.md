# 复核与决定证据

## 原因与选择

| 审查问题 | 统一处理 |
|---|---|
| 原理由不再成立时不能查看最新真实合同 | 分离只读原事实收集与理由判断；复核使用完整当前原事实，申请仍按原条件受理 |
| 只绑定申请摘要无法防止旧页面覆盖后续签7、付款或解除 | 保留冻结申请；复核确认绑定当前事实、程序结果、材料、模型映射及状态，事务内重新核对 |
| 内部依据含原传输封套，客户端不能重算且不能全部公开 | 决定另存公开证据视图，签名绑定decisionEvidenceDigest；SDK重算并核原卡，原AP2凭据不公开 |
| 人工操作与模型重试可能混淆 | 独立网页账号、无本案活动writer、原幂等操作与明确理由；不重算或改写已知程序结果，限定原补偿金额与币种 |
| 假设无卡请求需要变为合同案件 | 已核现行响应期限与正式offer受理检查排除这一分支；保持原subject，不增加迁移引擎 |

## 范围

更新委托中心、平台接口、管理员界面、A2C适配、术语和验收；不修改A2C合同字段，不增加材料追加/重开或独立裁定执行器。人工复核、双端SDK和界面须继续按规范实现及公开验证，设计发布不表示产物完成。原发布限制仍在，不表示已经提交、打标签或推送。
