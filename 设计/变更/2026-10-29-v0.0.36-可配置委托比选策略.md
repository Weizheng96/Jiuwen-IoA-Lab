# 可配置委托比选策略

| 项 | 说明 |
|---|---|
| 原要求 | 原美甲剧本三份正式提案比选；主skill与SDK核心保持通用，不包含服务名称、固定三家或美甲参数 |
| 实测 | 通用技能能读取真实模板并取得码上飞299提案，但模型提前请求用户确认，没有继续征集其余候选；该take不能发布为原三家比选影片 |
| 决策依据 | 按既有原剧本要求，将最低三份作为演示账号可配置偏好；不是推断用户同意新的收费或外部操作，用户可调整该演示偏好 |
| 策略 | 默认1、范围1—8；scope固化下限，request/draft附进度，sign/adopt检查数量及费用结果；SDK只校验，不代替模型理解业务或推荐 |
| 边界 | 不改A2C对象/算价/签名规则，不改九问源码或全局配置；私人交互独立；旧scope按原语义恢复 |
| 场景隔离 | 三份偏好置于examples/nail-booking并显式写入演示配置；通用安装包不包含该场景策略 |
| 验证 | 唯一服务端点计数、预算/费用约束、未达下限拒签、缓存进度更新、旧scope及三种成约方式；随后完整原生重录 |
