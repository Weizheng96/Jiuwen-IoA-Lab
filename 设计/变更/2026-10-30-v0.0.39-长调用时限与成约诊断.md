# 长调用时限与成约诊断

| 项 | 说明 |
|---|---|
| 模型配置 | 使用九问原生models.upsert新增非默认qwen3.5-plus，保持原模型、源码及全局指令；录像保存实际模型标识 |
| 实测 | 无固定数量偏好，正常创建scope、读信誉/模板、实际请求三家提案；取得两份，第三次shell工具60秒超时，scope保留pending，SDK阻止重付 |
| 调用约定 | 同账号逐条命令；request工具等待覆盖模板拟卡窗口，watch工具超时大于本地等待。timeout是九问工具参数，不是SDK业务参数 |
| 诊断 | draft遇proposal、request遇其他类型直接给出正确接口提示；不改A2C验证/算价/签名 |
| 结果未知 | 保留失败参与方与原始回执，不清pending、不伪造第三份报价，不把两份称为三家比选完成；新录制用独立参与方 |
| 剧本选择 | 助手按价格偏好推荐灵犀，原剧本选码上飞；已询问用户是否由店主在合同确认时选择，以保持通用skill无指定服务偏好 |
