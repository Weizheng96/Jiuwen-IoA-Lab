# 提案到期与容量释放

| 项 | 内容 |
|---|---|
| 原因 | 真实原生询价产生未采纳的正式提案，既有维护只释放 held，committed 可能永久占用接单名额，阻塞后续 Demo。提前准备的合同选择也须在提交时重新核期限，避免过期释放后跨窗口选择 |
| 归属 | 委托中心核原承诺、合同和协议记录，支付中心核具体选择的提交期限；消息中心用已有维护事务统一释放、关闭和可靠通知，不新建服务、协议字段或后台执行器 |
| 范围 | 本轮只自动收敛可证明完整响应与开工窗口均已结束且未选中的正式提案；待批准、已成约、未知或缺证据保留原恢复路径，不清库、不提高容量、不撤销已付拟卡费 |
| 验证 | 覆盖窗口边界、选择竞争、原请求终局/未知、合同与开工证据、原子回滚和重复维护；实际通过情况另记开发计划与运行证据 |
| 规范 | [委托中心](../组件/委托中心.md)、[支付中心](../组件/支付中心.md)、[验收](../工程/验收.md) |
