# Outlook通知邮箱授权

| 项 | 决策 |
|---|---|
| 起因 | 用户选择专用公开通知地址jiuwenioa@outlook.com，并要求继续真实Outlook验收；是否注册成功以用户登录结果为准 |
| 发现 | 现有SMTP客户端只支持密码登录，Outlook.com官方要求OAuth2；本地SMTP捕获成功不能代表真实Outlook可用 |
| 发信 | 保留标准iCalendar邀请及SMTP传输；Microsoft端点使用SMTP.Send委托授权与XOAUTH2，不引入Graph发信或日历写权限 |
| 身份 | 发信邮箱与被预约邮箱分别登录，令牌不同文件；SMTP令牌不请求Graph日历权限，日历令牌不请求发信权限 |
| 安装 | 一个支持个人账号的公共客户端应用即可，启用公共客户端流程；需要具备应用注册权限的Entra目录，不代建付费订阅 |
| 验收 | 登录后先检查日历与SMTP认证，再通过消息中心发一封真实邀请，人工接受后核对Outlook日历；缺授权保持未验收 |
| 不变 | 邮件受理不代表送达或接受；UID固定，发送结果不明不自动重发；平台核心不持有邮箱凭据 |

参考：[Outlook.com设置](https://support.microsoft.com/en-us/outlook/pop-imap-and-smtp-settings-for-outlook-com)、[SMTP OAuth](https://learn.microsoft.com/en-us/exchange/client-developer/legacy-protocols/how-to-authenticate-an-imap-pop-smtp-application-by-using-oauth)、[应用注册](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app)。
