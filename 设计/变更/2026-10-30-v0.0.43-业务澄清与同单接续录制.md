# 业务澄清与同单接续录制

| 项 | 说明 |
|---|---|
| 真实分支 | 三家提案已取齐；云构需要架构图，助手询问是否补充。店主本轮不提供，继续比较现有提案；这是业务输入，不提供SDK命令、技能路径或指定推荐的技术补救 |
| 剧本 | 先加材料澄清镜头和旁白，再继续实际会话；核心需求首句不变，委托/合同/环节/验收仍分别确认 |
| 接续边界 | 仅支持已记录注册、配置、技能选择及三份未签约提案的同一会话；合同摘要、账号、技能摘要和原片一致。原片和接续片独立时间原点，保留原因及摘要；不重放授权、付费或注册 |
| 不变 | 通用skill与SDK、A2C协议、九问源码和全局配置不变；不增加场景假设，不改写旧合同或失败结果 |
| 准入 | 额外业务答复只能出现在实际材料问题后；不得添加技术救援提示。签约/环节/验收仍核对真实用户答复和签名时序 |
