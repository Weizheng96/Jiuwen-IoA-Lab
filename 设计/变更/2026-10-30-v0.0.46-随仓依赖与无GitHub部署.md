# 随仓依赖与无GitHub部署

| 项 | 说明 |
|---|---|
| 用户约束 | 服务器不能直接连接GitHub，后续同步本仓到GitCode部署；依赖内容随仓并标明来源 |
| 原问题 | A2X是Git子模块，安装/升级递归拉取；九问安装器现场clone，锁文件含远程VCS依赖，服务器还需构建网页 |
| 处理 | A2X普通源码快照；A2C、Process SDK、九问及Git源码依赖保存固定来源/许可证/摘要，随仓源码归档与本地安装包；九问网页预构建 |
| 部署 | 安装无clone、submodule或Git形式pip依赖；升级使用本仓配置的origin或同步目录。PyPI普通包使用可达镜像，全离线准备另依系统架构确定 |
| 边界 | 不改九问源码和全局指令；只配置新部署的自动更新策略，保留用户已有配置。可选在线市场和基准数据不当作平台必需依赖 |
| 验证 | 摘要/许可/锁文件、安装入口和不含Git元数据的部署副本、九问静态网页及完整回归；Linux实机另验 |
