# Windows单席试用兼容

Windows本机通过WSL2与Docker Linux容器部署，采用单席保守容量；Linux服务器继续三席。同一协调器复用原生命周期，不建设第二条业务链，也不将单席当作降低凭据、可信确认和整轮重置要求的理由。

现行规则集中在[在线试用](../工程/在线试用.md)，架构仅引用容量职责。profile及容量进入控制库绑定；环境不匹配或旧控制库缺少绑定时在创建资源和开放网关前拒绝，保留原记录，不静默缩容。Windows提供调用指定WSL解释器的薄启动入口。资源实验与界面按实际容量呈现，原生网页、挂载归属与权限仍须目标环境实证。

本次仅发布规范，不代表Windows安装、Docker Desktop、原版九问或业务验收已通过，不递增产物VERSION。
