# 确定性委托阶段入口

| 项 | 说明 |
|---|---|
| 实测问题 | 原生九问会把技能条目当工具，或读完模板后以参考价请求选择，未真正征集提案；失败实录保留、不发布 |
| 改进 | 宿主原生按需技能发现；本地SDK通过begin/advance/poll/status编排既有Client，每个阶段返回明确gate及真实证据 |
| 不变 | 用户一句业务需求、四处确认；平台核心不运行助手，模型不代用户签字，协议仍复用A2C wheel |
| 扩展 | 新场景提供声明式plan和服务定义；不能注入执行代码、金额算法或绕过确认 |
| 验证 | SDK完整回归、真实HTTP阶段推进、九问自然请求实录、每个用户确认前的可见询问与实际状态 |
