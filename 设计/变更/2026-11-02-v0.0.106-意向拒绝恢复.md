# 意向拒绝恢复

| 项 | 内容 |
|---|---|
| 原因 | 原生会话使用已退出公示的模板，平台明确拒绝并保存到SDK，本地报价调度却显示unknown |
| 规则 | 保存的明确拒绝与平台无原受理记录共同证明未受理；用同一收敛函数结束原作业，不重建请求 |
| 边界 | 原操作HTTP/WS查询统一将保留期后的回执返回history_gap，不伪装从未受理；单纯404或本地异常不构成拒绝证明；原操作已受理、查询失败或明确未知均保持unknown；不推定付款、签约或生产已失败 |
| 规范 | [A2C适配](../接入/A2C适配.md)；实际验证和原生进度另记验证记录 |
