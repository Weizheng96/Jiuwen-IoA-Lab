# 业务工具输出契约

| 项 | 内容 |
|---|---|
| 原因 | 真实自然语言规则配置虽完成预览与批准，因工具只有输入格式，模型仍自造booked状态，将邀请提交误写为预约完成 |
| 归属 | SDK共用机制完整定义可选工具输出契约与执行边界；个人助手SDK和技能规定起草/预览使用；会议值仅归场景及官方工具 |
| 规则 | 已声明输出格式在目录、预览和模型上下文公开并参与策略摘要；结果执行后校验，不合约保留原回执与未知效果，不自动重跑；未声明工具不强制改写 |
| 取舍 | 不建立第二个模型或通用自然语言语义证明器，不把会议枚举写入SDK，也不放宽真实业务断言来容纳虚构状态 |
| 验证 | 结构失败、副作用后格式错误、冻结策略变更及恢复去重分别检查；自然语言配置到冲突后自主改约另行真实验收 |
