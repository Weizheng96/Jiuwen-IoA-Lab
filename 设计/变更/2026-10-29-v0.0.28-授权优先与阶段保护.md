# 授权优先与阶段保护

| 项 | 决定 |
|---|---|
| 顺序 | 用户一句需求 → 发起委托授权 → A2X发现与渐进筛选 → 三家真实提案与推荐 → 合同确认 → 实名环节授权 → 本地验收 → 验收确认与付款 |
| 授权前 | 仅依据plan提出拟卡费上限，不能宣称已经筛选出服务；授权后从真实模板核对费用，超限重新询问 |
| 实录发现 | 模型会误抄CLI动词、把taskId与卡摘要混用、或在失败后回退到原语；重复取件可能重复追加签6 |
| 保护 | 有效action路由到delegate；受管理合同限制原语绕行；重复begin恢复同一活跃任务，status可列任务；取件重试使用验签清单对应缓存 |
| 验证 | 阶段确认与实际状态分开检查、原语拒绝、取件重试签名数量、断联服务排除及真实九问完整复录；失败录像不发布 |
