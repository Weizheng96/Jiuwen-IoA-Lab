# 账号与独立角色接入

## 问题与决定

原注册、登录与赠币分开提交；角色 SDK 又各自登录，丢响应或重新创建服务账号会重复认证赠币。规范补齐稳定操作、短事务及有效凭据续用：账号/登录事实和赠币一并提交，重传恢复原结果，已接受的参数不可改变。

服务身份可独立证明密钥归属并绑定，无需个人助手或公网服务端点；绑定不等于模板发布或可以接单。两角色使用同一账号会话机制，连接不调用密码登录维持。

## 标识与边界

agentId 标识平台智能体，protocolId 标识 A2C 签名主体。服务的协议地址由平台基址和服务 agentId 导出；已有个人助手保留其 URN。关联属于接入数据，不增加 A2C 字段。完整执行、容量门禁、宿主与演示仍按开发计划推进。

## 实现与核验

- 身份中心维护挑战、公钥和账号操作；应用用例调用身份及账本公开事务接口，统一登录赠币及付款身份登记，不让身份模块直接改账本。
- SDK 的 AccountSession、IdentityClient 共用登录恢复与绑定；旧委托、收件和服务账号已接入共用账号机制，未就绪的完整角色执行仍见开发计划。
- 绑定证明按内联公钥签署，不携带 JWKS kid；公钥保留发布用 kid。丢响应后先恢复同一证明，已成功绑定不因挑战到期重复创建。
- 新增12项公开接入测试，含并发登录、账号/赠币及身份/付款绑定原子回滚、失效显式认证、登录/绑定丢响应、跨账号公钥冲突、服务无需个人助手或公网端点即可连接，以及 cookie 不代替 SDK Bearer。
- 旧管理员测试原先假定服务列表只含测试服务进程；改为逐一核对该进程已发布的真实端点全部可见，允许其他用户独立登记的身份。
- 全部213项测试通过；原产物 VERSION 保留实际实现依据。真实九问、接单执行和新版视频尚不以本轮测试作完成证明。
