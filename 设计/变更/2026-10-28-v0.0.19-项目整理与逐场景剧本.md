# 项目整理与逐场景剧本

| 项 | 结论 |
|---|---|
| 文档职责 | 设计记约束，变更记录记实现范围与历史，verification记运行结果和成片状态；试用手册不保留旧的本地收件阶段描述 |
| 剧本入口 | 全局视角、美甲委托、助手交互各有场景目录与剧本.md；根演示说明只做索引，原散放剧本与重复镜头方案归档 |
| 生成来源 | 保留global_story与case_story的旁白唯一源，结合配音时间轴、镜头操作说明与公开证据生成；预览缺镜头明确待补录 |
| 代码整理 | 共用JSON读取、路径约束和真实用例证据判定，避免编辑、检查、发布的准入条件漂移；按步骤展开录屏工具，补齐Pillow演示依赖 |
| 校验 | 自检检查剧本未漂移、镜头ID覆盖、成片哈希；新增缺签名、错合同、未付款和Outlook缺证拒绝等回归 |
| 不变边界 | 不修改协议、用户身份、合同状态、邮件授权与既有视频内容；原始运行和凭据不入库；交互正式片仍待真实Outlook镜头 |
