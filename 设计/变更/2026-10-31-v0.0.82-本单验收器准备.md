# 本单验收器准备

## 依据与决定

原生服务配置中没有业务验收资源；前台上传的引用不会自动成为后台上下文。仅允许提交quote而不给后台准备真实验收引用的能力，会使按单提案依赖人工搬运或猜测引用。

| 问题 | 决定 |
|---|---|
| 验收器来源 | 可预置复用，也可按本单业务判据生成；通用SDK不确定业务判据或固定场景 |
| 后台能力 | quote阶段提供provider.task.verifier.publish；仅打包和取得真实引用，不提供服务管理 |
| 实现归属 | 管理上传和本单回调共用provider内的验收器准备实现，复用平台确定性打包与A2C包校验 |
| 关联与复用 | 身份、作业和交互由SDK固定，同内容恢复原上传；宿主调用ID不作为新的业务来源 |
| 阶段与结果 | 收到引用才能quote；未知先核对并结束本轮；决定后及其他阶段拒绝；不改变已签判据 |

不增加A2C合同字段，不要求修改原版九问，不把具体服务、判据或价格写进通用模块。
