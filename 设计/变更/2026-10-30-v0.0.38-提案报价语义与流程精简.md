# 提案报价语义与流程精简

| 项 | 说明 |
|---|---|
| 进一步实测 | 未配置数量下限、实际读取完整通用流程后，九问仍把三家proposalFee=1列作交付价格，并在request之前要求选择；该take未完成，保留为失败证据 |
| 模板检查结论 | 候选能力与费用足够，不是模板把其他两家排除；但提案型模板对拟卡费/合同价的文字说明不充分，容易误读 |
| 服务说明 | 公开说明及签名模板的交付描述增加报价约定，正式金额须由request返回签名合同；不增加协议字段或改变价格 |
| 技能精简 | 只保留按阶段执行的命令、输入及回执条件；详细参数/诊断放原语参考，行业信息仍在独立示例 |
| 验收 | 模板签认与既有三家闭环回归；不设固定数量偏好的原生九问完整复录。尚未通过不更新成片状态 |
