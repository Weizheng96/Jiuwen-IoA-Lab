# 2026-10-26 · v0.0.2 · 执行边界与本地 SDK

## 起因

用户确认：平台没有个人助手（含背景助手）；ISC账号空闲，流量由独立客户端产生；官方服务随平台部署在独立进程；用户安装九问、导入技能、配置地址与账号即可使用，安装流程准备本地 SDK。所有设计先写文档、更新版本，再开发。

## 决定

| 项 | 决定 |
|---|---|
| 核心 | 只留基础设施，不保存用户私钥或代其验收签字 |
| SDK | 独立可安装包，直接使用 A2C Client，复用现有 SDK 规则而非 REST 代理合同操作 |
| 官方服务 | 独立目录与进程；常驻 Provider + 持久化队列 + 按需九问；公开登记，与第三方同路 |
| 模板 | 可缓存带原签名的完整模板，浏览不激活模型 |
| 观察 | 标明已核验合同证据与上报过程；幂等、乱序保护、实验来源 |
| 开发顺序 | 先提交设计基线，再实现本地闭环与服务进程，再做真实 Swarm/部署验证；产物未完成如实记落后 |

## 非目标

不改 A2C 协议，不实现助手间消息系统，不引入通用工作流平台，不把桩测试当成真实 Swarm 或 Linux 已验收。
