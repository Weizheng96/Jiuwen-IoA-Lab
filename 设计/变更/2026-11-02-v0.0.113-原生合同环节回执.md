# 原生合同环节回执

| 项 | 内容 |
|---|---|
| 原因 | 原生个人助手取得合同环节请求后，因状态未给出后续操作必需的请求摘要，误将合同摘要传入answer_step；拒绝后打开空确认页并误报待确认 |
| 归属 | 个人助手端SDK定义当前环节请求、官方对象摘要及错误恢复入口；个人助手技能据真实回执申请并继续本阶段确认 |
| 规则 | status仅同时返回已经核验的当前stepRequest和原A2C对象摘要stepRequestDigest；无当前请求、解除或原核验未知时不暴露未核验对象或摘要。answer_step消费status字段，摘要失配先重查且不创建确认 |
| 取舍 | 不让模型计算或猜摘要，不增加旧字段别名、第二套摘要算法或确认入口；打开页面与真实待确认及实际答复分别核实，保留原签名、当前阶段、期限和独立可信答复门禁 |
| 验证 | 检查当前请求与摘要一致、未知核验不暴露、无请求及解除均为null；错误摘要不产生确认，正确回执可申请真实确认；下一期不能沿用上一期摘要 |
| 规范 | [个人助手端SDK](../接入/个人助手端SDK.md#委托交易入口)、[个人助手技能](../接入/个人助手技能.md#流程页契约) |
