# 一句需求与原版委托流程

| 项 | 决定 |
|---|---|
| 触发 | 用户只描述店铺、预约需求、预算；流程指令属于产品技能，不写进用户请求 |
| 用户节点 | 发起需求 → 委托授权 → 合同确认 → 实名注册环节授权 → 验收确认；不另问基础/高级版本 |
| 原剧本 | 对照A2C仓demo/美甲预约/台词-完善.txt；七家同名服务，三份真实提案，九问比较后推荐码上飞299虚拟币；未发生的历史信誉数字不得复用 |
| 范围 | 本地预约工具及微信小程序源码交付；实名注册为合同预声明的演示授权，不采集真实身份资料、不连接微信注册、不宣称微信审核上线 |
| 授权 | 本地SDK保存目的、预算、拟卡费额度、有效期；选定一份合同，合计费用受总预算约束；重启可恢复，不重复付结果不明的拟卡费 |
| 验收 | 快搭建站5项，码上飞10项；运行真实预约行为而非只比较配置标志；灵犀采用L2程序判定与单个已配置仲裁模型，模型不能直接输出裁决 |
| 网络 | 仅其他个人助手匿名；专业服务使用公开目录原名，关联服务彩色、其余弱化；本地背景动效不进入真实统计，说明放在图例详情 |
| 服务方 | A2X分类导航、可选服务列表、所选服务详情、履约队列、收入和历史；只计真实过账，不混合合同金额与收入 |
| 产物 | 先更新代码和技能并验证，再真实九问网页录制；旧委托片未重录前如实记旧版本 |
