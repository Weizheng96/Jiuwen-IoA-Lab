# 三视角网络与演示

| 项 | 决定 |
|---|---|
| 动机 | 领导需要在活跃网络中理解自己的一笔委托、各组件职责与消息交互，而不是只读订单列表 |
| 个人助手 | 上方网络与可点选组件，下方有证据的阶段、当前与历史委托、金额、消息 |
| 隐私 | 普通视图只返回所属数据；灰色背景为无身份示意，不获取其他用户正文、账号或实时活动 |
| 服务方 | 分类树、所属服务、实际模拟收入、履约中与历史 |
| 视频 | 全景并发、美甲工具委托、定向留言与会议邀请；真实九问网页与真实SDK记录 |
| 真实性 | 私人日历授权缺失不得假定空闲；支付以凭证计收入；背景动效不制造统计 |
| 配音字幕 | 大字短句、约1.12倍语速、同一事件时间轴；实际等待可标注压缩 |

本次先更新设计，再实现界面与录制工具。已存在的测试视频不是本轮正式三段演示；各产物完成迁移后分别更新VERSION。会议可预约依据与真实收件镜头须按可用授权验证，不以已有邮件成功替代整条预约验收。
