# 全局分段演示与登录赠币

| 反馈 | 决定 |
|---|---|
| 无开场片头 | 独立完整封面，展示正式名称与一句话介绍 |
| 组件空洞 | 收紧布局，增加合同记录、分离仲裁与信誉，并展示真实账号登记和事件观察 |
| 读音、语速 | A2C念A to C；采用参考片快语速，实测配音驱动时间轴 |
| 动画与解说不符 | 固定剧本逐段隔离路径，0—8不播放无关活动，9—10加速全景与监控 |
| 字幕弱 | 大字、短句、高对比底条，逐句同步 |
| 登录赠币 | 用户明确要求每次成功登录赠100；保留认证、访问与登记边界，不再按日去重 |
| 真实性 | 真实运行导出驱动统计；ANN、支付授权及条件仲裁机制与本轮实际执行区分 |

研究参考主仓智能体互联网的story/script、事件导出、map、配音及逐帧录制。沿用固定剧本控制地图和音频实测排镜头的方式；不复用旧运行数字、不改变协议签名与验收边界。原第二、第三段开发进度保留，优先完成本次全局修改。
