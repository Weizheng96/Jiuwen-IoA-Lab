# 演示默认值确认与录制恢复

| 项 | 说明 |
|---|---|
| 观察 | 模板确认三家合格后，助手请求营业时间和项目等业务设置；不是把拟卡费误作合同价，也不是排除其他候选 |
| 剧本 | 店主在委托授权答复中允许非关键设置采用合理默认值，要求在具体合同中列明并再次确认。首句仍只有业务需求；不添加技能路径、SDK命令或固定服务偏好 |
| 边界 | 用户核心需求、预算、必需材料及真实身份不能靠默认值覆盖；主skill与SDK不写行业值 |
| 中断 | 辅助截图JSON由PowerShell写入BOM，录制器退出，发生在签约前；兼容该编码，保留原录像及实际合同/费用状态，不补造结果 |
