# 部署教程与重部署职责

用户要求人类只读一篇常规教程，覆盖Windows本地、Linux服务器远程部署与LLM API key配置；两平台均先清理此前部署所属进程再重新部署，不保留旧进程升级。原数据、账号、模型配置与业务回执默认保留，未授权删库或清配置。

部署.md成为两部分操作教程，是设计目录内明确标识的非规范操作资料。原发行、依赖、环境、网络、进程与核心数据锁规范收归安装与升级；配置权威归平台配置；试用入口归在线试用。现行调用方同步引用，不改写历史设计记载。部署发行只保留必要公开验证及历史影片摘要；deployment技能仅指向教程，异常经验按需读references。

规则、数据和状态所有者不变：deploy管理所属安装/进程，组件各持运行数据与配置；调用只走既有公开安装、SDK和原版九问接口。重部署先停止与核权，再复用受审发行、备份、迁移及激活链，不建立第二引擎或状态库。未知归属/锁拒绝并保留现场，模型配置与真实组件调用分别核验。

教程中尚缺的公开重部署、HTTPS、三席与模型实机证据在开发计划登记。文档整理不宣称这些实现或验收完成，不提高其他产物VERSION。
