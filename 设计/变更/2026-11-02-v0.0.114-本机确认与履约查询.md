# 本机确认与履约查询

| 项 | 内容 |
|---|---|
| 原因 | 本机确认页刷新可能覆盖答案草稿并抹去提交错误；履约状态业务operationId与CLI外层幂等字段同名，正常脚本查询因此缺少目标动作 |
| 归属 | SDK共用机制定义参数文件的外层标识及受控确认页行为；个人助手端SDK定义合同履约动作查询字段与结果 |
| 规则 | status业务目标唯一使用fulfillmentOperationId，CLI顶层operationId继续作为本次外层幂等标识，旧业务字段不保留别名；确认页按reference与bindingDigest保留同一待确认绑定的草稿，提交期间保持稳定并阻止重复，失败草稿和错误不被后台刷新清除 |
| 边界 | 草稿不跨绑定或终态复用，不构成授权；刷新不回退已收到的终态，未知决定先核原记录；保留原合同归属、确认绑定、期限及同源和CSRF校验，不改变协议签名或付款规则 |
| 验证 | 经真实CLI与IPC验证外层幂等键和履约查询目标分别传递，跨合同及旧业务字段拒绝；确认页覆盖单选、多选、文本、迟到刷新、提交重入、失败提示及绑定变化，不以仅下载HTML替代页面行为检查 |
| 规范 | [SDK共用机制](../接入/SDK共用机制.md#操作返回与恢复)、[用户确认](../接入/SDK共用机制.md#用户确认)、[个人助手端SDK](../接入/个人助手端SDK.md#委托交易入口) |
