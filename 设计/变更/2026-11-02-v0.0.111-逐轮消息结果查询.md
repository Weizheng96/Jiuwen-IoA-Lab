# 逐轮消息结果查询

| 项 | 内容 |
|---|---|
| 原因 | SDK与技能将消息引用和交互句柄并列用于结果查询，未定义交互级查询范围；实现固定读取首消息，改约后可能反复返回已完成的首轮冲突 |
| 归属 | 个人助手端SDK定义查询单位与引用；助手通信流程保存每轮回执，接入技能依该契约调用 |
| 规则 | status仅接受本轮messageRef；interactionRef继续串联交流和关闭。每轮结果独立且终局不可变，不新增“最新消息”投影或另一个查询状态机 |
| 取舍 | 内部开发阶段直接移除歧义入口，不保留旧参数别名；不以测试专用提示绕开普通用户会遇到的问题 |
| 验证 | 同交互的两条消息分别经历等待与终局，首轮冲突不覆盖第二轮，也不被成功结果改写；错误引用明确拒绝；真实发信模型依正常接口说明读回执并自主改约，结果另记验证记录 |
| 规范 | [个人助手端SDK](../接入/个人助手端SDK.md#助手通信入口)、[助手通信](../流程/助手通信.md)、[验收](../工程/验收.md) |
