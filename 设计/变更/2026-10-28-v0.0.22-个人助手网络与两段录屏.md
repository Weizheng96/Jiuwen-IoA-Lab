# 个人助手网络与两段录屏

| 项目 | 决定 |
|---|---|
| 页面布局 | 上方网络固定可见，下方记录、接口和详情独立滚动；沿用管理员组件目录与协议副标题 |
| 数据边界 | 本人真实活动取自授权数据；其他参与方仅本地匿名灰色背景示意，有限短连接，不读取全局隐私数据 |
| 交互口径 | 统称助手间交互，接口区为“我定义的交互接口”；不将交互一律定性为协作，不强调免费 |
| 人物 | 消息示例使用王经理与赵专员的个人助手；显示名不参与授权判断 |
| 会议链路 | 查询接口、格式化发信、冲突回执、改约、发出邀请待本人接受；不冒称已接受入历 |
| 录制 | 同步委托与交互片，真实九问与工作台重新录制；按实测语音剪辑并生成各自剧本 |

用户补充的新旁白由场景源继续完善，交由用户检查。删除企业邮箱字符串免责声明的旁白，技术边界保留在设计与验收说明。未拍到本轮Outlook接受与日历显示时仍标为预览，不能把发件成功当作接受证据。
