# 未成约记录展示

| 项 | 内容 |
|---|---|
| 原因 | 原数据的到期提案已正常释放名额，但观察视图仍显示等待确认；网络把候选报价称为当前委托和合同总额，服务方分组也依赖不一致的显示状态集合 |
| 归属 | 界面通用规范统一表达；观察投影读取既有接单、成约与未知执行证据，工作台据此分组。历史活动保留当时事实，不补造结束事件 |
| 规则 | 未成约的权威释放记录使用观察状态unformed-closed；候选记录始终保留，报价、拟卡费与合同价款分别显示。缺副本、未知或仅过期不推断正常结束；默认优先在途记录，用户选择保持 |
| 范围 | 不改变A2C字段、接单和付款规则，不增加数据库、后台任务或新的协议状态机 |
| 验证 | 真实HTTP/WS的候选到期、未到期/未知保留、费用及既成合同不受影响；检查三类工作台实际渲染与分组，结果另记开发计划和验证记录 |
