# 预约输入结构校验

| 项 | 结论 |
|---|---|
| 触发 | 实录中委托方将项目时长写为duration，字符串schema放行；生产侧转换为minutes后不再等于合同，真实验收失败 |
| 修正 | services改为数组，元素为name和minutes，整数时长限定15至240，禁止额外字段；提案前由A2C校验，失败不付拟卡费 |
| 证据 | 服务宿主保留实际工具事件与模型终止结果；聊天宣称完成不代表已交付 |
| 历史 | 不修补已签署的错误合同，不覆盖失败任务；正式录屏重新发起合法委托 |
| 边界 | 不改A2C协议，不在宿主执行验收器，不通过样件代替真实生产 |
