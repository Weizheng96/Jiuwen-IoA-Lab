# 本机配置辅助

## 原因与取舍

产品技能已经要求模型不读取密码，但增配服务仍需修改含凭据的整份设置，原生复测曾读取整份演示配置。改为SDK提供启动前的字段查询和受限合并，用户只私下填写账号一次。保留一个配置所有者、一个实例锁和已有原子私有文件写入，不新增配置服务、兼容别名或业务状态机。

## 规则归属

完整契约见[SDK共用机制](../接入/SDK共用机制.md#不读取凭据的配置辅助)，服务方配置引用公共操作；产品技能说明使用顺序，验收新增I21。角色校验由角色模块拥有，离线命令与真实执行复用，不在引导脚本复制。

## 先行审查

| 问题 | 处理 |
|---|---|
| 如何保留密码、工具凭据与其他角色 | 不返回全文；白名单字段局部合并，账号及专用数据目录不可更改 |
| 是否自动停止或改变在途业务 | 有实际实例锁则拒绝，用户先安全停止；配置变更不扩展既有交互 |
| 并发启动是否会使用旧配置 | 取得实例锁后、认证与开库前复核所读快照，变化即拒绝 |
| 是否增加一套操作日志 | 同值重复只报告当前事实，异摘要拒绝；没有外部业务效果，不增加恢复引擎 |
| 是否真的检查业务可用 | 结构校验与启动后的宿主、连接、工具探测分开，不能混报 |
