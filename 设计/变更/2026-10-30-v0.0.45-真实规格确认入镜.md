# 真实规格确认入镜

| 项 | 说明 |
|---|---|
| 实际分支 | 助手读取模板后要求确认规格参数，尚无付费提案；已允许默认值但模型仍追问，不能把该轮宣称为完全自动 |
| 剧本 | 店主只答“非关键设置按合理默认值拟定，列在合同中由我确认。”，不提供SDK命令、路径、服务偏好或数量指令；单独镜头与旁白如实说明 |
| 证据 | 通过原录制浏览器输入，核对原生会话确有规格问题及该用户答复；保存时间、消息及轨迹摘要，补齐真实用户轮次和原片镜头位置 |
| 边界 | 四处不可逆阶段确认仍保留；额外业务澄清不当作签约、环节或验收授权。其他工程提示仍不得用于正式片 |
| 不变 | 不修改通用skill、SDK或九问，不把业务回答写入产品默认；只修正本场景脚本与证据记录 |
