# AgentMail专用通知邮箱

| 项 | 决策 |
|---|---|
| 起因 | 用户已有独立Outlook邮箱，但无Entra目录，明确改选AgentMail作为智能体专用邮箱 |
| 接入 | 官方注册API＋邮箱所有权验证；验证后将实际邮箱地址/API key配置到现有SMTP客户端，无新增邮件微服务、消息中间件或第三方SDK依赖 |
| 权限 | 通知工具只配置已拥有的邮箱；API key不进入模型、核心或Git；不因服务支持收信就自动执行外部邮件 |
| 恢复 | 有本地注册状态即复用；未知注册结果不自动重试，避免无意轮换API key；OTP只提交到官方验证端点 |
| 兼容 | 其他SMTP服务与可选Outlook OAuth2保留；用户仍可选择Outlook接收邀请 |
| 验收 | 邮箱创建、所有权验证、SMTP认证、邮件受理、收件人收到/接受分别记录；缺日历读取授权时不能报告完整自动预约成功 |

参考：[AgentMail注册](https://docs.agentmail.to/api-reference/agent/sign-up)、[验证](https://docs.agentmail.to/api-reference/agent/verify)、[SMTP](https://docs.agentmail.to/imap-smtp)。
