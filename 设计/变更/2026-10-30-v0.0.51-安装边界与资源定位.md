# 安装边界与资源定位

## 发现与处理

首轮结构迁移发现两处隐藏源码依赖：管理员组件接口从相邻设计目录读取版本，技能下载接口从包的父目录查找 dist。前者改为读取安装发行元数据；后者先在部署和平台接口设计中明确 IOALAB_BUNDLES_DIR，再实现配置目录读取。接口不在请求内构建、不包含用户配置。

平台与 SDK 分别迁入 src/platform、src/access/sdk，保留 Python 导入名和实际产物依据；平台依赖按发行包声明，不以设计发布冒充代码完成。端到端冒烟是仓库验证工具，移入 tools，不随核心运行包导入参与方 SDK。

显式种子清单由官方公开元数据构建，记录来源摘要；平台只读取经配置传入的 JSON，不找相邻参与方源码，缺少或非法输入在启动检查中报告。默认账号、分类及公开服务数量保持既有配置。
