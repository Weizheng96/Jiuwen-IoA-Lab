# 受限业务技能与能力证据

## 问题与决定

原版只读探测确认：传入选中技能名称不保证读取正文；显式 Agent.skills 与 skill_tool 可实际加载，但同一工具也能读取未选中的其他已安装技能。选中列表不是授权边界。原版 permission.get 返回命名权限策略，不是完整工具目录；未列出的 skill_tool 确实存在，不能按此认定工具缺失。

参与方本机明确配置业务技能源目录，适配器将本单所选技能的主文件与 references Markdown 冻结到原交互工作区。模型仅通过本单只读回调取得这些文档，不暴露原生全库 skill_tool；读到主文件后才允许提交本单 SDK 业务动作。文档是业务知识，不扩大工具、预算或合同授权。已开始交互继续使用原快照，源目录变化不替换原内容。

原版命名权限只作为策略快照；已知 deny 阻止新生产配置，缺少条目记为未核实，实际失败仍按原结果返回，不冒充能力验证。精确工具清单、阶段限制和原宿主参数规则继续生效，不授予全工具访问。

## 实施与验证

设计先于实现。核对跨技能/路径/私有文件拒绝、原快照恢复与篡改检测、主文档真实读取，以及原版九问调用证据。原生网页加载、业务生产和影片继续分别验收。
