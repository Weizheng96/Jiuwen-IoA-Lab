# 全局旁白主线

| 项 | 决定 |
|---|---|
| 用户要求 | 全局视角旁白参考A2C主仓demo/智能体互联网/剧本.md |
| 展示名称 | 九问IoA实验平台（Jiuwen IoA Lab）；介绍为“面向智能体互联网的仿真验证与开放体验平台。”；仓库与代码标识不变 |
| 主线 | 平台定位、两类参与方接入、多方委托、发现与履约、平台价值；加入当前个人助手消息与账号聚焦 |
| 数据边界 | 旧剧本的10人、拒单换家和仲裁结局属于旧运行，不移植到新实录；登录赠币改按当前注册体验机制描述 |
| 呈现 | 旁白讲规则和价值，短字幕突出要点；真实管理员页面按已生成音频安排镜头，持续显示仿真实验标识 |
| 版面 | 平台组件居中放大，服务方收紧为领域窄栏，事件流辅助；普通页面保留服务滚动浏览能力 |
| 讲解动画 | 单独标识的组件高亮、箭头与流动光点，只表达机制，不改真实记录或统计；验收在个人助手本地 |
| 唯一台词源 | demo/global_story.py；生成全局剧本.md，避免录制入口和文档分别维护台词 |
| 并发 | 独立实验客户端持续产生消息，按预算内节奏产生三种成约方式的真实委托；不制造拒单或裁定数据 |

本次调整全局概念片、管理员全景布局与录制工具，不改变A2C协议及平台执行边界。其他两段正式视频仍另行完成。
