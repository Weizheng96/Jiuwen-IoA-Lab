# 2026-10-26 · v0.0.1 · 版本基线与 Codex 迁移

## 起因

用户明确要求完全切换到 Codex，并将平台版本从 0.0.1 开始，采用与 A2C 一致的递增策略。

## 决定

| 事项 | 处理 |
|---|---|
| 版本基线 | 当前平台由 v0.1.0 重新编号为 v0.0.1；这是同一份实现的编号调整，历史建仓记录保留 |
| 自动递增 | 设计或口径变更时 Codex 可递增最后一位；倒数第二位及更高位仅由用户明确决定，不自动进位 |
| 产物 | ioalab、connector、examples、deploy 的 VERSION 同步；连接器 manifest 与产品技能的版本元数据同步 |
| A2C 依赖 | 保持原 wheel、摘要与来源提交，不随平台编号改变 |
| 开发入口 | 根 AGENTS.md 承接项目约定；当前开发交接见 docs/开发计划.md |

## 影响

开发约定和版本标识改变，平台业务行为不变。历史 v0.1.0 记录用于追溯，不再是当前版本。
