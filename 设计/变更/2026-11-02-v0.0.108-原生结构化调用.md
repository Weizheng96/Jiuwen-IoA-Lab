# 原生结构化调用

| 项 | 内容 |
|---|---|
| 原因 | 原生询价参数曾缺JSON分隔符，统一报成UTF-8错误使模型误改编码；实际SDK合同中文完整，宿主终端回显却按其他代码页解码。模型把作业UUID代替完整reference对象，读取失败后仍概括验收覆盖 |
| 归属 | 产品脚本只序列化真实SDK结果，采用ASCII转义JSON跨终端，SDK仍按UTF-8读写文件；SDK区分语法、编码和文件读取失败，不猜测或修复原输入 |
| 读取 | 保存data.reference完整对象；operations.get的外层完成表示查询完成，内层作业完成后读取data.data，才可解释候选和真实验收源码 |
| 边界 | 不修改九问源码、全局指令或历史，不执行服务方源码；错误不触发重新询价、改合同或付款。示例保持通用，业务验收强度由对应Demo业务配置负责 |
| 规范 | [SDK共用机制](../接入/SDK共用机制.md)、[助手技能](../接入/个人助手技能.md)及[验收](../工程/验收.md)；本轮运行结果另存验证记录 |
