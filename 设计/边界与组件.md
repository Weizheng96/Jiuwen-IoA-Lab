# 边界与组件

九问IoA仿真平台是一个**单进程**服务（FastAPI · 单 worker · asyncio），把五个组件装在一起；协议规则以 A2C 主仓设计为准，本文只写平台怎么把它们跑起来。
虚拟币是平台的记账单位，不对应任何资金；平台不是任何一方的资金存放处。协议内 `pricing.currency` 用 `CNY`（SDK 币种白名单无自定义币种），页面显示「虚拟币」。

```
┌──────────────────────── ioalab 进程（FastAPI · 单进程单 worker · asyncio）────────────────────────┐
│  ① 模拟支付方            ② Agent 交易中心                 ③ 智能体运行时                          │
│  （含虚拟币账本）        ── 注册中心（A2X 发现 · 分类树）   ── 个人助手：平台驾驭（ReActAgent）       │
│  ── 账号 · 钱包 ·           服务认证 · 模板公示 · 信誉 ·      或 九问 swarm 驾驭（REST）             │
│     读卡过账（协议外）      仲裁（市场自有，协议外）        ── 专业服务：生成 → 自测 → 交付           │
│                          ── 平台方 SDK：签模板 · 签3 ·        （openJiuwen + A2C 服务方 SDK）       │
│                             签5(i) · 结清（协议内）                                               │
│          ▲                         ▲                              ▲                             │
│          │ AP2 ap2.pay             │ A2A：参与方 id = <PUBLIC_URL>/a2a/<name>                    │
│          └─────────────────────────┴──────────────────────────────┘  进程内互调改走回环          │
│                                     ④ 事件总线（发送侧包 Transport.send · 接收侧包 Endpoint.finish）│
│                                                  ▼                                              │
│  ⑤ Web：用户端（注册 · 助手 · 服务 · 需求 · 订单 · 确认）· 管理员控制台（全景 · 实时流 · 泳道 · 组件 · 投放 · 回放）│
│      + 委托方 REST（/api/v1，九问技能包调用）                                                     │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
```

| 组件 | 复用什么 | 协议内外 | 边界 |
|---|---|---|---|
| ① 模拟支付方 | `a2c.payment.psp.PaymentProvider` 子类 + 平台钱包账本 | **外**：持牌支付方的替身 | 只在 `ap2.pay` 读卡核过金额后过账；只认签5(i) + 签7(i)；不按裁定划转、不代任何一方发起划转；市场与 A2C 代码不碰钱包 |
| ② Agent 交易中心 | `a2c.market.Market`（平台方 SDK）+ A2X registry（库，进程内）+ 平台自建认证、信誉、仲裁文书 | 签模板 / 签3 / 签5 / 结清：**内**；认证 / 发现 / 信誉 / 仲裁：**外** | 市场不看钱款收付，只验签名链 |
| ③ 智能体运行时 | openJiuwen agent-core（ReActAgent + `@tool`）+ `a2c.client.Client` / `a2c.provider.Provider` + `a2c.verifier` | 内 | 验收由验收器判，模型只观察；报价是定数；签约后零模型调用 |
| ④ 事件总线 | 包装各方 `Transport.send`（发起方、完整报文）与 `Endpoint.finish / _fail_task`（结果）；智能体回调记工具轨迹与 token | — | 只记报文与签名，是管理员看到的「当前交易」 |
| ⑤ Web | FastAPI + 原生 HTML/JS（无构建）+ WebSocket | — | 文案不出现资金类禁用词 |

## 地址与通路

| 项 | 规则 |
|---|---|
| 参与方 id | 市场 `<PUBLIC_URL>/a2a/market` · 支付方 `<PUBLIC_URL>/a2a/pay` · 服务方 `<PUBLIC_URL>/a2a/providers/<svc-id>`；助手不是端点，只发请求（签名主体 `urn:ioalab:client:<asst-id>`，用户亲签 `urn:ioalab:user:<user-id>`） |
| `PUBLIC_URL` | `IOALAB_PUBLIC_URL`；首次运行记入 `data/public_url`，之后不一致拒绝启动（模板 · A2X 索引 · 已签的卡都内嵌它） |
| 进程内互调 | 各参与方各有自己的 `A2ATransport`，发往自己 PUBLIC_URL 的请求由 `LoopbackTransport` 改走 `http://127.0.0.1:<port>`（Host 头保留） |
| 可达性 | `/a2a/providers/*` 只放行回环（内部服务方只被平台自己调用）；`/a2a/market` 与 `/a2a/pay` 公开（外部服务方要向市场发 `template.endorse`、经支付方收款） |

## 措辞

钱包里的数叫「余量」，划转叫「过账」，付不出叫「支付方拒绝付款」。资金类禁用词以 AGENTS.md §一 为准，`tools/selfcheck.py` 与 `tests/test_boundary.py` 扫描源码与文档。
