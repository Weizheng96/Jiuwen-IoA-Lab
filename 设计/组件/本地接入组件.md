# 本地接入组件

## 目的与范围

本地接入组件是 IoA Lab SDK 提供的常驻进程，运行在用户设备或服务方环境中，负责连接、可靠收发、业务调度及九问会话恢复。它不属于平台核心，也不依赖模型循环轮询维持在线。

个人助手端 SDK 和服务方端 SDK 是同一软件包的两个角色模块，共用本组件；同账号的一个实例可以承载个人助手及多个服务，各自保留身份、配置与业务状态。共用实现归 `src/access/sdk/ioalab_sdk/runtime/`；项目组织见[架构](../架构.md)，产品调用契约见[SDK 共用机制](../接入/SDK共用机制.md)。

## 模块与依赖

| 模块 | 唯一职责 | 依赖 |
|---|---|---|
| 传输适配 | WebSocket、认证恢复、回执与推送订阅 | 公共报文和身份，不依赖业务场景 |
| 本地存储 | inbox/outbox、交互映射、检查点、操作及工具回执 | 为运行时和业务模块提供短事务 |
| 调度 | 同交互串行、跨交互并发、模型名额、等待恢复 | 调用角色处理器，不解释合同字段 |
| 个人助手模块 | 发起委托、收发助手消息与本地收信规则 | 共用运行时，委托功能复用 A2C SDK |
| 服务方模块 | 发布服务、接单策略、A2C 履约与交付 | 共用运行时和 A2C SDK |
| 九问适配器 | 能力探测、执行/续接、取消、通知、受限工具绑定、真实用户答复关联 | 独立可选 ioalab-jiuwen 包，使用九问公开能力 |

SDK 核心不导入平台核心、A2X 内部实现、九问或官方场景目录；平台核心不导入参与方执行器。九问适配包的启动入口将角色处理器和实现 AgentHost 的宿主对象注入运行时；运行时仅通过该窄接口调用宿主，不自行发现插件或复制角色流程。

AgentHost 负责上述宿主能力及其真实结果，合同、报价、接单和会议规则不属于宿主接口。可信用户答复由适配器关联，授权对象和阶段仍由 SDK 核验；无法建立关联时按下文保留等待并使用本地受控确认入口。业务技能负责生产和业务判断，传输、签名、付款与重试由 SDK 执行，不建立通用工作流引擎。

## 本地数据所有权

本组件是身份目录、私钥和 SDK 业务数据库的唯一写入所有者。技能脚本和 CLI 经本机认证的 IPC/回环 API 调用，不另开同一身份库，不持有竞争的全局长期锁。

同一 data_dir 在打开账号、私钥或协议数据前取得操作系统进程锁；第二实例明确失败，不凭遗留 PID 文件认定进程仍存活或删除数据。端点描述只在监听就绪后原子写入，含回环地址、随机访问凭据、进程与实例标识，文件仅所属用户可读。描述文件不是运行证明，客户端必须验证当前接口和实例；重启更换访问凭据，清理只删除本实例自己的描述。

启动按配置激活本地身份，不自动接管账号下其他设备的全部智能体。角色的本地 profile key 对应持久 agentId；重新启动不换钥，加角色不另起实例。已有身份与原业务数据缺失时要求迁移，不能用新目录重建同名助手。旧执行入口与新运行时切换前须确认原写入者已经停止。

平台暂时不可达时，仅有已绑定身份、未过期缓存凭据和已固定公共配置的实例可离线启动；持续恢复连接并报告离线。首次认证或绑定必须在线完成，认证明确拒绝时不使用缓存绕过；离线启动不授予业务开始许可，也不重新密码登录或赠币。

| 数据 | 保存规则 |
|---|---|
| 身份与凭据 | 本地私钥、付款身份、平台凭据；不上传平台或交给模型 |
| 用户授权 | scope、阶段确认对象与真实用户答复来源、许可动作、有效期和预算使用记录 |
| 协议原件 | 模板、请求、合同、材料、交付件、签名链、验收及付款回执，由 A2C SDK 管理 |
| 收发记录 | inbox/outbox、去重依据、连续 ACK 游标和控制操作结果 |
| 执行映射 | 起始消息、交互 ID、参与方、九问会话、固定技能/工具定义摘要与业务检查点 |
| 收信版本 | 已确认的完整本地规则、内容摘要与平台修订映射；修改草稿不覆盖在途处理版本 |

数据库事务和写锁只覆盖短操作，不在锁中等待网络、模型或用户。观察上报失败只进入 outbox，不回滚已成功的协议动作；平台观察副本不替代本地原件。

日程、预约、邀请等业务状态及原始工具回执由所属本地业务工具保存；运行时保存调用标识、输入摘要、回执引用及检查点。工具沿用运行时传入的稳定操作键，恢复时先查询原回执；未知外部效果不能由新一次模型调用自动重做。工具状态不复制成 SDK 内的会议或邮件状态机。

## 交互建立与会话映射

| 时点 | 本地行为 |
|---|---|
| 可靠收件 | 在同一事务保存 inbox、去重记录与可连续推进的游标，再确认送达 |
| 首次有效请求 | 以“接收智能体、发送智能体、起始消息 ID”查唯一记录；不存在才创建交互 UUID |
| 建立回执 | 同一事务保存交互映射和待发 `interaction.opened`；重传只返回原记录 |
| 开始业务 | 先取得平台登记及请求开始许可，再执行业务工具；不得把创建本地会话视为获准接单 |
| 发起端关联 | 按 originMessageId 原子补齐 UUID；等待期间记 awaiting_open，不凭正文或用户名猜测关系 |
| 补查 | 原建立回执丢失时查询平台登记或重传原请求；查到建立前终态则结束等待，不创建第二交互 |
| 后续发送 | 接受本地交互句柄，由 SDK 自动附加 UUID 和修订；未建立或已关闭时返回明确状态 |

平台关联约束和关闭竞争以[消息中心](消息中心.md)为准。本地保留 A2A 请求 ID、任务 ID、合同摘要；这些协议标识与九问 Session ID 都不能替代业务幂等键。

每个**入站交互**拥有独立执行会话；发起端的用户会话可以协调多个对外子交互。收到结果先更新原任务，不把回复当成新入站请求。不同候选服务分别有交互；同一目的的改约可以沿用原交互。

调度同时按交互和实际九问 Session 串行，避免多个子交互同时修改同一用户会话。续接固定原 Agent、技能版本和工具集合；双方保存各自 Session ID，不要求相同，也不向平台上传。

## 调度、容量与等待

| 资源 | 限制与释放 |
|---|---|
| 接单容量 | 服务的有效预留及未结束承诺；权威台账在[委托中心](委托中心.md)，本地仅镜像；等待授权/验收仍占用 |
| 模型执行并发 | 同时运行的九问轮次，由 max_model_runs 限制；本轮结束或中断后释放 |
| 本地待处理队列 | 有界；消息开始、过期或明确拒绝后收敛；排队不延长协议期限 |
| 控制通道 | 授权答复、解除、状态查询、回执与恢复独立调度，不能被新委托或满额模型队列阻塞 |

业务检查点采用 queued/running/waiting/completed/rejected/failed/unknown；这是本地执行状态，不能替代 A2C 合同状态或签名证据。

调度器只接受本地装配时登记的角色处理器。提交时按稳定操作及输入摘要落库，重传不新建作业；处理器是否需要模型由本地登记决定，外部正文不能改变。调度前原子保存 running，调用期间不持有数据库事务。跨交互并发仍受实际 Session 串行约束；waiting 释放可释放的模型轮次，unknown 阻止同交互或同 Session 继续产生效果。重启将未收敛 running 标为 unknown，先由所属角色查原结果，不盲目重跑；尚未开始的 queued 可继续执行。控制与只读入口不等待模型队列。

取得有效执行连接前不调度新入站作业；业务工具发起效果前仍须复核连接及该动作的许可。连接有效性以最近平台认证/心跳确认的保守租期判断，不以 TCP 尚未关闭判断；本地使用单调时钟及对应请求发送时点计算期限，迟到的心跳不能乐观延长旧许可。失效即暂停新调度并恢复连接，不改变已经发生效果的状态。

可结束本轮的业务等待先持久化 waiting，再释放模型名额；收到有效答复后续接。九问原生 ASK 如需同一进程回调，只能等待真实用户或已有明确授权的宿主处理；不能伪造同意或把杀进程当作可恢复暂停。宿主能力验证见[验收](../工程/验收.md)。

## 用户确认与预算保护

| 边界 | 规则 |
|---|---|
| 确认来源 | 保存真实原生答复或本地受控确认入口的记录；模型传 confirmed=true 不能自证同意 |
| 确认绑定 | 绑定账号/智能体、具体对象摘要、阶段及获准动作；对象或动作变化不能复用旧确认 |
| 使用确认 | 受保护操作前检查当前阶段、对象、授权期限及原操作记录，避免重复签署或跨阶段套用 |
| 宿主不支持 | 无可信答复关联时保留待确认，通过本地受控入口完成，不绕过用户 |
| scope 预算 | 总预算覆盖拟卡费与履约价款，并另核拟卡费子限额；同 scope 的并发候选使用同一预算记录 |
| 并发费用 | 按稳定操作标识原子预留在途费用，成功计入已支出，确认未生效才释放；结果未知保留占用 |
| 合同选择 | 核已付/在途费用与拟承诺合同总价，不因分期付款而忽略整份承诺；后续阶段费用继续使用原关联 |

本地预算预留保证多个模型或候选不会并发越过用户限额；[支付中心](支付中心.md)还须对同一授权凭证核额度，不能仅相信客户端声明。网络或模型等待期间不持有预算数据库锁。

## 按需执行与工具边界

| 触发 | 执行方式 |
|---|---|
| 身份、模板、历史结果查询、ACK | 确定性处理，不调用模型 |
| 协议验证、价格、签名、确定性验收 | 调用 A2C SDK；验收器只在核摘要后的 WASM 沙箱运行 |
| 拟卡业务判断与服务生产 | 容量、格式、阶段和权限检查后启动或续接九问 |
| 助手通信处理 | 装载原修订的本地规则，按需调用九问及已授权业务工具 |
| 配置技能 | 只处理本机用户的配置意图；外部业务消息不能切换为发布、安装或修改权限流程 |

工具权限限定当前账号、交互和阶段；外部输入只能填充业务参数，不能选择任意文件、密钥、工具或修改接入技能。收信处理文本不是 Python/Shell 程序，不能作为可执行代码导入；业务工具由用户预先配置。官方日程、邀请邮件等工具归 `src/official/tools/`，通过已配置的宿主工具入口调用；SDK 核心不导入该目录，普通接入也不自动获得这些业务能力。

九问适配器仅使用锁定原版公开接口，不改源码、全局指令和私有历史数据库。Process SDK 可每次新建进程并用同一 Session ID 续接，运行请求 ID 不等于业务幂等键。网页显示、通知和审批须分别取得真实证据，后台成功不能记作网页已显示或用户已读。

## 故障与外部效果恢复

| 情况 | 处理 |
|---|---|
| 启动恢复 | 恢复本地记录和连接代次，核对原协议步骤、工具回执与接单台账，再开放新业务 |
| 租约失效 | 停止发起新外部动作；工具调用前检查执行资格；新代次不能消除旧外部效果 |
| 外部调用 | 发起前保存稳定操作键，返回后保存真实结果；未知则查询或交由用户核实，不盲目重复发信、付款或生产 |
| 接单状态未知 | 查询平台权威台账；不得根据本地缺记录释放名额 |
| 收信版本缺失 | 停止执行并报告；不以新草稿代替原处理流程 |
| 模型退出但缺 SDK 动作 | 只在有界轮次内提示补齐；遇未知副作用、原生交互或协议错误停止自动重放 |
| 授权或期限失效 | 停止对应新动作，保存已经发生的效果并返回明确状态 |

平台控制请求可幂等恢复，不等于外部工具具有同样保证。结果未知保留检查点及证据，不能以“模型说完成”推进实际合同或付款状态。
