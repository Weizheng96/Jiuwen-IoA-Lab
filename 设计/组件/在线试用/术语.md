# 在线试用 · 术语

只收本模块独有的术语；被两个以上模块使用的术语在[术语地图](../../术语.md)。

**试用席位**：部署容量内一个固定编号的隔离运行位置，同时只租给一个用户；容量与 profile 绑定在控制库中。
_Avoid_：槽位、实例、沙箱。代码：`seats.id`、`Store.capacity`

**轮次**：一个席位从准备到整轮销毁的一次数据生命周期；资源名、控制令牌、模型代理令牌与浏览器会话都绑定它，重连只续用原轮次；网页登录只作准入，轮次内业务使用席位专用身份。
_Avoid_：会话、批次、generation（只在 SDK 确认通道中指同一值）。代码：`epoch`

**试用资源布局**：绑定程序、控制库、镜像标签与每轮资源形状的固定标识；缺失或不符时保留原数据并拒绝接管。
_Avoid_：布局版本、schema 版本。代码：`RESOURCE_LAYOUT`（`epoch-ingress/1`）

**准入票据**：正式平台签发、60 秒内按 jti 一次有效、绑定用户与目标 origin 的 HMAC 凭据；网关消费后换成本 origin 会话。
_Avoid_：登录令牌、试用令牌。代码：`Coordinator.consume`

**原生交互 origin / 可信确认 origin**：网关的两个独立 HTTPS origin；前者透传原版九问页面，后者只提供 SDK 确认页与决定，二者 cookie 与会话互不通用。
_Avoid_：试用域名、确认域名。代码：`origin`、`confirm_origin`、`purpose`（native、confirm）

**入站转发器**：每轮独立容器，只把 loopback 两端口透明转发到本轮席位的 8080 与 8767，不作授权、不持凭据。
_Avoid_：反向代理、网关。代码：`ioalab_trial.ingress`、`Ingress`

**模型代理**：每轮独立容器，独占供应商密钥，只转发固定模型路径；席位只持其轮次令牌。
_Avoid_：模型网关、出口代理、sidecar。代码：`ioalab_trial.model_egress`、`ModelServer`

**有限调用桥**：预装技能调用本轮 SDK 的固定白名单通道，先把 operationId 写进参数文件再经控制端口发送。
_Avoid_：RPC 代理、模型桥。代码：`model_bridge`

**席位监督进程**：席位容器的 PID1，按受审计划运行四个角色进程并开放带 bearer 的控制端口。
_Avoid_：agent、守护进程。代码：`ioalab_trial.agent`

**隔离**：停止、销毁或运行状况未知时席位进入的终止状态；保留资源与数据，不再分配，须人工处置。
_Avoid_：故障、禁用、冻结。代码：`quarantined`

**整轮重置**：停止并完整核验后删除本轮三个容器、业务卷与内部网络，再以新轮次准备；不同于部署停机。
_Avoid_：清空、reset 聊天。代码：`DockerSandbox.wipe`、状态 `wiping`、`preparing`

**停机回执**：协调器退出时写下的配置摘要与“全部轮次资源已停止”结论，供部署生命周期放行。
_Avoid_：停止标记。代码：`shutdown.json`、`--verify-stopped`
