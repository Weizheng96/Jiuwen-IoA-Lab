# 在线试用 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/trial/ioalab_trial/`、`deploy/trial/` |
| 产物 | `src/trial/VERSION`（`ioalab-trial` wheel，`src/trial/pyproject.toml`）；席位镜像由 `deploy/trial/Dockerfile` 构建 |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `DockerSandbox`、`capacity`、`DOCKER_COMMAND`、`has_assistant_skill` | 包入口；`tools/verification/trial_engineering.py`、`trial_resources.py` 只经此导入，其他模块不导入本包 |

## 其他入口

| 文件 | 调用方式 | 说明 |
|---|---|---|
| `__main__.py` | `ioalab-trial` 脚本、`python -m ioalab_trial` | 部署单元启动；部署生命周期以 `--verify-stopped` 调用 |
| `agent.py` | 镜像 `ENTRYPOINT`（`-m ioalab_trial.agent`） | 席位 PID1 |
| `bootstrap.py`、`probe.py`、`sdk_entry.py` | `plan.json` 的 `-m` 命令 | setup、core、native、services 与服务 UID 子命令；health；assistant |
| `model_bridge.py` | 技能副本 `scripts/ioalab.py` 写入的唯一调用 | 预装技能的有限调用桥 |
| `ingress.py`、`model_egress.py` | 转发器与模型代理容器的 `-m` 命令 | |
| `deploy/trial/install_swarm_wheels.py` | 镜像构建步骤按文件路径运行 | |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 包入口 | `__init__.py` | 只再导出开发工具所需的公开名 |
| 控制器 | `__main__.py`、`stopped.py` | 配置与 profile 核对、单写者锁、启动网关、停机回执；只读停止核验 |
| 准入与租用 | `coordinator.py`、`store.py`、`profile.py` | 票据与会话、排队分配、租期与宽限、撤权、串行推进重置；控制库与容量、布局绑定 |
| 浏览器网关 | `gateway.py`、`trial.html` | 双 origin 分路、会话与 CSRF、确认页、HTTP 与 WS 透传、工作线程生命周期；试用页 |
| 席位资源 | `sandbox.py` | Docker 资源的创建、完整核验、控制端口调用、停止与删除 |
| 席位内监督 | `agent.py`、`processes.py`、`acceptance.py` | PID1 角色进程、控制端口、脱敏日志、所属进程 TERM；受审验收证据 |
| 席位内装配 | `bootstrap.py`、`probe.py`、`sdk_entry.py`、`model_bridge.py` | 经公开入口准备核心、九问与服务；就绪观察；SDK 常驻与受信确认；技能的有限调用桥 |
| 伴随容器 | `ingress.py`、`model_egress.py` | 固定入站转发；本轮模型代理 |
| 镜像与部署 | `deploy/trial/Dockerfile`、`plan.json`、`service-ids.json`、`install_swarm_wheels.py`、`config.example.json`、`README.md` | 受审镜像输入与构建、配置模板、部署说明 |

## 存储与迁移

数据位置见[接口](接口.md#独占数据与配置)。控制库以 `CREATE TABLE IF NOT EXISTS` 建表，首次写入 `deployment` 绑定与 1..capacity 席位，WAL 模式；已有库缺 `deployment` 表、列集合不同、绑定或席位编号不符时在建表前拒绝且不改字节。没有升级路径：布局或容量变化须先沿原部署完整清退全部轮次，再改用新的 `control_directory`。轮次业务卷随整轮重置整体删除，不迁移；`shutdown.json` 每次启动先删除，退出时经临时文件改名写入。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `Coordinator(clock=…)` | 测试推进时间，覆盖租期、宽限与票据期限 |
| `Coordinator.listeners` | 网关登记撤权回调，关闭该席位的活动 WS |
| `DockerSandbox.run` | 默认 `subprocess.run`；测试替换为 Docker 替身，断言命令顺序与核验先于动作 |
| `create_app(…,secure=False)` | 测试用非 `__Host-` cookie 名 |
| `validate_environment(profile,*,system,release)` | 测试注入平台与内核版本 |
| `Ingress(host,ports,dial)`、`ModelServer(…,listen,transport)` | 测试绑定临时端口、替换目标连接与供应商传输 |
| `model_bridge.arguments(path,*,root)`、`acceptance.validated_checks(root)`、`bootstrap.public_seed(service_ids,manifest)`、`bootstrap.ROOT`、`SERVICE_IDS` | 测试改根目录或传入固定清单 |
| `install_swarm_wheels.install(…,run=…)` | 测试替换 pip 调用 |
