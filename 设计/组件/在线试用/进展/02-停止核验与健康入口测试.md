# 02：停止核验与健康入口测试

**目标行为：** 部署生命周期依赖的 `ioalab-trial --verify-stopped`、停机回执 `shutdown.json` 与网关 `GET /health` 都有定向测试：只有全部原轮次资源核实退出时核验与回执才为真，布局或容量变化、锁被占、任一资源仍运行时失败；`/health` 只在未停机且每个席位都有 epoch 并处于 ready、leased 或 reconnect_grace 时返回 200。现状：`stopped.verify`、`__main__` 的回执写入与网关 `/health` 在 `tests/` 中均无引用，而 `deploy/lifecycle.py` 以前两者作为升级前的放行条件。

**阻塞于：** 无

**状态：** ready

**范围：** 在线试用（`stopped.py`、`__main__.py`、`gateway.py`）；需读本模块[接口](../接口.md#控制器与部署入口)与[浏览器网关](../接口.md#浏览器网关)。部署侧的读取方式见部署模块的进程与数据页，本票不改部署代码。

**定向测试：** trial_profiles、trial_gateway、trial_sandbox

- [ ] `--verify-stopped` 的成功、布局变化、容量变化、资源运行中与锁被占各有用例，且不修改控制库
- [ ] 停机成功与停止失败分别写出 `allEpochResourcesStopped` 为真与假的回执，`configSha256` 与配置字节一致
- [ ] `/health` 的就绪、准备中、隔离与停机中各有用例
- [ ] 接口页 `GET /health` 与 `--verify-stopped` 两行的测试列改为实际测试文件
