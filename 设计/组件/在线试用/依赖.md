# 在线试用 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../架构.md#模块表)的依赖图持有。导入全部发生在席位镜像内的进程（`sdk_entry`、`model_bridge`、`probe`、`bootstrap`）；主机上的协调器与网关只导入本模块与第三方包。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 共用运行时 | [作业、确认与观察](../客户端/共用运行时/接口.md#作业确认与观察)：`runtime.TrustedUserPort`、`TrustedUserServer` | `sdk_entry` 在宿主装配之外开放本轮受信确认服务 | 进程内 | trial_processes 以替身断言装配与确认服务的开闭顺序；确认通道由真实 SDK 对象测 |
| 共用运行时 | [本机生命周期与调用](../客户端/共用运行时/接口.md#本机生命周期与调用)：`runtime.ipc.LocalClient`、`runtime.__main__.require_configuration`、`runtime.installation.require_matching`；[配置](../客户端/共用运行时/接口.md#配置本机文件与公共值)：`runtime.config.RuntimeConfig` | 有限调用桥核对实例、安装与 bootId 后发送原操作；探针读取运行状态 | 进程内 | 替换 `LocalClient` 与配置读取的边界替身 |
| 共用运行时 | [用户确认](../客户端/共用运行时/接口/用户确认.md#用户确认)：包资源 `ioalab_sdk/runtime/web/user.html` | 网关在可信确认 origin 上复用 SDK 确认页，只改写固定传输路径 | 进程内 | 真实包资源 |
| 宿主适配 | [命令行](../客户端/宿主适配/接口.md#命令行)：包入口 `assembled(path)`、`Assembly.run()` | `sdk_entry` 经宿主的唯一常驻装配取得工具、宿主、两角色模块与常驻运行时，只在其外加受信确认服务 | 进程内 | trial_processes 替换 `assembled` |
| 官方服务 | 包入口 `ioalab_services`：[领域资产](../官方服务/接口.md#领域资产) `seed_manifest`；[部署协调命令](../官方服务/接口.md#部署协调命令) `prepare_deployment`、`authorize`、`administrator_session`、`serve`、`status`；[进程内入口](../官方服务/接口.md#进程内入口) `Deployment(path,*,services)` | 筛四个编程服务的公共种子；以显式服务 id 列表取得官方服务筛好目录并计算绑定的部署对象，再以服务 UID 准备与授权、运行服务方；探针读服务状态 | 进程内 | 传入固定清单；替换子进程与 `status` |
| web服务 | [进程与命令](../平台/web服务/接口.md#进程与命令)：`python -m ioalab init`、`serve`、`python -m ioalab.readiness`；[HTTP 入口](../平台/web服务/接口/HTTP入口.md#http-入口)：`/api/config`、`/api/auth/register`、`/api/session`、`/api/wallet`；[网页观察接口](../平台/web服务/接口/网页与部署接口.md#网页观察接口)：`/api/admin/login`、`/api/admin/orders`、`/api/admin/delegation-intents`、`/api/admin/components` | 席位内试用核心的初始化、运行与就绪；注册普通试用账号；准备时核空历史与样例余量 | 自有远端 | 假 HTTP 客户端与假子进程 |
| 身份中心 | [试用准入](../平台/身份中心/接口.md#试用准入)：准入票据 `{v,owner,aud,iat,exp,jti}`，HMAC-SHA256，共享 `admission_key` | 网关只接受正式平台签发、绑定 audience 的一次性准入 | 自有远端 | 测试用同一密钥自签票据 |

## 外部依赖

| 包 | 用途 | 版本来源 |
|---|---|---|
| `fastapi`、`uvicorn` | 网关应用与单进程服务 | `src/trial/pyproject.toml` 范围；镜像按 core 与 participant 锁约束 |
| `httpx` | 网关上游、控制端口、模型代理上游与探针 | 同上 |
| `websockets` | 网关 WS 透传与探针原生 WS 查询 | 同上 |
| `ioalab-sdk` | 上表 SDK 接口 | `pyproject.toml` 下限，发行时取同仓 wheel |
| `ioalab-jiuwen`、`ioalab-official`、`ioalab` | 宿主适配、官方服务与试用核心 | 未在 `pyproject.toml` 声明；由 `deploy/trial/Dockerfile` 装入镜像 |
| `jiuwenswarm`（原版九问） | 席位内原生网页、Gateway 与 Agent 进程；工作区、模型资源与技能目录的公开函数 | 原 manifest 与 requirements 中的 vendor wheel，由 `install_swarm_wheels.py` 核摘要后离线安装 |
| Docker Engine（本机 `unix:///var/run/docker.sock`） | 每轮容器、卷与网络 | 部署主机；不继承 `DOCKER_HOST` 或 context |
| 模型供应商 HTTPS API | 模型代理的唯一上游 | 部署配置 `provider_base_url` |
