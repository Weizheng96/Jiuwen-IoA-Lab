# 观测 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/observation/` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `ContractProjection`、`MessageViews`、`ServiceViews`、`AccountQueries`、`ActivityViews`、`OverviewQueries`、`WorkbenchQueries`、`event_view`、`migrate` | 唯一入口，只含导入与 `__all__` |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 合同 | `contracts.py` | 副本核验与保存、重建、合同与意向视图、收入与完成数；投影可重建、经验签与权限裁剪，`web/workbench.py` 与 `/api/orders` 读取 |
| 活动与事件 | `activity.py`、`events.py` | 受理帧到活动元数据；允许的动作、字段与结果词表及裁剪函数 |
| 查询 | `accounts.py`、`workbench.py`、`overview.py`、`messages.py`、`services.py` | 账号、公开人员、事件历史与回放（`AccountQueries`）、工作台（`WorkbenchQueries`）、管理员总览（`OverviewQueries`）等各页面所需的只读汇总；身份列表与合同双方名称经 `services.py` 的 `identity_rows`、`listed_name` 叠加注册中心服务目录；`OverviewQueries` 显式接收当前组件，`/api/admin/stats` 读取，`Platform` 不保留统计转发 |
| 存储定义 | `migrations.py` | `observation_contracts` 表 |

## 存储与迁移

表见[接口](接口.md#独占数据与配置)。迁移由平台基础统一入口持锁后事务内调用；升级只追加。展示副本可由 `rebuild()` 从各中心仍保存的原件重建，装配完成后调用一次。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `ContractProjection(clock=…)`、`MessageViews(clock=…)`、`ServiceViews(clock=…)` | 固定时间核到期、预留截止与连接在线 |
| `record_in` 返回布尔而不抛错 | 在业务事务内注入损坏或陈旧的卡，断言业务提交不受展示影响 |
| `event_view` 的词表 | 用未登记的动作与字段断言裁剪 |
