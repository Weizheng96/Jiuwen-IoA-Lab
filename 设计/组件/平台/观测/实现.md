# 观测 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/observation/` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `ContractProjection`、`MessageViews`、`ServiceViews`、`event_view` | 合同展示副本、消息视图、服务视图、事件裁剪 |
| `accounts.py` | `AccountQueries` | 账号、公开人员、事件历史与回放 |
| `activity.py` | `ActivityViews` | 受理活动的元数据 |
| `overview.py` | `OverviewQueries` | 管理员总览与组件状态 |
| `workbench.py` | `WorkbenchQueries` | 工作台汇总 |
| `migrations.py` | `migrate` | 表定义与追加升级，由平台基础统一迁移入口调用 |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 合同 | `contracts.py` | 副本核验与保存、重建、合同与意向视图、收入与完成数；投影可重建、经验签与权限裁剪，`web/workbench.py` 与 `/api/orders` 读取 |
| 活动与事件 | `activity.py`、`events.py` | 受理帧到活动元数据；允许的动作、字段与结果词表及裁剪函数 |
| 查询 | `accounts.py`、`workbench.py`、`overview.py`、`messages.py`、`services.py` | 各页面所需的只读汇总；`OverviewQueries` 显式接收当前组件，`/api/admin/stats` 读取，`Platform` 不保留统计转发 |
| 存储定义 | `migrations.py` | `observation_contracts` 与 `events` 两张表及事件索引 |

## 存储与迁移

表见[接口](接口.md#独占数据与配置)。迁移由平台基础统一入口持锁后事务内调用；升级只追加。展示副本可由 `rebuild()` 从各中心仍保存的原件重建，装配完成后调用一次。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `ContractProjection(clock=…)`、`MessageViews(clock=…)`、`ServiceViews(clock=…)` | 固定时间核到期、预留截止与连接在线 |
| `record_in` 返回布尔而不抛错 | 在业务事务内注入损坏或陈旧的卡，断言业务提交不受展示影响 |
| `event_view` 的词表 | 用未登记的动作与字段断言裁剪 |
