# 15：种子装配经身份中心入口判断预置账号并授予管理员角色

**目标行为：** web服务 的 `seed/accounts.py` 不直接读写身份中心的表；预置账号是否存在、取账号 ID 与为 ISC_001 授予 admin 角色都经身份中心入口的公开接口完成，行为（幂等、只补不改、ISC_001 保留 admin）不变。现状：`_ensure` 直接 `SELECT id FROM users WHERE username=?`，`ensure_accounts` 直接 `INSERT OR IGNORE INTO user_roles VALUES (?, 'admin')`。

**阻塞于：** 无

**状态：** ready

**范围：** web服务 与 身份中心。方案：`_ensure` 改用 `IdentityDirectory.account(username)`；身份中心增加事务内 `Auth.grant_role_in(conn,user_id,role)` 一类接口（只补不删，不记操作者的种子路径另行说明，或复用 `set_roles` 的变更记录），种子调用它。需读[身份中心接口](../身份中心/接口.md#网页角色与审计)与 web服务 实现页的种子分区。

**定向测试：** auth（test_internal_accounts_seeded_idempotent）、deployment、seed

- [ ] `seed/` 代码中不再出现 `users`、`user_roles` 表名
- [ ] 种子重复执行幂等，ISC_001 保留 admin
- [ ] 身份中心接口表与 web服务 实现页同步
