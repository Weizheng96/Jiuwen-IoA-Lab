# 01：付款操作记录表归入所属模块

**目标行为：** `delegation_payment_operations` 的表定义与读写属于同一模块；web服务 的应用用例只经该模块接口读写付款操作的幂等记录，不再直接执行其 SQL。现状是表由 `payments/migrations.py` 定义，`operations.py` 的 `PaymentOperations` 直接 SELECT 与 INSERT。

**阻塞于：** 无

**状态：** ready

**范围：** 支付中心与 web服务。两个可选方案：支付中心暴露 `operation_in` 与 `record_operation_in`；或把操作幂等记录迁到平台基础的通用操作表并由范围操作、发布操作共用。需读[支付中心接口](../支付中心/接口.md)、[实现](../支付中心/实现.md)与[架构模块表](../../../架构.md#模块表)。

**定向测试：** payment_atomicity、payment_rejection、protocol_operations、core_ownership
