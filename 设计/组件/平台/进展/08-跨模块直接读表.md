# 08：业务模块经接口取账号与归属，不直接读他人的表

**目标行为：** 除观测的只读汇总外，业务模块不直接查询其他模块的表。现状：消息中心的配额统计 JOIN `agents` 按账号计数，收信接口目录与白名单解析直接查 `users`；这些都是身份中心的表。观测直查各中心表是既定取舍，见[决策](../决策/0002-观测只读直查各中心表.md)，不在本票范围。

**阻塞于：** 无

**状态：** ready

**范围：** 消息中心与身份中心。方案：身份中心提供按用户名定位账号、按账号列出智能体的只读接口；消息中心的配额改为先取收件与发信账号的智能体列表再计数，或在投递记录上冗余账号 ID。与[服务目录事实归属](03-服务目录事实归属.md)一并核对注册中心对 `agents` 的读写。需读[消息中心依赖](../消息中心/依赖.md)与[身份中心接口](../身份中心/接口.md#归属查询)。

**定向测试：** message_boundaries、agent_delivery、inbox_rules、account_views

- [ ] 消息中心代码中不再出现 `agents`、`users` 表名
- [ ] 配额、目录可见性与白名单解析的行为不变
- [ ] 两个模块的接口与依赖页同步
