# 12：官方预置账号显示名与登录名一致

**目标行为：** 所有官方预置账号的账号显示名与登录账号名完全一致，例如 `ISP_001` 显示为 `ISP_001`，`ISC_001` 显示为 `ISC_001`；不再显示“内部服务方 · 领域拼接”或“内部用户001”等自动生成的描述性名称。

**阻塞于：** 无

**状态：** ready

**范围：** 平台身份中心[账号注册与登录](../身份中心/接口.md#账号注册与登录)、[实现](../身份中心/实现.md)；平台账号初始化 `src/platform/ioalab/seed/accounts.py`；[观测接口](../观测/接口.md)的账号目录读模型、[网页UI接口](../网页UI/接口.md)的账号显示；依赖官方服务[预置服务账号归属](../../官方服务/接口/预置服务与启动器.md#预置服务账号归属)。

**定向测试：** seed、seed_manifest、account_views、frontend、auth；实施时补官方预置账号显示名、已有账号迁移与普通账号不受影响的针对性验证。

## 已定需求与初始方案

本票只登记待实施需求，尚未修改现行接口或业务代码。实施前按 design 将预置账号命名规则写入唯一归属接口页并升版，再开发。

- 规则覆盖所有官方预置账号，包括现行 `ISP_*`、`ISC_*`，以及具有账号显示名字段的预置管理账号；以实际预置清单识别，不仅凭用户填写的账号名前缀判定，避免误改普通用户。
- 新建预置账号时直接以登录账号名作为 `display_name`，保留原领域分类与服务配置，不再把领域标签拼进账号显示名。
- 既有官方预置账号通过明确的迁移路径修正账号显示名，重复执行保持幂等；保留稳定账号 ID、登录名、密码、角色、余额、原身份绑定、合同、付款、消息与会话。
- 个人助手和服务方智能体的 `name` 是独立字段，本票只统一账号显示名，不批量重命名智能体；普通用户自行填写的显示名保持不变。
- 账号目录、个人助手目录、工作台和管理员账号列表均读取一致的账号显示名，不在页面单独替换文案掩盖原数据不一致。

## 验收项

- [ ] 新初始化的所有官方预置账号均满足 `display_name == username`，覆盖 `ISP_001`、多个 `ISC_*` 及适用的预置管理账号
- [ ] 已有官方预置账号的显示名可明确迁移，重复初始化或升级不恢复旧描述名、不重复创建账号、不触发再次赠币
- [ ] 普通用户、非预置账号及其自定义显示名不受影响；账号名类似预置前缀的普通用户也不会被误改
- [ ] 稳定账号 ID、凭据、权限、余额和全部业务数据保持；助手及服务智能体名称、身份和归属不变
- [ ] 各网页入口显示一致，账号显示名与智能体名称仍分别来自各自字段
- [ ] 定向测试通过，并按工程进展的统一验收基线在新 Linux 部署上核对新建与迁移结果
