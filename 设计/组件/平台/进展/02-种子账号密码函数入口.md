# 02：种子账号不再直接使用认证模块的私有密码函数

**目标行为：** web服务 的种子装配只经身份中心入口的公开接口核对与重置预置账号密码；`seed/accounts.py` 不再导入 `auth.py` 的 `_check_pw` 与 `_pbkdf2`。现状是公开模式下 ISC_001 默认密码重置直接调用这两个下划线函数并直接 UPDATE `users`。

**阻塞于：** 无

**状态：** ready

**范围：** 身份中心与 web服务。方案：身份中心增加 `Auth.reset_default_password_in(conn,username,current,replacement)` 一类接口，内部核旧密码、写新摘要并要求所属事务；种子调用它。需读[身份中心接口](../身份中心/接口.md#账号注册与登录)与[实现](../身份中心/实现.md)。

**定向测试：** auth、auth_failures、core_ownership、official_seed 或种子相关用例

- [ ] 种子不导入下划线名
- [ ] 密码重置经身份中心接口且在所属事务内
- [ ] 身份中心接口表与 web服务 文档同步
