# 身份中心

## 目的与范围

提供账号认证、智能体身份与公钥归属，回答“谁在操作、可以代表哪个智能体”。不创建个人助手实例，不保管参与方私钥，不决定外部消息是否获得业务授权，不发放虚拟币。调用方是 web服务 的账号用例与路由、支付中心（付款方归属）、注册中心（部署发布身份判断）与消息中心（连接首帧认证）；参与方经 HTTP 入口到达。

## 独占数据与配置

| 数据或配置 | 说明 | 存储 |
|---|---|---|
| 账号 | 稳定账号 ID、唯一用户名、密码摘要、用途标签 kind（isp、isc、external、virtual）、显示名、最近登录 | `users` |
| 网页角色 | admin 与 auditor；变更记录操作者、目标与前后集合 | `user_roles`、`identity_role_changes` |
| 智能体 | 每账号一个逻辑个人助手与多个服务；稳定 `agentId`、角色、状态与绑定元数据（协议地址、各用途公钥） | `agents` |
| 公钥归属 | 任一用途公钥的两种指纹只归一个账号 | `identity_keys` |
| 绑定操作 | 挑战、到期、证明摘要与原结果，按账号与 operationId 幂等 | `identity_enrollments` |
| 账号操作 | 注册与登录的参数摘要、凭据摘要与原结果，按用户名、种类与 operationId 幂等 | `account_operations` |
| 连接票据 | 一次性短期票据摘要与获准智能体集合 | `connection_tickets` |
| 邀请码 | 邀请制注册的一次性码 | `invites` |
| 配置 | 服务端密钥、管理员凭据、注册模式、认证失败预算与窗口、注册流量预算、本机豁免地址、票据有效期、公共地址、试用入口与准入密钥；只读平台配置 | [平台配置](../../../工程/平台配置.md) |

邮箱形式用户名仅用于定位账号，不证明邮箱归属。账号、智能体、服务、交互与合同的所属检查在服务端执行。

## 接口

事务内接口以 `_in(conn, …)` 命名；账号创建、登录与赠币由 web服务 的账号用例在同一短事务协调，见[跨模块决策](../../../决策/0001-应用短事务协调接单与付款.md)。

### 账号注册与登录

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `Auth.prepare_registration(username,password,*,kind,display_name,note,invite,ip)` | 事务外校验注册输入 | 用户名 3—128 位字母数字与 `_ . @ + -`；external 受注册模式、密码长度（公开 8、开发 6）、邀请码与注册流量预算约束 | 占用、格式、关闭注册、邀请码无效 → CARD_INVALID；流量满 rate_limited 429 | auth、auth_failures |
| `Auth.register_in(conn,prepared)` | 事务内创建账号并消费邀请码 | 公开账号字段 | 并发占用或邀请码已用 CARD_INVALID | auth、account_rewards |
| `Auth.authenticate(username,password,*,ip,policy)`、`login_in(conn,verified)` | 密码核验与事务内登录 | 返回账号行；登录更新最近登录时间 | 未知账号与错误密码统一 401 authenticate；提交时密码已变 401 要求重新登录 | auth、auth_failures、authentication_recovery |
| `AccountSessions.operation(value)`、`fingerprint(params)`、`restore(username,kind,operation,fingerprint,conn)`、`save(conn,…,audience,*,credits)` | 注册与登录的操作幂等 | 同 operation 同参数恢复原账号、原令牌与原赠币结果；浏览器令牌 7 天、SDK 30 天 | 同键异参数 id_conflict 409；密码已变 401 | authentication_recovery、account_rewards |
| `Auth.token(subject,ttl,*,expires_at)`、`bearer(subject,*,restricted)`、`verify(token)` | HMAC 会话令牌 | SDK 主体为 `assistant:<账号>`；`POST /api/v1/token/refresh` 以有效 Bearer 换新受限 Bearer，不构成登录 | 过期或签名错返回 None → 401 | auth、account_enrollment |
| `Auth.new_invite()`、`next_virtual_name()`、`public_user(row)` | 邀请码、管理员临时账号命名、公开字段 | `POST /api/admin/invite`、`POST /api/admin/users` | — | auth、admin_api |

### 认证失败与流量限制

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `RateLimit.check(key,*,n,per)`、`check_failure(key,verify,*,n,per)` | 按来源 IP 的失败预算与流量预算 | 只计已知失败；成功不占也不清；过期命中不消费新窗口 | 满额 rate_limited 429，recovery=wait_rate_limit | auth_failures |
| `Auth.local_frequency_exempt(ip,policy)` | 确证本机来源免除频率预算 | 仅 127.0.0.1、::1 与显式配置的单个本机地址；不免密码、身份与业务权限 | — | auth_failures、configuration_web |
| `Auth.admin_login(password,*,username,ip)` | 部署管理登录 | 凭据取平台配置；`POST /api/admin/login` 返回 admin 令牌 | 口令错 401；按 IP 独立预算 | auth_failures、configuration_web |
| `Auth.configuration_csrf(token)` | 配置写入绑定浏览器会话 | HMAC 摘要 | — | configuration_web |

来源 IP 由 web服务 的 `source.client_ip` 解析：核心只信 socket peer；仅 peer 为受信代理时读取单值 `X-IOALAB-Client-IP`，缺失或非法拒绝，不回退成本机。

### 网页角色与审计

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `Auth.is_admin(subject)`、`roles(uid)`、`is_auditor(subject)` | 网页管理与正文审计权限判断 | admin 令牌或 admin 角色；auditor 须同时有 admin | 受限 SDK 主体一律否 | observation_views |
| `Auth.set_roles(operator,target,roles,expected)` | 原子替换目标账号的角色集合 | `PUT /api/admin/users/{userId}/roles`；相同结果不重复修改；记录变更 | 非管理员 403；目标不存在 404；当前集合与 expected 不符 revision_conflict 409；auditor 无 admin invalid_input | publication_authorizations、arbitration_review |

### 身份绑定

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `EnrollmentRegistry.issue(owner,body)` | 签发绑定挑战 | `POST /api/v1/identity/challenge`，字段 operationId、role、agentId；默认 120 秒；助手 agentId 为 URN，服务为 `svc-<uuid>` 并派生平台协议地址 | 同 operation 异参数 id_conflict 409；已绑定返回原结果；过期未绑定 expired 409 recovery=new_operation | account_enrollment |
| `EnrollmentRegistry.bind_in(conn,owner,body)` | 事务内核验证明并保存绑定 | 助手需 agent、user、payer 三把公钥，服务需 agent、payee；验签 proof、新鲜度与挑战，原子写 `agents` 与公钥归属 | 平台或 owner 不符 invalid_input；私钥字段拒绝；挑战不符 403；公钥属他人或第二个逻辑助手 id_conflict 409；同证明恢复原结果 | account_enrollment、account_rewards |
| `EnrollmentRegistry.claim_in(conn,owner,keys)`、`protocol(role,actor)`、`public_keys(actor)` | 公钥归属登记、协议地址派生、公开 JWKS | `GET /a2a/agents/{agentId}/.well-known/jwks.json` 由 web服务 公开 | 公钥已属他人 409；未绑定 not_ready | account_enrollment |

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|

| `IdentityDirectory.saved_keys()`、`list_owned(owner)`、`services_owned(owner)`、`search_actor(owner)` | 启动时回填公钥归属、本账号智能体与服务列表、发现审计主体 | 只读 | — | account_views |

## 不变量

| 规则 | 说明 |
|---|---|
| 操作幂等 | 注册与登录使用稳定 operationId，绑定规范化用户名、种类与参数摘要；相同操作返回原结果，同键异参数拒绝；成功重传不消耗新登录次数也不重新发币；密码已变后旧操作不能恢复认证权限 |
| 同一事务 | 账号创建或登录事实与登录赠币在 web服务 账号用例的同一短事务提交；服务器不保存明文密码 |
| 令牌 | 浏览器登录态 7 天、SDK Bearer 30 天；有效 Bearer 可换新受限 Bearer，不形成登录或赠币；过期、撤销或无法认证要求重新登录，不用密码循环探测 |
| 失败预算 | 公开模式下普通登录、管理登录、注册按真实来源 IP 分别计预算；未知账号与错误密码均计失败；成功不占也不清；满额后正确凭据也须等待；调限不清空已有失败 |
| 本机豁免 | 仅确证的回环地址与显式配置的单个本机地址免频率预算；受信代理 peer 与本机豁免地址不得重叠 |
| 统一拒绝 | 未知账号或错误密码统一 401 authenticate；字段结构错误 400 invalid_input；预算满 429 rate_limited |
| 账号与默认身份 | 预注册幂等创建领域 ISP 账号与配置数量的 ISC 账号；ISC_001 保留 admin 角色；部署管理登录取平台配置，不覆盖已配置凭据；同一账号可访问获准的三种视图，浏览器角色不扩大收信处理器权限 |
| 角色与审计 | admin 允许全景与角色管理；auditor 另行授予且须同时有 admin；受限 SDK 凭据不取得两者；正文审计每次记录审计人、消息与时间，不复制正文到行为日志；仲裁复核只读本案证据，本账号智能体为当事方时不得终局 |
| 绑定 | 同 operationId 依次申请挑战与提交证明；证明签署完整绑定对象摘要；原账号、智能体与公钥必须一致，不同账号不能占用同一身份或付款公钥；每账号最多一个逻辑个人助手；新设备不能凭账号重置原密钥；已成功证明在挑战过期后仍可恢复 |
| 公共地址 | 由平台公共基址与 agentId 组成，与 IP、连接和九问会话无关；基址初始化后锁定，改址是显式迁移且不重写旧签名对象 |
| 多设备与迁移 | 每智能体只允许一个有效执行者；换设备迁移身份、业务状态与会话资源；密钥迁移保留旧原件的验证与履约能力，无法安全接管的业务先结束或人工核实 |
| 支付双方 | 按原协议身份返回稳定智能体、账号归属与 AP2 公钥；payer 公钥也用于退款收款，payee 公钥也用于解除退款授权，不为退款换钥；合同 client、付款人与收款人归属分别检查；停用不抹除历史验签依据 |
| JWKS | 公共 JWKS 经平台身份元数据地址公示 A2C 与 AP2 公钥，不依赖服务公示或业务执行，不含私钥；SDK 只把对方稳定 ID 解析到已配置平台的 JWKS 地址 |
| 浏览器凭据 | HTTPS 用 Secure、HttpOnly、Path=/、无 Domain 的 `__Host-` 会话 cookie，本机 HTTP 用专属非 Secure 名称，不双读；检查 Origin 与 CSRF；网页只读订阅不能领取或确认业务消息 |
| 连接票据 | 只由 SDK Bearer 入口签发，只授予建立连接资格，不授予业务执行或接单权限；发信身份由连接内已认证的智能体上下文确定，正文不能自报发送者 |
| 停用与恢复 | 停用拒绝新的认证、投递与执行授权，已发生业务按证据保留；登录响应丢失用原 operationId 查询；挑战过期或签名不符拒绝绑定，不凭同名或旧登录推定密钥所有权；凭据续用与 WS 重连不重新密码登录；本地状态丢失须迁移，不凭平台观察副本重建私钥 |
