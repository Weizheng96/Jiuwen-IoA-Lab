# 身份中心 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/identity/` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `IdentityDirectory`、`Auth`、`RateLimit`、`KINDS`、`INTERNAL`、`USERNAME`、`EnrollmentRegistry`、`AccountSessions`、`thumbprint`、`public_key`、`fingerprints`、`trial`（`entry`、`admission_origin`）、`migrate`、`release_service_listings` | 唯一入口，只含导入与 `__all__`；`auth.py` 的下划线密码函数不导出，种子装配经 `Auth.reset_default_password_in`、`normalize_preset_display_name_in` 与 `grant_admin_in` |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 认证 | `auth.py` | `RateLimit` 失败与流量预算；`Auth` 注册准备与事务内创建、密码核验与事务内登录、HMAC 令牌、管理登录、角色集合、邀请码 |
| 设备会话 | `devices.py` | Auth.devices 暴露设备访问/续期、轮换恢复、列表和撤销；不存凭据原文 |
| 绑定 | `enrollment.py` | 挑战签发、证明核验、公钥归属登记、协议地址派生、公开 JWKS |
| 归属 | `directory.py` | `IdentityDirectory`：智能体归属、付款方与服务方身份、部署发布资格、账号定位、连接票据签发与消费 |
| 操作记录 | `sessions.py` | 注册与登录的参数摘要、凭据摘要、结果渲染与令牌签发 |
| 工具与准入 | `keys.py`、`trial.py` | 公钥指纹与校验；试用准入链接与 Origin 独立性 |
| 存储定义 | `migrations.py` | 本模块全部表；`release_service_listings` 把旧库服务目录列移交注册中心 |

## 存储与迁移

表见[接口](接口.md#独占数据与配置)。迁移由平台基础统一入口持锁后事务内调用；升级只追加，唯一例外是服务目录列移交：旧库 `agents.definition` 由注册中心迁移经 `release_service_listings` 取走后删除，`listed` 状态改回 `registered`。启动时 web服务 用 `saved_keys()` 回填 `identity_keys` 归属。账号显示名迁移复用 `ioalab --config <原平台JSON> init` 或正常启动时的种子初始化；已有部署先正常停止取得数据所有权，再用新发行初始化。`normalize_preset_display_name_in` 只写 `users.display_name`，重复执行不创建账号、不登录或赠币，不更新智能体 name。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `IdentityDirectory(clock=…)`、`trial.entry(clock=…)` | 固定时间核票据与准入到期 |
| `Auth.authenticate(policy=…)` | 传入配置快照，避免同一操作混用两份修订 |
| `RateLimit.check_failure(verify)` | 注入核验函数，测试失败计数与并发原子性 |
| `EnrollmentRegistry(existing_keys=…)` | 启动回填，测试公钥冲突 |

设备会话迁移只新增 `device_sessions` 表及 owner/device 索引，连接票据表追加 session 列；旧账号、身份与业务表不重建。旧无会话绑定票据不能建立新的业务连接。
