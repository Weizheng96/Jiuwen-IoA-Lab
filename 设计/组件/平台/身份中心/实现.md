# 身份中心 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/identity/` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `IdentityDirectory` | 归属查询、Bearer 解析与连接票据 |
| `auth.py` | `Auth`、`RateLimit`、`KINDS`、`INTERNAL`、`USERNAME` | 注册、登录、令牌、角色与失败预算 |
| `enrollment.py` | `EnrollmentRegistry` | 公钥绑定 |
| `sessions.py` | `AccountSessions` | 账号操作幂等记录 |
| `keys.py` | `thumbprint`、`public_key`、`fingerprints` | 公钥工具 |
| `trial.py` | `entry`、`admission_origin` | 试用准入链接 |
| `migrations.py` | `migrate`、`release_service_listings` | 表定义与追加升级，由平台基础统一迁移入口调用；后者把旧库 `agents.definition` 的服务目录事实一次性交给注册中心迁移并删除该列 |

入口按职责分成小文件，各由 web服务 装配时直接导入；`auth.py` 的下划线密码函数不是入口，种子装配经 `Auth.reset_default_password_in` 重置默认密码。

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 认证 | `auth.py` | `RateLimit` 失败与流量预算；`Auth` 注册准备与事务内创建、密码核验与事务内登录、HMAC 令牌、管理登录、角色集合、邀请码 |
| 绑定 | `enrollment.py` | 挑战签发、证明核验、公钥归属登记、协议地址派生、公开 JWKS |
| 归属 | `__init__.py` | 智能体归属、付款方与服务方身份、部署发布资格、连接票据签发与消费 |
| 操作记录 | `sessions.py` | 注册与登录的参数摘要、凭据摘要、结果渲染与令牌签发 |
| 工具与准入 | `keys.py`、`trial.py` | 公钥指纹与校验；试用准入链接与 Origin 独立性 |
| 存储定义 | `migrations.py` | 本模块全部表 |

## 存储与迁移

表见[接口](接口.md#独占数据与配置)。迁移由平台基础统一入口持锁后事务内调用；升级只追加，唯一例外是服务目录列移交：旧库 `agents.definition` 由注册中心迁移经 `release_service_listings` 取走后删除，`listed` 状态改回 `registered`。启动时 web服务 用 `saved_keys()` 回填 `identity_keys` 归属。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `IdentityDirectory(clock=…)`、`trial.entry(clock=…)` | 固定时间核票据与准入到期 |
| `Auth.authenticate(policy=…)` | 传入配置快照，避免同一操作混用两份修订 |
| `RateLimit.check_failure(verify)` | 注入核验函数，测试失败计数与并发原子性 |
| `EnrollmentRegistry(existing_keys=…)` | 启动回填，测试公钥冲突 |
