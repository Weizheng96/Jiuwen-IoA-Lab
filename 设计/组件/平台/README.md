# 平台

模块化单体 `src/platform/ioalab/`：五个公共中心、观测、web服务、网页UI 与平台基础。只保管机构密钥，不运行个人助手或服务生产；参与方经 HTTPS 与 WSS 到达。子模块各有接口、依赖、实现三页；本组共用[术语](术语.md)、[决策](决策/)与[进展](进展/)。
