# web服务 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/web/` 的 Python 文件，以及 `src/platform/ioalab/` 下的 `app.py`、`operations.py`、`cli.py`、`bootstrap.py`、`readiness.py`、`seed/`、`__init__.py`、`__main__.py` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包，命令 `ioalab`） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `src/platform/ioalab/cli.py` | `main` | `ioalab` 命令 |
| `src/platform/ioalab/app.py` | `Platform` | 装配与生命周期 |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 装配 | `app.py`（包根）、`bootstrap.py` | 启动路径 `__main__.py` → `app.py` → 各模块；`Platform.ensure_seeded` 与 `service_definitions` 是路由取种子的唯一入口，`web/` 不导入 `seed`、`storage`、`files`；取得数据所有权、迁移、构造并相互注入各模块、原协议路由分发、回环传输、维护与仲裁循环、初始化时的进程内服务；核心只装配公共服务，不执行私人助手或服务生产 |
| 应用用例 | `operations.py` | 账号、账本、发现、付款、市场、服务发布六组跨中心用例（`AccountOperations`、`LedgerOperations`、`DiscoveryOperations`、`PaymentOperations`、`MarketOperations`、`ServiceOperations`），Web 与种子初始化调用其明确入口；参与方控制帧分派器 `ControlOperations` 与种类登记 `Control`，装配时由 `register_platform` 登记各中心种类 |
| 参与方路由 | `web/api_v1.py`、`web/agents.py` | SDK 的 HTTP 入口、恢复查询、范围路由、参与方 WebSocket 的认证、收发与投递循环 |
| 浏览器路由 | `web/app.py`、`web/frontend.py`、`web/workbench.py`、`web/arbitrations.py`、`web/configuration.py`、`web/trial.py`、`web/identity.py` | 会话与管理员接口、页面入口、工作台、仲裁复核、配置、试用准入、公开身份与原协议模板读取 |
| 入口辅助 | `web/cookies.py`、`web/source.py` | 会话 cookie 名称与属性、来源解析 |
| 命令与种子 | `cli.py`、`readiness.py`、`seed/` | 命令行、就绪探针、内部账号与分类树种子；`cli` 自检把 `seed.load_domains` 注入 `Settings.check`；种子经身份中心 `account` 判断预置账号是否已存在、`reset_default_password_in` 重置 ISC_001 默认密码、`grant_admin_in` 补 admin 角色，经注册中心 `listings()` 取分类成员，不直接读写身份与注册表；`reset`（可选 `--keep-keys`）与 `backup` 先取得 DataOwner 排他锁，整理与检查不执行真实数据重置 |

## 存储与迁移

本模块不定义表。`Platform` 在持有数据目录所有权后调用平台基础的统一迁移入口；失败则关闭并释放所有权。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `Platform._worker`、`_owned` | 所有阻塞工作登记为核心拥有的任务；测试取消调用方后断言实际写入仍完成 |
| 应用用例的 `prepare` 与 `apply_in` 分界 | 在准备后、提交前注入故障，断言台账、账本与原回执整体提交或回滚 |
| `ControlOperations.register` 与按调用解析的适配器 | 测试登记临时控制种类核准备、提交与查询路由；替换所属模块的 `prepare`、`apply_in` 即在分派链路上生效 |
| `LoopbackTransport` | 进程内调用公共地址时改走本机监听地址，测试不依赖域名解析 |
| `Settings` 对象 | 测试直接构造配置，不经私有文件 |
