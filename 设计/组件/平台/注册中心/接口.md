# 注册中心

## 目的与范围

保存可验证的签名服务发布原件与模板索引，维护 A2X 分类目录并提供服务发现，管理部署发布授权。不拟卡、不承诺接单，不签认模板（归委托中心），不管理助手通信接口目录（归消息中心）。调用方是 web服务 的服务用例与路由、委托中心与支付中心（分类归属）、消息中心（公示校验）；参与方经 HTTP 入口到达。索引可重建，签名原件不因索引刷新改写；调用者仍须用 A2C SDK 验签，不能只相信搜索列表的说明或价格摘要。

## 独占数据与配置

| 数据或配置 | 说明 | 存储 |
|---|---|---|
| 签名发布原件 | 每服务按修订保存的声明、证明、已签认模板原件与声明摘要 | `registry_publications` |
| 发布操作 | 按服务与 operationId 的参数摘要与原回执 | `registry_publication_operations` |
| 索引投影 | 每服务最近一次写入 A2X 的修订与实际叶类 | `registry_projection` |
| 服务目录 | 已登记服务的公开名称、说明、标签、协议地址与实际叶类；有行即 listed，随索引投影在同一事务写入 | `registry_services` |
| 部署发布授权 | 每服务一份：修订、条款摘要、模板寿命上限、启用、操作者；配置操作幂等记录 | `registry_publication_authorizations`、`registry_authorization_operations` |
| A2X 数据集 | 服务卡索引、分类树与归属文件，可重建；按领域确定性生成，零模型 | `data/a2x/`（`taxonomy.json`、`class.json`、`assignments.json`、`build_config.json`） |
| 配置 | 发现与分类模型、嵌入模型、A2X 凭据目录；分类与账号种子由部署清单显式传入 | [平台配置](../平台基础/接口/平台配置.md)、`runtime.seed_file` |

服务目录事实只由本模块持有；身份中心的 `agents` 只保留身份、显示名、停用状态与绑定元数据。

## 接口

### 分类目录与预览

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `Discovery.categories()`、`taxonomy_state()` | 实际 A2X 叶类列表与树状态 | `GET /api/v1/services/categories`、`GET /api/public/categories`；叶类含 id、名称、说明、决策规则、路径、是否兜底 | 无树返回空列表 | category_preview、seed |
| `CategoryPreview.preview(body)` | 用公开名称、说明、标签与可选分类取得分类路径与目录摘要 | `POST /api/v1/services/category-preview`；显式分类先核实际叶类；自动匹配只能从非兜底叶类选一项并返回依据；无模型、说明不足、含糊或无效返回 choose_category 与实际分类列表 | 字段越界 invalid_input；指定不存在叶类 category_required 409，recovery=choose_category | category_preview |
| `DiscoveryModels.classify_category(service,categories)`、`embed(texts)` | 发现模型的分类匹配与嵌入 | 未配置返回 None 或抛错 | 网络或格式错误由调用方降级为待选择 | category_preview |
| `taxonomy.build(categories,members,tdir)`、`assign(tdir,service_id,category_id)`、`remove`、`categories(tdir)` | 分类树文件的确定性读写 | 树深 1，根到领域叶类到服务；不存在的叶类退到 `cat_misc` | 环状树 ValueError | category_preview、seed |

### 签名发布

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `ServicePublications.prepare(owner,actor,body)` | 事务外校验声明、证明、模板引用与修订 | `POST /api/v1/services/{agentId}/publications`，body 为 operationId、declaration、proof、templates 与可选 authorizationRevision；声明 `ioalab.service/1` 绑定 agentId、协议地址、修订、名称、说明、标签、分类、模板摘要；签名 slot `ioa-service`，kid 必需 | 非 service 身份 403；地址或公钥与绑定不符 403；修订非 previous+1 revision_conflict 409；分类无效 category_required 409；超 1 MiB 或 16 份模板 invalid_input | service_publication |
| `ServicePublications.commit_in(conn,owner,prepared,templates)` | 事务内复核绑定公钥、新鲜度、分类、修订与已签认模板期限后保存原件与回执 | 返回 agentId、acceptedRevision、declarationDigest、templateDigests、templates、acceptedAt | 绑定公钥已变 403；模板与声明不符 id_conflict 409；模板已过期 expired 409；同 operation 异参数 id_conflict 409，同参数恢复原回执 | service_publication、publication_authorizations |
| `ServicePublications.restore(owner,actor,body)`、`operation(owner,actor,operationId)` | 原发布操作恢复与查询 | 原回执 | 无结果 not_ready 404，recovery=retry_original | service_publication |
| `ServicePublications.status(owner,actor)` | 所属方查看发布、索引、模板与授权状态 | `GET /api/v1/services/{agentId}/status`：published、revision、publishedTermsDigest、templateExpiresAt、indexedRevision、indexReady、categoryId、indexedCategoryId、templateReady、activeTemplateDigests、publicationAuthorization | 非本账号服务 403 | service_publication、official_deployment |
| `ServicePublications.public(actor)`、`card(actor)`、`templates(actor,template_digest=None)` | 公开声明与证明、原版 A2C Agent Card、当前有效或指定摘要的历史模板 | web服务 在 `/a2a/agents/{agentId}/.well-known/agent-card.json`、`/publication` 与 `template.get` 公开 | 未发布 not_ready 409；摘要不存在 404 | service_publication、resident_delegation |
| `ServicePublications.index_document(actor)`、`indexed_in(conn,actor,declaration,actual_category)` | 生成 A2X 索引文档，记录投影并写服务目录 | 索引字段只含名称、说明、地址、修订、标签与模板摘要、成约方式、有效期、拟卡费 | 当前修订或分类已变 revision_conflict 409 | service_publication |
| `RegistryView.category_in(conn,provider)` | 已登记服务的实际分类 | 按协议地址查服务目录，经身份中心核未停用；供委托中心与支付中心核分类授权 | 未登记、已停用或无分类 not_ready 409 | delegation_admission、delegation_scopes、domain_migrations |
| `RegistryView.listings()` | 全部已登记服务 | 按服务 ID 返回公开名称、协议地址与实际叶类；种子建树取分类成员 | — | service_publication、seed |

## 不变量

| 规则 | 说明 |
|---|---|
| 原件权威 | 签名发布原件是权威，A2X 是可重建投影；索引失败不撤销已发布原件，恢复旧操作只重建当前最新投影，不覆盖后续修订；索引重建不重签模板、不改有效期、不建第二份身份 |
| 身份与地址 | 仅所属 service 身份可发布；声明地址与签名公钥必须等于当前绑定；平台不按用户输入抓取公网地址，不要求服务方有公网 IP 或入站端口 |
| 修订 | 首次为 1、严格递增；同一发布操作参数不可变；回执是原修订的历史事实，当前状态另查 |
| 模板 | 模板签认归委托中心；普通服务只用待批准或提案，付款提供者必须是本平台；旧修订与模板按摘要保留，已成立合同继续引用原件；到期模板不用于新签约 |
| 分类 | 本次发布须有有效叶类；自动匹配不能可靠确定时返回可选分类请用户选择，不回落到兜底；显式分类也先核实际叶类；分类授权使用注册中心实际归属，不采用来信自报 |
| 预览 | 预览只接收公开名称、说明、标签与可选分类，不登记、不签署、不写 A2X；SDK 保存实际预览与预期修订，同一预览操作恢复原结果；分类已删或修订变化时拒绝新发布并要求重新预览 |
| 可用性 | 已发布、索引就绪、连接在线、可执行与容量分别报告；完成公示不等于可接单；搜索结果与在线状态不是接单承诺 |
| 部署发布授权 | 只面向本平台 ISP 账号下已绑定未停用的服务，只替代该范围内逐次公示的用户确认，不授予接单、签署、开工、工具、验收或付款权限；授权修订独立于公示修订；撤销保留记录并递增修订；所属方人工改条款时同一事务停用旧授权；被撤销或改条款后不得重签旧请求延长时间 |
| 种子 | 分类与内部账号种子由部署清单显式传入并幂等建立，平台不按源码路径读取官方目录；默认目录可重建，重复部署不创建同名重复身份；官方与外部服务采用同样的登记、签认、容量与执行接口 |
| 下线与刷新 | 下线停止新的推荐与接单入口，不删除既有合同所需资料；同一服务更新索引时旧模板与原件仍可查询 |
| 异常 | 上传成功而索引未知时以稳定发布操作与模板摘要查询；搜索命中但离线或满额时只展示状态；缓存与原件不一致时拒绝使用并重取原件；删除或替换种子不覆盖已有身份、合同与原件 |

### 验收条件

单模块的可验证条件；跨模块条件在流程页的“端到端验收”节。

| 场景 | 必须满足 | 测试 |
|---|---|---|
| 授权隔离 | 普通外部账号和受限 SDK 不能设置部署授权；越身份、条款、寿命及授权修订均拒绝；原正常用户确认仍必需且无 confirmed 快捷参数；同一操作固定授权来源，后增授权不绕过原待确认、拒绝或过期 | publication_authorizations |
| 批量与竞争 | 授权设置原子比较，失败不部分提交；重传、丢响应及写事务前被撤权正确；提交公示时再次核当前授权 | publication_authorizations |
| 人工变更 | 所属方修改公开条款后旧自动授权停用；旧启动器不能回滚新条款；再次配置须明确授权新范围 | publication_authorizations |
