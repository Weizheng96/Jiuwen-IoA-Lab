# 注册中心 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/registry/` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `RegistryView`、`ServicePublications`、`PublicationAuthorizations`、`publication_terms`、`CategoryPreview`、`Discovery`、`DiscoveryModels`、`migrate` | 唯一入口，只含导入与 `__all__` |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 发布 | `publication.py`、`authorizations.py` | 声明与模板校验、原件与回执持久化、状态汇总、授权条款与寿命核对 |
| 服务目录 | `view.py` | `RegistryView`：按协议地址取实际分类、已登记服务列表 |
| 分类 | `categories.py`、`taxonomy.py`、`models.py` | 预览决策；树文件的确定性生成、归类与读取；模型调用；嵌入每批最多10条，校验数量及完整唯一index并按输入顺序合并，失败不返回部分结果 |
| 发现 | `discovery.py` | A2X 数据集生命周期、种子与运行期注册、树导航与向量退路、超时降级；只读检索与公共可用性的组合由 web服务 的 `DiscoveryOperations` 协调，不预留接单容量 |
| 存储定义 | `migrations.py` | 本模块全部表 |

## 存储与迁移

表见[接口](接口.md#独占数据与配置)。迁移由平台基础统一入口持锁后事务内调用；升级只追加。旧库服务目录在身份中心的 `agents.definition`，迁移经身份中心 `release_service_listings` 取回原名称、说明、标签、分类与绑定地址写入 `registry_services`，同一事务内删去旧列。A2X 数据集在 `data/a2x/` 下，可按原件重建；凭据文件由平台基础的配置写入 `data/a2x_home/`。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `ServicePublications(clock=…)`、`PublicationAuthorizations(clock=…)` | 固定时间核新鲜度、模板期限与授权寿命 |
| `ServicePublications(categories=…)`、`CategoryPreview(categories,choose)` | 替换叶类来源与分类模型 |
| `Discovery(embed_fn=…, llm_configured=…)`、`tree_timeout` | 替换嵌入与树检索条件 |
| `prepare` 与 `commit_in` 的分界 | 在准备后、签认后、提交前注入故障 |
