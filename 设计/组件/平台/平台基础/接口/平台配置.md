# 平台基础 · 平台配置

本页是[平台基础](../接口.md#接口)的子页。

## 目的与范围

定义平台参数的唯一文件、默认值、权限及动态生效边界。配置管理是平台基础设施，不是另一套身份、支付或参与方执行器；领域行为分别由身份中心和支付中心维护。部署与组件读取同一平台配置，不以网页数据库、逐字段环境变量或另一个core.env保存第二份权威。

## 文件与字段

启动显式指定私有JSON文件；IOALAB_CONFIG只定位文件，不能逐字段覆盖。文件必须是受限普通文件，拒绝越界链接、未知字段和错误类型；缺失或损坏明确失败，不回退到旧环境变量或重新生成已用凭据。格式为ioalab.platform-config/1，revision为单调递增正整数。

| 组/字段 | 默认或规则 | 在线热改 |
|---|---|---|
| runtime | mode、bind、port、public_url、data及显式资源路径；原有连接、消息、注册及运行选项集中于本组，按所属职责页校验 | 否 |
| runtime.trial_url / trial_confirm_url | 管理员可在线保存两个试用HTTPS入口的端口；保留既有hostname/scheme，仅端口可变，三Origin必须独立。未初始化时只有正式HTTPS显式IP可据其初始化两端口；域名部署先离线配置独立hostname | 保存后待部署应用，不热切换 |
| admin.username / password | 新部署admin / admin1234；密码是敏感输入，已有配置不被默认值覆盖 | 否 |
| llm | 平台模型的api_key、base_url及模型选择，api_key为敏感输入；不把用户自管参与方配置读入核心 | 否 |
| authentication.max_failures | 40，正整数 | 是 |
| authentication.window_seconds | 60，正整数 | 是 |
| authentication.registration_limit / registration_window_seconds | 保留现有独立注册流量预算5次/3600秒，与登录失败预算分别计数 | 是 |
| authentication.local_unlimited | true，只免频率限制 | 是 |
| authentication.local_addresses | 默认127.0.0.1、::1；额外值只能是显式确证的单个本机接口地址，不支持全私网推定 | 否 |
| authentication.trusted_proxy_addresses | 默认空；Linux Nginx显式以proxy_bind 127.0.0.2连接核心，仅登记此独立回环peer；其X-IOALAB-Client-IP覆盖为实际remote_addr | 否 |
| credits.initial | 500.00，非负两位十进制数 | 是 |
| credits.login | 100.00，非负两位十进制数 | 是 |
| credits.repeat_daily | false，是否允许同账号同日多次明确登录重复领取 | 是 |
| credits.day_timezone | Asia/Shanghai（UTC+08:00），业务日与宿主时区无关 | 否 |

受信代理地址与本机豁免地址不得重叠。代理peer必须可在socket层与普通SDK回环连接区分；本布局Nginx使用127.0.0.2源地址，目标仍为核心127.0.0.1。此peer缺少或携带非法单值来源一律拒绝，不退回本机豁免；普通SDK从127.0.0.1或::1直连可不带代理头。部署须实测源绑定与伪头负例，不能只靠配置文本宣称成立。

字段类型、允许范围及所有运行项必须同步集中配置模板；JSON布尔值不能以字符串代替，数值拒绝NaN、无穷、负数或超精度。管理员用户名和密码是部署管理登录的实际校验字段，不把展示名当认证。既有普通账号的管理员角色规则保持不变。

所有写权限只授予本平台配置所有者及必要系统管理者；Linux父目录和文件须支持核心对其唯一配置原子写入，不将整个部署树交给核心。Windows核实际ACL，不把chmod成功当作机密保护。备份及临时文件同样受限；配置值、请求正文或密码不得进入普通日志、API错误或Git。

## 修订与运行时生效

配置组件负责完整校验、读取快照和更新。管理员提交expectedRevision及显式可热改字段，或上述两个试用端口字段；其他启动项、未知字段或错误修订拒绝。更新在同一写锁内重新核原磁盘修订，完整校验候选，受限临时文件写入并同步后原子替换，再发布一致的内存快照。保存失败不发布内存半成品；同一进程内请求只能看到完整旧版或新版。其他写者或手工编辑导致修订不符时明确冲突，不覆盖。

在线写入只走该接口，不另设文件监听或数据库配置副本。手工修改需停机并在下次启动完整验证。公共URL、数据路径、管理员凭据、模型与代理来源策略属于重启项；只读显示不代表可在线提交。两个试用入口端口是可在线保存的例外，保存只更新唯一JSON和修订，不改变运行中Settings或即时签发的aud。查询同时给出已保存入口、当前核心进程使用入口和待部署应用标记；该标记不证明Nginx、云安全组或公网连通，准入密钥只返回是否配置。平台模型变更不自动覆盖其他参与方已经配置的模型/业务工具，部署更新通过其所属公开配置入口处理。

限流变更保留既有失败记录，不通过调参清空次数；赠币策略只影响随后新operation，不重算既有余额/付款或恢复旧登录发币。领域事务使用同一读取快照，不把一个操作的金额与日限从不同修订混合取得。

## 管理员入口与脱敏

我的智能体页面的“管理者全景”提供平台设置。GET /api/admin/configuration仅返回当前revision、可编辑参数和重启项摘要；敏感项仅返回是否已配置，不返回原密钥、明文密码或可逆编码。PUT /api/admin/configuration仅允许上述热改字段及两个试用端口字段，要求原网页管理员权限及CSRF/Origin，不向普通用户、受限SDK、模型或A2UI答复开放。

变更审计记录操作者、字段名、修订及安全结果，不保存秘密或配置全文。热改字段提交成功只在持久化与运行快照生效后报告；端口保存成功须明确报告需部署应用，未验证公网可达；未知结果先查当前修订，不换标识重复写入。

## 配置归属

平台启动参数集中在一个受限JSON文件，格式、默认值、敏感字段及动态生效规则只在[平台配置](平台配置.md)维护。核心只读取显式文件，IOALAB_CONFIG仅作为路径定位；不再以逐字段环境变量覆盖文件，也不通过core.env维持另一套平台参数。公共地址首次初始化后仍锁定。

接入技能、SDK、九问工作区及官方业务工具保留所属参与方的私有配置，核心不读取或改写其凭据/私钥/会话。统一部署文件可提供首次装配输入，部署器通过原公开接口生成各所属组件的运行配置；普通重启不重放模型模板、身份、授权或人工设置。模型执行并发、服务接单容量、消息保留等规则仍由各职责页定义，平台文件只集中所属字段。组件间不得反向依赖部署源码。

新增字段同步模板的类型、默认、敏感性和生效时点；网页查询不输出秘密，协议币种/签名/期限不能由配置任意改写。

## 部署与保留

安装器输入以platform_config引用本文件，不再重复定义平台地址、模型、管理员及发币/认证参数。安装记录保存原配置引用和部署身份；合法动态修订不触发重新创建账号、替换密钥、重放公示或业务授权。参与方运行配置、私钥和业务状态仍归各组件，派生配置不是第二个平台参数编辑入口。

从旧环境配置切换时显式一次性导入并切换启动引用，保留原文件、原人工值和业务数据；没有运行期双轨回退。旧账号不补初始500；历史同日发放从原账本核实后纳入资格，禁止迁移再次领取。新安装默认值不能覆盖已有密码/模型/账户状态。

## 验证

覆盖文件缺失/权限/链接/非法字段、并发修订冲突、原子保存失败、重启读取同一配置、脱敏和普通用户拒绝；实测本机直连、公开客户端伪造来源及Nginx覆盖来源，不能让所有反代请求都取得本机豁免。认证与支付分别验证失败预算、正常登录、发放并发幂等、跨日、旧operation与旧账本保留。部署专项另验真实配置文件权限与运行生效，单元通过不代表部署完成。
