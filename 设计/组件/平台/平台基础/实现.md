# 平台基础 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/` 下的 `storage.py`、`migrations/`、`errors.py`、`files.py`、`keys.py`、`events.py`、`config.py`、`configuration.py`、`configuration_permissions.py` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `storage.py` | `DataOwner`、`DataInUse`、`DB`、`SqliteStore`、`initialize_adapter`、`now`、`jload`、`jdump` | 所有权、事务与存储适配 |
| `migrations/__init__.py` | `migrate`、`execute` | 统一迁移入口 |
| `errors.py` | `LabError` | 公共错误 |
| `files.py` | `PrivateFiles`、`MAX_FILE`、`migrate` | 私有文件 |
| `keys.py` | `KeyStore` | 机构密钥 |
| `events.py` | `EventBus`、`TracingTransport`、`trace_endpoint`、`LABELS` | 事件总线 |
| `config.py` | `Settings`、`DEFAULT_LLM_BASE` | 类型化配置 |
| `configuration.py` | `PlatformConfiguration` | 配置权威 |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 存储 | `storage.py`、`migrations/__init__.py` | 操作系统锁、连接与事务、键值适配、迁移顺序与逐句执行 |
| 文件与密钥 | `files.py`、`keys.py` | 协议文件的配额、落盘、完整性与授权；机构密钥的生成与读取 |
| 事件 | `events.py` | 事件记录、缓冲、订阅、JSONL 导出、传输与端点追踪 |
| 配置 | `config.py`、`configuration.py`、`configuration_permissions.py` | 字段与默认值、完整校验、修订更新、脱敏视图、试用端口变更规则、文件权限核对 |

## 存储与迁移

本模块定义 `kv` 与三张私有文件表；其余业务表由各模块在自己的 `migrations.py` 定义。`migrate` 在一次事务内先建键值适配，再依次调用各模块与私有文件的迁移。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `Settings(...)` 直接构造 | 测试不经私有文件即可得到隔离配置；`_configuration` 为空时 `policy()` 取字段值 |
| `PrivateFiles` 先占配额后写盘、再置就绪的三段 | 在写盘处中断，断言同操作恢复原引用而不重复占配额 |
| `PlatformConfiguration.update` 的临时文件与原子替换 | 注入写盘失败，断言不发布内存半成品 |
| `EventBus.record_in` 与 `publish` 分离 | 断言事务回滚时没有事件，提交后才广播 |
