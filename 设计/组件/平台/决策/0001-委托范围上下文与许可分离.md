# 委托范围上下文与用户许可分离

A2C 卡与请求用 `delegationScopeDigest` 绑定用户授权，而授权需要续期与撤回。若摘要包含有效期，续期会改变摘要，使已签的卡与请求失效。决定：context（用途、分类、币种、预算、拟卡费上限、用户公钥）不可变，scopeDigest 只对 context 计算；grant（修订、起止）单独签为 proof，续期与撤回只推进修订，不改 context，也不重置支出或已选合同。

原因：卡载摘要稳定，续期不必重签合同；撤回靠推进修订而不靠删除，原证据与支出保留。后果：平台校验时同时核 context 签名与当前修订；已选合同权威在新许可过期或关闭后仍有效，只拒绝新动作。规则正文见[支付中心接口](../支付中心/接口.md#不变量)。
