# 支付中心 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/payments/` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `SimPaymentProvider`、`Wallets`、`money` | AP2 适配、账本与金额定值 |
| `scopes.py` | `ScopeLedger` | 委托范围与许可台账，由 web服务 装配时直接导入 |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| AP2 适配 | `ap2.py` | `PreparedPayment` 与 `SimPaymentProvider`：事务外准备、事务内提交、投影、查询、证据与应付核对 |
| 账本 | `ledger.py` | `Wallets` 与 `money`：钱包、发放资格、流水、转账 |
| 授权台账 | `scopes.py` | `PreparedScope` 与 `ScopeLedger`：登记、选择、关闭、付款记入、准入视图 |
| 存储定义 | `migrations.py` | 本模块全部表与追加式升级 |

## 存储与迁移

表见[接口](接口.md#独占数据与配置)。迁移由平台基础的统一入口在持有数据库所有权后事务内调用 `payments.migrations.migrate`；升级只追加。历史正向登录发放按业务日迁入 `login_reward_days` 以确立资格，不造币、不改旧流水；旧 `paid` 缺原凭证的记录保持待核实。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `SimPaymentProvider(clock=…)`、`ScopeLedger(clock=…)` | 测试固定时间，核窗口与过期 |
| `SimPaymentProvider(parties, client_matches, on_transfer)`、`requires_admission` | 替换身份判定与投影回调 |
| `ScopeLedger(template, category)` | 替换原模板与分类来源 |
| 事务外 `prepare` 与事务内 `commit`、`apply_in`、`record_payment_in` 的分界 | 故障注入点：在准备后、提交前或提交中断言回滚 |
