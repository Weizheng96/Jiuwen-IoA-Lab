# 消息中心 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/messaging/` |
| 产物 | `src/platform/VERSION`（`ioalab` 发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `DeliveryBroker`、`InterfaceDirectory`、`build_router`、`migrate` | 唯一入口，只含导入与 `__all__` |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 投递 | `delivery.py`、`connections.py`、`controls.py`、`sending.py`、`interactions.py`、`retention.py`、`envelope.py` | `DeliveryBroker`（`delivery.py`）由五个分部组合，方法与入口不变：连接（租约与代次、心跳、投递读取）；控制（操作回执、帧与代次校验、续租、本模块五种控制操作的事务内提交与受理活动记录）；发送（信封与按消息种类校验、配额、入队、结果终局与未知）；交互（建立、开始许可、确认、关闭、裁定与关闭的系统通知、交互与原协议历史查询）；保留（保留期与周期清理）；`envelope.py` 放平台发送者、终态与 JSON、时间、标识工具。由 `Platform.delivery` 装配，在原操作事务内记录真实投递与 `EventBus.record_in`，提交后仅 publish；重放查询原回执，不二次生成事件或业务 |
| 收信接口 | `interfaces.py`、`schema.py`、`directory.py` | 声明发布与修订、发信权限、冻结修订读取；受限 Schema 检查；目录查询与其 HTTP 路由 `build_router`（`InterfaceDirectory` 只授权读取本人或对方公开声明，HTTP 保留目录 GET，实际发布与可靠投递走 SDK 入口） |
| 存储定义 | `migrations.py` | 本模块全部表与两个投递索引 |

## 存储与迁移

表见[接口](接口.md#独占数据与配置)。迁移由平台基础统一入口持锁后事务内调用；升级只追加。每个收件身份的序号在入队事务内递增，确认游标只前进到连续已保存的序列。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `DeliveryBroker(clock=…)` | 固定时间核租约、TTL、截止与保留期 |
| `DeliveryBroker(record_in=…, publish=…)`、`observe_in` | 替换活动记录与广播；广播失败不撤销已受理操作 |
| 装配后注入的 `admissions`、`protocol` | 不注入时委托意向与原协议消息返回 not_ready，可单独测助手通信投递 |
| web服务 分派器在准备后、提交前复核租约 | 在准备后、提交前切换连接代次或撤权，断言拒绝新提交 |

`schema.py` 与 `interfaces.py` 用 `fastapi.HTTPException` 表达校验失败，再由 `PublicInterfaces.check` 转成 `LabError`；纯规则函数因此带着网页框架类型。
