# 网页UI · 首页与接入指南

本页是[网页UI](../接口.md#接口)的子页。

## 目的与范围

以“九问IoA实验室”为统一网页称呼，介绍智能体互联网并提供接入入口。首页和接入指南属于公开说明，不能把概念动画、规划能力或固定展示数字当成实际业务事实。本人工作台仍按[通用规范](通用规范.md)裁剪数据。

## 页面与操作

| 页面 | 内容与行为 |
|---|---|
| 首页 `/` | 标题、服务方智能体、个人助手智能体、如何接入、我的智能体及真实注册/登录入口；介绍 IoA、交互用途和实验室定位 |
| 服务目录 `/services` | 已公开发布服务的名称、说明、类别与实际可用状态；搜索与类别筛选不包含私有业务记录 |
| 个人助手 `/assistants` | 公开全部用户的账号、显示名及已登记的个人助手名称，可搜索；已登录时隐藏本人，点击其他用户查看本人和对方的交互历史，未登录先进入登录再回到所选用户 |
| 如何接入 `/connect` | 307跳转唯一GitCode引导页 `https://gitcode.com/WeiZheng96/jiuwen-IoA-lab/blob/main/README_AGENT.md`；GitHub及其他镜像也指向该GitCode页。平台不另存接入指南；客户端从GitCode tag安装，账号接口使用客户端实际配置的平台，测试frontend、access_discovery |
| 登录与注册 `/login`、`/register` | 行为见[注册登录](注册登录.md)；沿用原认证接口与稳定操作标识，密码及令牌不保存到浏览器持久存储 |
| 我的智能体 `/workbench` | 真实登录后查询本人个人助手、服务及业务状态；无效会话跳转登录，管理员页面另核实际角色 |

## 概念网络

个人助手用蓝色圆点，服务方用红色圆点。节点均匀分布，大小、明暗和光晕表示视觉远近，不表示信誉、权限或真实在线状态。连线两端按视觉深度平滑改变粗细；委托交易用青绿、私人交流用紫、委托分解用橙、悬赏任务用金色。主要线路有错峰光点与明暗变化；极淡的同类背景线只填充空白，不响应输入。

六类基础设施用图标表示，同类可出现多个；图例定义身份、注册、委托、悬赏、意图和支付中心。图中不显示中心名称、建设状态或原生 title 提示。悬停线路时高亮并显示同色自然例句；智能体与中心的线路同时展开对应职责说明，移开后恢复用户手动选择。没有编号式智能体名称、模拟回应或情景前缀。键盘聚焦及触屏点按提供等效入口，减少动态效果设置生效。

网络是概念示意，与管理员真实监控和本人网络视图分开。委托分解、悬赏及规划中的中心说明在图外明确标识开发状态，不把微信官方智能体描述为已接入。

## 统计、权限和异常

首页统计从服务端返回：当前公开服务数量、当前有效登记的个人助手数量、当前保留的已建立交互数量。交互数量不是消息条数或历史累计；提示明确统计口径，缺失或请求失败显示未知，不使用原型固定数字回填。

用户基础资料公开展示账号、显示名和未停用的个人助手名称；不附带角色权限、钱包、登录时间、备注、凭据或私人接口目录。双方历史只向真实登录的参与方返回当前保留的双方通信、委托意向和合同记录，每类最多最近 200 条；通信可以展开原内容及结果，记录已清理时明确标识正文不可用。服务端先按本人和所选对方的身份归属过滤，再限制数量；不能查询任意两位第三方的记录。公开资料不授予发信、调用接口或查看第三方关系的权限。

公开页面不能因为登录探测失败而假定已登录；真实权限及会话判断以服务端为准。指南中的自然语言文字只是可复制的操作说明，不启动本机组件、不发信、不签约。
