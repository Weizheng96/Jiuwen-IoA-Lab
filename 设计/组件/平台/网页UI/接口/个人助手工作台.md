# 网页UI · 个人助手工作台

本页是[网页UI](../接口.md#接口)的子页。

## 目的与范围

让用户同时看懂自己的业务进展与所处网络。展示本账号助手的委托交易和助手通信，通用规则见[通用规范](通用规范.md)。

## 页面结构

| 区域 | 内容与操作 |
|---|---|
| 上半部网络 | 始终显示助手、服务与平台组件；自己的助手、相关服务和组件突出显示，可点击查看职责及记录 |
| 当前委托 | 发起、发现、筛选、协商、定约、交付、验收、付款；当前待办和证据入口 |
| 未成约记录 | 意向与候选合同、拟约阶段、报价与实际拟卡费；结束后保留原记录，分组规则见通用规范 |
| 委托历史 | 真实合同、交付、验收、费用与付款凭证；支持按状态筛选 |
| 助手通信 | 可访问的对方接口、当前与历史消息、投递及业务结果、待处理事项 |
| 我的收信规则 | “我定义的交互接口”、本人可见的允许发信人、接收/回复格式、公开说明及发布状态；本地处理步骤通过九问查看和配置 |
| 虚拟币 | 余量、登录赠币及支出明细，与合同报价区分 |

平台网页不持有本地处理正文，也不读取其摘要；不为展示此内容增加浏览器直连本地组件的通道。

上方网络与下方记录、表单分别滚动。没有实际事件的阶段保持待处理或未知，不能为了画完整流程自动补齐。待用户确认的动作指向对应九问会话或受控本地确认入口，网页投影自身不替参与方签字。

## 其他参与方的展示

其他个人助手以匿名灰色节点显示；专业服务使用公开目录的真实名称，相关服务彩色、无关服务弱化。不得使用“匿名服务”“背景展示”等作为服务名。

浏览器可生成匿名助手之间错峰、短时的环境示意动画，使网络持续可见；不使用其他用户的私人消息或合同，图例说明为网络示意，不计入真实活动统计。自己的业务始终使用真实事件。多种示意可并发，不用永久连线或机械轮播。

## 权限与异常

接口显示名与允许范围不代替服务端鉴权；个人助手间活动称为交互，不统一称为协作，也不强调收费与否。查看正文只限本账号获准内容。

消息“送达”、业务“已处理”和用户“已读”分别展示；预约的本地预留、邀请提交与本人接受分开。助手离线时展示暂存或等待，不能显示模型正在处理。

解除生效、执行收敛、结算和市场结清分别展示；未结清不得只显示完成。付款明细保留实际非负金额及支付/退款方向，已付金额展示净支出，退款另列；同账号内部过账不形成净支出。合法旧快照不得覆盖已确认解除，显示副本丢失从委托中心原证据恢复。

仲裁显示原对象、理由、证据预览及caseRef，用户确认、受理、评估、裁定、执行结束和实际付款分别展示。预览eligible不表示已申请或已裁定；已裁定而原执行/债务未核实不能只显示完成，不能给出重启原卡或按裁定自动付款的操作。依据见[委托中心](../../委托中心/接口/仲裁.md#争议案件与原证据)。
