# 网页UI · 管理员工作台

本页是[网页UI](../接口.md#接口)的子页。

## 目的与范围

让管理者理解整个智能体网络正在发生什么，并能追溯业务证据。共同布局、协议标注和动效以[通用规范](通用规范.md)为准。

## 页面结构

| 区域 | 内容与操作 |
|---|---|
| 全景网络 | 所有已登记助手、公开服务和平台组件；可按账号、智能体或组件聚焦 |
| 行为日志 | 网络右侧显示实际事件时间、参与方、动作及关联标识；最近 200 条，支持暂停/继续自动滚动 |
| 组件详情 | 职责、健康状态、相关活动与历史；委托中心展示合同认证、存证、信誉与案件入口，按状态查看原申请、待评估、待复核及已裁定案件 |
| 业务详情 | 委托阶段、合同证据、付款凭证、消息投递状态；按合同摘要或交互 ID 跳转 |
| 平台设置 | 我的智能体页面的“管理者全景”提供平台配置面板；展示当前修订、可热改字段和需重启项，规则见[平台配置](../../平台基础/接口/平台配置.md) |
| 运维详情 | 连接、队列、进程、异常与观察状态，和网络业务节点分开 |
| 历史查询 | 按时间、账号、服务、业务类型与状态筛选，查询结果不回放成新事件 |

保留双屏展示入口 `/admin?view=panorama`，另一屏可打开真实九问。浏览器使用观察通道，不消费智能体收件消息或推进游标。

## 配置操作

只有真实网页管理员可读脱敏设置及提交可热改字段，普通用户和受限SDK凭据均拒绝。提交携带读取时修订与原CSRF/Origin证明；冲突先刷新，不静默覆盖。非法字段、需重启字段、类型/金额错误、无写权限或原子保存失败均不发布部分结果。只在持久保存和运行快照共同生效后显示成功；设置变更记录管理员及修订，不记录密钥或明文密码。

## 案件复核

案件列表先展示caseRef、对象、理由、状态和实际更新时间。详情并列显示冻结申请与最新原事实，明确列出申请后新增的验收、付款或解除；另显示冻结材料、原程序结果和已签文书。管理员先阅读再选择归责并写明理由；页面不默认代选责任，也不把队列受理显示成裁定成功。仅按服务端availableActions显示复核或明确重评入口；提交绑定当前expectedEvidenceDigest，冲突则刷新实际事实，不静默代提交。终局展示裁定时固定的决定证据；材料和文书均可按原引用查看。

本账号作为当事方的案件不进入其独立复核入口；访问或下载也不得绕过这一检查。规范边界见[委托中心](../../委托中心/接口/仲裁.md#材料与复核边界)，不以本案材料入口代替独立的私人消息审计授权。

## 权限与异常

默认管理账号按[身份中心](../../身份中心/接口.md)初始化。一般全景权限不包括所有私人消息正文；审计入口独立鉴权并记录操作。行为日志不包含正文和凭据。

断线后先展示观察中断，再用获准快照补齐。空闲时不补造活动；需要活跃网络演示时由独立实验客户端产生真实、可标识的委托与消息，允许两者并发。
