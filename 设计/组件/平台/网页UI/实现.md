# 网页UI · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/platform/ioalab/web/static/` |
| 产物 | `src/platform/VERSION`（随 `ioalab` 发行包分发，由 web服务 挂载在 `/static`） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `index.html` | `/` | 首页 |
| `connect.html` | `/connect` | 接入指南 |
| `providers.html`、`assistants.html` | `/services`、`/assistants` | 公开目录 |
| `auth.html` | `/login`、`/register` | 注册登录 |
| `workbench.html` | `/workbench` | 个人助手与服务方工作台 |
| `admin.html` | `/admin` | 管理员工作台 |
| `trial.html` | `/trial` | 试用入口 |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 页面 | 八个 `*.html` | 各入口的结构 |
| 共用外壳 | `shell.js`、`shell.css`、`common.js`、`session.js`、`app.css`、`logo.svg` | 页头、会话探测、通用请求与样式 |
| 公开页 | `index.js`、`home.js`、`home.css`、`public.js`、`people.js`、`people.css`、`connect.js`、`connect.css`、`auth-page.js` | 首页、目录、接入指南与注册登录 |
| 网络与全景 | `network.js`、`network-map.js`、`network-map.css`、`panorama.js`、`panorama.css` | 概念网络、工作台网络视图、管理员全景 |
| 工作台 | `workbench.css`、`provider-workbench.js` | 工作台布局与服务方视图 |
| 管理员 | `admin.js`、`admin_messages.js` | 管理员页面与消息审计 |
| 试用 | `trial-entry.js` | 试用准入跳转 |

## 存储与迁移

无。静态文件改动后运行 `python tools/stamp_static.py` 更新内容摘要；页面验收同时核实际加载资源，避免旧缓存误判。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| 渲染函数与数据获取分开 | `tests/test_workbench_rendering.py` 用内存 DOM 驱动执行真实渲染函数 |
| `tools/check_frontend.cjs`、`tools/check_admin.cjs`、`tools/check_workbench.py`、`tools/check_panorama.py` | 页面脚本的静态与行为检查 |

## 已知偏离

无。
