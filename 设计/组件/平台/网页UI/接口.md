# 网页UI

## 目的与范围

给人类用户看的页面：公开首页与接入指南、注册登录、个人助手与服务方工作台、管理员工作台、试用入口页。页面只消费 web服务 的 HTTP 与 WebSocket 结果，不定义合同、支付或消息状态，不保存业务数据；展示所依据的事实与裁剪规则归[观测](../观测/接口.md)。调用方是浏览器用户。

## 独占数据与配置

本模块没有服务端数据。浏览器只持有 web服务 设置的会话 cookie；静态资源带内容摘要，改动后用 `tools/stamp_static.py` 更新。

## 不变量

| 规则 | 说明 |
|---|---|
| 消费事实 | 页面按服务端返回的事实表达，不自行推进状态；账号操作使用真实浏览器会话，不建立本地模拟身份 |
| 服务端裁剪 | 不把其他用户的消息、合同或全局私有事件发到普通浏览器后仅用样式隐藏；账号管理权限不改变收信接口的业务授权 |
| 只读观察 | 工作台查询和网络观察不领取或确认业务消息；浏览器断线补历史只恢复状态，不重放为当前活动 |
| 建设中组件 | 意图中心与悬赏中心只作灰色展示，没有活动或可调用入口 |

### 验收条件

单模块的可验证条件；跨模块条件在流程页的“端到端验收”节。

| 场景 | 必须满足 | 测试 |
|---|---|---|
| 页面实证 | 用新事实检查助手、服务方及管理页面的真实渲染与错误；脚本/结构检查不替代截图，也不能据此声称原生九问用户批准或四个新影片完成 | workbench_rendering、frontend |
| 未成约展示 | 权威释放后的候选卡保留为未成约结束记录，三类工作台状态一致；不进入合同历史、履约或完成统计，报价与拟卡费标注明确；仅时间流逝、未知执行或副本缺失不显示正常结束，默认聚焦与显式选择正确 | workbench_rendering、proposal_expiry |
