# 网页UI · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../../架构.md#模块表)的依赖图持有。页面只经网络访问 web服务，不导入任何 Python 模块。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| web服务 | [网页观察接口与公开网页查询](../web服务/接口/网页与部署接口.md)、[HTTP入口](../web服务/接口/HTTP入口.md)中的会话、注册登录与钱包入口、[仲裁接口](../web服务/接口/仲裁接口.md)的管理员入口、`/ws/admin` 实时事件 | 页面数据、账号操作、管理员复核、实时全景 | 自有远端 | 真实 ASGI 应用；渲染测试用内存 DOM 驱动 |
| 观测 | [事件与证据、授权观察视图](../观测/接口.md#不变量) | 页面表达所依据的事实口径 | 自有远端（经 web服务） | 同上 |

## 外部依赖

页面为原生 HTML、CSS 与 JavaScript，不引入前端框架或构建步骤。
