# 宿主适配 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../../架构.md#模块表)的依赖图持有。组内方向为 宿主适配 → 两角色端 → 共用运行时；SDK 不导入本模块。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 共用运行时 | [`AgentHost` 契约](../共用运行时/接口/本地执行与恢复.md#模块与依赖)：`HostTurn`、`HostResult`、`AgentDefinition`（`runtime/host.py`） | `ProcessHost` 实现的四方法契约与轮次输入输出 | 进程内 | 直接构造 `HostTurn` 与角色回调 |
| 共用运行时 | [本地业务工具](../共用运行时/接口/本地业务工具.md#本地业务工具)：`ToolBinding`、`BusinessTools`、`validate_output` | 工厂返回值校验、工具注入、通知输出契约核对 | 进程内 | 真实对象；已安装的样例工厂 |
| 共用运行时 | [本机调用与启动](../共用运行时/接口/调用与启动.md#本机调用与启动)：`ResidentRuntime`、`RuntimeConfig`、`runtime.__main__` 的 `start`、`setup_command`、`validate_roles`，`ipc.public_error`；[配置](../共用运行时/接口/配置.md#不读取凭据的配置辅助)：`files.read_arguments` | 命令行装配常驻进程、后台启动、配置查看与修改、读取参数文件 | 进程内 | 临时配置目录与真实运行时 |
| 共用运行时 | `protocol.RuntimeFault`、`encode`、`configure_stdio`；`files.private_json`、`private_text`、`read_json`、`restrict`；`lease.Lease` | 错误对象、规范 JSON、私有文件写入与权限、通知队列单实例锁 | 进程内 | 临时目录 |
| 个人助手端 | [个人助手端](../个人助手端/接口.md)：`assistant.role.AssistantRole(host, tools)` | `serve` 装配助手角色模块 | 进程内 | 真实对象配合假 `Client` |
| 服务方端 | [服务方端](../服务方端/接口.md)：`provider.ProviderRole(host, tools_by_profile)` | `serve` 装配服务方角色模块 | 进程内 | 真实对象配合假 `Client` |

## 外部依赖

| 包 | 用途 | 版本来源 |
|---|---|---|
| `jiuwenswarm-process-sdk`（`jiuwenswarm_sdk.Client`） | 原版九问进程的 query、run 与工具、交互、事件回调 | `pyproject.toml` 精确固定 0.1.0；发行锁 |
| `ioalab-sdk` | 上表各接口 | `pyproject.toml` 下限，发行时取同仓 wheel |
| `websockets` | 通知扩展的 WebChannel RPC 客户端 | `pyproject.toml` 范围；发行锁 |
| `python-dotenv` | 从专用凭据文件读取通知密钥 | `pyproject.toml` 范围；发行锁 |
| `a2c`（`codec.digest`、`digest_bytes`、`errors.A2CError`） | 定义摘要与技能快照摘要 | 经 `ioalab-sdk` 依赖取得，本包未直接声明 |
| `jsonschema` | 业务工具输入 Schema 合法性检查 | 经 `ioalab-sdk` 依赖取得，本包未直接声明 |
| `jiuwenswarm`（`extensions.sdk.ApplicationPluginExtension`、`common.e2a.models.E2AEnvelope`） | 通知扩展在九问进程内运行时使用 | 用户既有九问安装提供，不随本包安装 |
