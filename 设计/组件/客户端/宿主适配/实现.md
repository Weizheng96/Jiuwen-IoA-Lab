# 宿主适配 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/client/hosts/jiuwen/ioalab_jiuwen/` |
| 产物 | `src/client/hosts/jiuwen/VERSION`（`ioalab-jiuwen` wheel，`src/client/hosts/jiuwen/pyproject.toml`） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `ProcessHost`、`ConfiguredTools`、`prepare_extension`、`assembled`、`Assembly` | `AgentHost` 实现、业务工具装配、通知扩展准备与常驻装配；在线试用、管理员助手从此导入 |

## 其他入口

| 文件 | 调用方式 | 说明 |
|---|---|---|
| `__main__.py` | `python -m ioalab_jiuwen`、`ioalab-jiuwen` 脚本 | 技能入口脚本、部署单元、官方服务协调器以命令调用 |
| `web_notifications.py` | 入口点组 `ioalab.business_tools` 的 `jiuwen-web`（`factory`） | 由 `ConfiguredTools` 经入口点加载 |
| `a2ui.py` | `python -m ioalab_jiuwen.a2ui` | 个人助手产品技能取需求与候选表单 |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 模型轮次 | `process.py` | `ProcessHost` 调用原版公开接口：能力探测、工具别名与声明、权限、轮次记录、Session 绑定、回调转发、取消；复用共用运行时的冻结技能与受限读取 |
| 确认表单 | `a2ui.py` | A2UI 0.8 需求与候选表单的生成和提交值校验 |
| 网页通知 | `web_notifications.py`、`web_client.py`、`web_setup.py`、`resources/ioa-notifications/extension.py`、`resources/ioa-notifications/extension.yaml` | 本地持久队列与后台投递线程；固定目标的 WebChannel RPC 与回执核对；向已有九问准备扩展；在九问进程内运行的扩展与清单（随包资源，由九问加载，不被本包导入） |
| 装配 | `__main__.py`、`assembly.py`、`configuration.py`、`tools.py`、`__init__.py` | 命令分派；`assembly.py` 是 `serve` 与在线试用共用的唯一常驻装配（工具、宿主、两角色模块、常驻运行时，probe 先于工具启动，先关运行时再关工具）；host 区域的校验与合并；入口点工厂的构造、注入与生命周期（`tools.py` 只装配明确选中的工具工厂） |

## 存储与迁移

数据位置见[接口](接口.md#独占数据与配置)。轮次记录与技能快照位于 SDK 交给本轮的工作目录内，随所属交互保留；技能快照的生成、摘要与只读恢复归共用运行时的`business_skills.py`。通知队列在 `start` 时首次建库并写同内容标记，库与标记须同时存在且固定目标一致，否则 not_ready，要求恢复或显式迁移，不重建空库。扩展回执库首次加载时建表并置 `user_version=1`，其他版本拒绝加载；两侧均无升级路径，格式变化须另行设计迁移。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `ProcessHost._client` | 测试替换为假 `Client`，断言请求内容、回调顺序与 Session 绑定，不启动原版进程 |
| `WebNotifications.client` 的 `probe`、`get`、`deliver` | 测试替换为本地扩展替身，覆盖离线、响应丢失、回执库重置与 TTL |
| `importlib.metadata.entry_points` 组 `ioalab.business_tools` | 业务工厂唯一来源；测试安装样例工厂包 |
| 环境变量 `JIUWENSWARM_DATA_DIR`、`JIUWENSWARM_CONFIG_DIR` | 子进程与扩展的数据目录由 `data_dir` 决定 |

`configuration.HOST_FIELDS` 与 `ProcessHost.from_config` 各自列出同一组四个 host 字段，修改时须同步。
