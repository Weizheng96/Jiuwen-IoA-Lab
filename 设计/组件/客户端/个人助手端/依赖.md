# 个人助手端 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../../架构.md#模块表)的依赖图持有。进程内只导入共用运行时；平台各中心的规则只经 web服务 的网络接口到达，不导入平台代码。宿主由装配方以 `AssistantRole(host=…)` 注入，其契约归共用运行时。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 共用运行时 | [运行时对象](../共用运行时/接口.md)：`bind(runtime)` 传入的 `store`（`checkpoint`、`checkpoint_set`、`checkpoints`、`checkpoint_update`、`prepare_checkpointed`、`interaction`、`prepare_open`、`bind_session`、`messages`、`response`）、`connection`（`call`、`submit`、`wait`、`recover_interaction`）、`account.api`、`config.home`、`identities`、`require_execution`；`runtime.files.private_text`、`restrict`；`runtime.protocol.RuntimeFault`、`encode`、`instant`、`stamp`；`runtime.ipc.public_error` | 本角色检查点与文件、平台控制操作与 HTTP 调用、执行租约、错误与时间格式 | 进程内 | 真实运行时配合临时 home 与测试平台 |
| 共用运行时 | [流程日志](../共用运行时/接口/本地执行与恢复.md#本地数据所有权)：`FlowJournal`、`flow_key` | 角色流程检查点、原子调用绑定、稳定子操作键与有界恢复 | 进程内 | 真实运行时及公开IPC |
| 共用运行时 | [操作目录](../共用运行时/接口.md#装配与常驻实例)：`runtime.catalog.ASSISTANT`、`CATALOG`、`handled_by` | 登记本角色操作并按目录的输入形状检查参数 | 进程内 | 真实目录 |
| 共用运行时 | [调度与确认](../共用运行时/接口/用户确认.md#用户确认)：`runtime.scheduling.JobHandler`、`JobOutcome`；`scheduler`（`submit`、`get`、`reference`、`records`、`resolve`、`bind_session`）；`confirmations`（`ensure`、`claim`、`native_answer`）；`runtime.questions.native_answer` | 异步作业、阶段确认与原生问答 | 进程内 | 真实调度器；确认由测试直接批准记录 |
| 共用运行时 | [宿主契约](../共用运行时/接口/本地业务工具.md#本地业务工具)：`runtime.host.AgentDefinition`、`HostTurn`、`ToolBinding`、`validate_output`；注入的 `host.run`、`cancel`、`capabilities`；`runtime.observations.model_port` | 入站规则处理回合、本地工具绑定、验收模型观察 | 进程内 | `tests/_support.py` 的 `ScriptedHost` |
| 共用运行时 | [A2C适配](../共用运行时/接口/A2C适配.md)：`adapters.ProtocolStore`、`SessionTransport`、`adapters.transport.stable`、`adapters.endpoint.EndpointSession`、`adapters.market.reputation_evidence`、`adapters.reports.report`、`adapters.arbitration.read_case` | 原 A2C Client 的持久存储与会话传输、退款端点、信誉证据、验收报告、当前案件读取与裁定验签 | 进程内 | 真实适配器配合测试平台与测试服务方 |
| web服务 | [HTTP入口](../../平台/web服务/接口/HTTP入口.md)：`/search`、`/scopes`、`/messaging/interfaces`、`/messaging/accounts/{username}/interfaces`、`/messages/{messageId}`、`/operations/{operationId}`、`/payments`、[仲裁接口](../../平台/web服务/接口/仲裁接口.md#仲裁接口) `GET /arbitrations`；[WebSocket与消息封套](../../平台/web服务/接口/WebSocket与消息封套.md)：`message.send`、`request.start`、`interaction.close`、`contract.bind`、`scope.*`、`ap2.pay`、`a2c.market` 控制操作与系统消息 `contract.ruling`；原协议入口 `/a2a/market`、`/a2a/pay` | 检索、授权台账、收信接口发布与目录、消息与操作补查、成约与付款 | 自有远端 | 测试夹具 `platform` 起真实平台进程（uvicorn） |
