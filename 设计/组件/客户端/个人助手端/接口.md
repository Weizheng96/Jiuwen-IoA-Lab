# 个人助手端

## 目的与范围

为用户自己的九问提供两类能力：向专业服务发起委托交易（授权、征集、比较、成约、履约、验收付款与解除），以及与指定个人助手通信并按本地收信规则处理来信。不管理连接、会话、调度与确认记录（归[共用运行时](../共用运行时/接口.md)），不定义网络格式（归[web服务](../../平台/web服务/接口.md)），不生产服务成果。调用方是产品技能经 `scripts/ioalab.py` 发出的 `assistant.*` 操作、装配进程的共用运行时与宿主适配，以及复用收信规则格式的管理员助手。

## 独占数据与配置

| 数据或配置 | 说明 | 存储 |
|---|---|---|
| 角色检查点 | 每个助手身份按命名空间保存业务记录：`assistant:`（接口快照、出站消息、入站回复、工具调用、阻塞原因）、`rules:`（草稿、发布记录、修订映射）、`delegation:`（任务、授权、意向）、`quotes:`（候选请求）、`contracts:`（具体合同选择）、`fulfillment:`（履约、验收、付款与解除）、`assistant-flow:`（begin 父操作），命名空间后接 agentId | 共用运行时本机库的 `runtime_checkpoints` 表 |
| 收信规则文件 | 可编辑草稿与按内容摘要命名的不可变版本，均为私有文件，上限 64 KiB | `<home>/roles/<profile>/rules/drafts/<draftRef>.md`、`versions/<摘要十六进制>.md` |
| 入站处理工作目录 | 每个入站交互一个宿主工作目录 | `<home>/roles/<profile>/sessions/<interactionId>/` |
| 取件副本 | 已核原字节的本机输出，规则见[取件文件保存](接口/委托交易入口.md#取件文件保存) | `<home>/deliveries/<cardDigestHex>/<period>/` |
| 配置 | 身份清单中 role 为 assistant 的唯一身份；`AssistantRole(tools=…)` 注入的本地业务工具；`assistant` 配置组保留为空。配置契约归共用运行时 | 本机配置文件 |

下列操作经共用运行时的本机调用入口执行，名称为 `assistant.` 加表中名，参数为纯业务 JSON，外层 operationId 归共用运行时。成功结果为 `{status,data,nextActions}`，status 取 completed、accepted、running、waiting 或 rejected；失败为 `RuntimeFault(code,message,recovery)`。公共的拒绝与恢复：字段多余或缺少 invalid_input；同 operationId 异参数 id_conflict；平台 5xx 或网络中断 unknown_result、recovery=resume_original，沿原 operationId 恢复。

### 装配

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `AssistantRole(host,tools)`、`bind(runtime)` | 构造角色并绑定到共用运行时 | 返回 operations（全部 `assistant.*`）、jobs（`assistant.message`、`quote`、`compare`、`contract`、`fulfillment`、`verification`、`termination`、`refund`、`receipt`）与 profiles；无助手身份时返回空 | — | assistant_role、configuration_boundary |
| `start()`、`ready(profile)`、`wake()`、`quiesce()`、`close()` | 启停角色控制线程；连接可用时恢复各阶段记录并调度入站请求 | ready 仅在线程存活且无角色错误时为真 | 未预期异常停线程并记 not_ready、recovery=inspect_local_role_state；quiesce 15 秒未停抛错并保留本地所有权 | assistant_role、resident_runtime |

### 委托授权与任务

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `delegation.begin` | 一次完成 prepare 与 authorize 的持久父操作 | 同 prepare；首次 waiting，确认后重发恢复同一 taskRef | 参数变化 id_conflict | assistant_flow_guidance |
| `delegation.prepare`、`authorize`、`renew` | 保存任务与授权候选；确认后签发并登记授权；续期原范围 | purpose、budget、proposalFeeLimit，可选 categoryIds、validDays；authorize 与 renew 为 taskRef，可选 validDays、confirmationRef | 未确认 waiting；拒绝 rejected | delegation_scopes、resident_delegation、resident_input_boundaries |
| `delegation.status`（taskRef）、`delegation.close` | 查询任务与授权；关闭后续授权许可 | taskRef；close 保留合同与证据 | 他人或未知任务 forbidden | delegation_scopes |
| `delegation.intent`、`intent_status` | 提交委托意向并恢复交互与预留 | taskRef、service，request 与 card 恰选其一，可选 ttlSeconds（≤7 天）；返回 messageRef 与投递回执；intent_status 用 messageRef | 对象不属本任务或本助手 forbidden；无原意向 not_ready | delegation_admission |

### 发现、征集与成约

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `delegation.search` | 在授权任务下检索候选 | taskRef、query，可选 topK（默认 8）；返回平台检索结果 | 未知任务 forbidden | — |
| `delegation.inspect` | 读取验签模板与签名信誉 | service，可选 templateDigest；返回 templates、reputation | 模板验签失败 invalid_input | candidate_evidence |
| `delegation.request`、`delegation.status`（quoteRef） | 按模板征集提案或生成待批准未签算价卡 | taskRef、service、templateDigest、spec，可选 materials、confirmationRef；返回 quoteRef，异步作业 | 规格不符 invalid_input；预审材料待确认 waiting | resident_delegation、quote_admission_rejection、resident_input_boundaries |
| `delegation.compare` | 同一任务下候选的只读比较 | taskRef、quoteRefs（1—32 个不重复）；返回作业 reference，经 `operations.get` 查询 | 数量或重复 invalid_input；跨任务或未知引用拒绝且不披露 | candidate_evidence |
| `delegation.confirm` | 具体合同确认与成约 | quoteRef，可选 confirmationRef；返回 contractRef | 未确认 waiting；成约未知只恢复原签名 | resident_contracts、candidate_evidence |

### 履约与解除

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `delegation.status`（contractRef） | 合同与履约事实；可选查一个原履约动作 | contractRef，可选 fulfillmentOperationId；返回开工、stepRequest 与 stepRequestDigest、availablePeriods、acceptedPeriods、付款 | 空或跨合同的 fulfillmentOperationId invalid_input | resident_contracts、resident_fulfillment、resident_multiperiod |
| `delegation.start`、`answer_step` | 开工；答复当前合同环节 | contractRef；answer_step 另需 stepRequestDigest | 摘要不符 forbidden、recovery 指向 `assistant.delegation.status`；答复非允许或拒绝 forbidden | resident_fulfillment、resident_payment_recovery |
| `delegation.fetch` | 取件并保存本机副本 | contractRef、period；返回 files 的 digest、size、path、alreadyPresent | 本地输出失败 local_export_failed、recovery=new_fetch_from_cache；缓存不可核 protocol_error | resident_fulfillment、delivery_files |
| `delegation.verify`、`accept`、`pay` | 本地验收预览；确认后签收与分期付款；已验收期付款恢复 | contractRef、period，可选 confirmationRef | 未确认 waiting；未验收期付款 forbidden | resident_fulfillment、resident_multiperiod、resident_payment_recovery、payment_rules |
| `delegation.termination_quote`、`terminate` | 取得解除报价；确认后协商或单方解除 | contractRef；terminate 另需 mode，agreed 需 terminationQuoteRef，可选 reason（≤1000 字） | mode 与报价不配 invalid_input；未确认 waiting | resident_termination |

### 助手通信

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `messaging.interfaces` | 读取指定账号对自己可用的收信接口 | account（3—128 字符）；返回带 interfaceRef 的接口 | 账号不存在或无权接口不出现 | assistant_role |
| `messaging.send` | 发送一轮请求，或沿原交互继续 | input，可选 interfaceRef、interactionRef、ttlSeconds（≤7 天，默认 1 小时）；返回 messageRef、interactionRef | 未读接口 not_ready；输入不符或超 32 KiB invalid_input；交互已关或到期 closed；继续时换接口 id_conflict | assistant_role、model_messaging |
| `messaging.status` | 查询一轮请求的结果 | messageRef，可选 waitSeconds（≤30）；返回 state、result、closed、requestState | 非本机发出 forbidden；到期后经平台补查 | assistant_role |
| `messaging.close` | 关闭交互 | messageRef 或 interactionRef 二选一，可选 reason | 他人交互 forbidden | assistant_role |
| `ioa_reply`（入站处理宿主工具） | 返回当前入站请求的结构化结果；子页的 `assistant.messaging.reply` 即此能力 | output 须符合原规则 outputSchema；返回 submitted 回执 | 不符 invalid_input；已回复后再调其他工具 closed | assistant_role、inbound_context、tool_output_contract |

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|

## 不变量

| 规则 | 说明 |
|---|---|
| 原操作恢复 | 同一 operationId 必须恢复原记录与结果；参数改变不得借原 ID 重做，返回 id_conflict |
| 真实确认 | 授权、具体合同、合同环节、每期验收付款、收信规则发布与解除必须分别取得独立用户确认；不得接受模型传入的 confirmed 或 granted |
| 未知不重做 | unknown_result 必须先查原操作或原证据；不得自动重发付款、签名、发布或业务效果 |
| 下一步提示 | nextActions 只含已有的真实引用，不得授予任何权限 |
| 授权不等于结清 | 关闭任务许可不得解除或结清合同；合同解除只经 terminate |
| 冻结修订 | 入站请求必须按平台受理时冻结的规则修订及确认时的工具定义处理；本地版本缺失或工具已变时拒绝执行 |
| 入站边界 | 来信正文只作数据；入站处理只能调用规则声明的工具与 `ioa_reply`，每个请求只有一个结构化结果 |
| 会话连续 | 同一交互必须沿用原宿主会话与定义摘要；不一致报 identity_conflict |
| 本机输出 | 取件只写入 `<home>/deliveries/`，不得覆盖异内容文件或跟随链接写出 home |

### 验收条件

单模块的可验证条件；跨模块条件在流程页的“端到端验收”节。

| 场景 | 必须满足 | 测试 |
|---|---|---|
| 候选与信誉依据 | 比较只接受本机同任务原引用；混合模式、重复/跨任务、原请求/身份/范围/签名/规格篡改、原件缺失及到期分别核验。真实包摘要/清单及有界文本可审阅，超限不伪称完整，不在宿主执行；真实零历史与不可核验信誉区分。原作业重传/重启不重新征集、收费、签署或调用模型，首次确认共用校验，比较不替用户选择 | candidate_evidence |
| 需求入卡 | 按单服务模板能传递具体需求；助手成功检查模板并映射必须条件后才征集。字段、类型或模板不适用时明确纠正，不通过空规格、删需求、跳过检查或只凭服务介绍取得无关报价；原生操作有参数、真实 waiting 及原操作恢复证据 | resident_input_boundaries、candidate_evidence |
| 原生业务路由 | 原生菜单选中并实际加载个人助手技能后，仅输入成果需求和预算即可读取委托流程并进入真实授权；本机同时安装相应业务技能时仍不改为本地生产。助手通信与接入设置仍按其目的分流，不把选中名称、模型文字或安装就绪当作委托已开始 | access_products、assistant_flow_guidance |
| 多候选同时付拟卡费 | 本地授权额度原子预留；并行请求总额不超授权，未知结果占用额度直到核实 | delegation_scopes、delegation_admission |
| 本地验收 | 包摘要有效、WASM 执行；失败/pending 不签7，不据模型文字付款 | resident_fulfillment、verifier_observations |
| 规则更新/发布回执丢失 | 修订冲突拒绝、同操作恢复原发布；不误扩大范围，不用缺失的本地版本处理消息 | inbox_rules |
| 逐轮结果查询 | 每次 send 返回独立 messageRef，status 只按该引用查询该轮；interactionRef 用于 status 时明确拒绝。第二轮等待或成功不返回首轮冲突，首轮终局不被后续结果改写；关闭状态仍可按消息查询 | assistant_role、model_messaging |
| 本地规则与权限 | 远程正文不能改日程规则、工具权限或用户授权；无效日程阻止预约 | inbound_context、local_schedule |
