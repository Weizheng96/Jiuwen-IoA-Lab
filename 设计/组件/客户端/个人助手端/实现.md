# 个人助手端 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/access/sdk/ioalab_sdk/assistant/`、`src/access/skills/assistant/` |
| 产物 | `src/access/sdk/VERSION`（`ioalab-sdk` 发行包）、`src/access/skills/VERSION`（`ioalab-delegate` 技能包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `AssistantRole`、`parse`、`render` | 角色装配与全部 `assistant.*` 操作，收信规则文件编解码；SDK装配、宿主适配、管理员助手与在线试用从此导入 |

## 其他入口

| 文件 | 调用方式 | 说明 |
|---|---|---|
| `src/access/skills/assistant/SKILL.md` | 产品技能 `ioalab-delegate` | 主文件，流程页在同目录 `references/` |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 装配 | `role.py` | 构造各分区并登记操作与作业；按操作目录检查字段并分派，归类平台错误；控制线程恢复各阶段记录并排程入站请求 |
| 助手通信 | `messaging.py` | 收信接口读取与快照、出站请求（与检查点同事务登记）、状态查询与关闭交互；`stable` 派生本角色的稳定标识 |
| 入站处理 | `inbound.py` | 入站请求排程与阻塞记录、规则回合、工具检查点与 `ioa_reply` 回复、回复丢失后的恢复 |
| 操作组合 | `flow.py` | begin 父操作串联 prepare 与 authorize；按真实引用生成 nextActions |
| 授权与意向 | `delegation.py` | 任务与授权范围、续期与关闭、委托意向 |
| 征集 | `trading.py` | 原 A2C Client 装配、模板检查、提案与待批准算价、征集作业与恢复；公共读取借用共用Network同步池和系统CA，无独立事件循环 |
| 候选比较 | `candidates.py` | 候选原件校验（比较与合同确认共用）、验收器包只读审阅、比较作业 |
| 合同选择 | `contracts.py` | 具体合同确认、选择回执与签1、成约恢复 |
| 履约 | `fulfillment.py`、`delivery_files.py` | 开工、环节答复、取件与本机安全保存、验收、分期付款、验收通知回执 |
| 解除 | `termination.py` | 解除报价与决定、同合同 AP2 退款接收、结清扫描 |
| 案件门禁 | `arbitration.py` | 受保护合同动作前按原 admission 读取并验签当前案件，保存裁定摘要；扫描 contract.ruling 通知 |
| 收信规则 | `rules.py` | 规则文件格式与 Schema 子集检查、草稿、预览、确认发布与不可变版本 |
| 委托发起链路 | `delegation.py` → `trading.py` → `contracts.py` → `fulfillment.py` | 从产品技能流程进入，锁定 A2C 与 AP2；委托、合同、环节、验收与付款分别核真实授权 |
| 收信与交流链路 | `rules.py`、`messaging.py`、`inbound.py` → 共用运行时 → 平台消息中心 | 入站上下文绑定已确认规则、实际请求和明确允许的工具 |
| 产品技能 | `src/access/skills/assistant/SKILL.md`、`references/*.md`、`settings.example.json` | 需求分流与各流程页；公共调用页与 `scripts/ioalab.py` 构建时取自共用运行时的 `_shared/` |

## 存储与迁移

本模块不建表。业务记录以 JSON 存入共用运行时库的 `runtime_checkpoints`，命名空间见[接口](接口.md#独占数据与配置)；本机文件位于实例 home 的 `roles/<profile>/` 与 `deliveries/`。数据随实例目录整体迁移，规则与设备迁移归[部署模块](../../部署/接口.md)。不可变规则版本按内容摘要命名，摘要失配视为本地损坏而拒绝执行。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `AssistantRole(host=…, tools=…)` | 注入 `ScriptedHost` 与测试业务工具，驱动入站回合与工具结果 |
| `flow.begin(role,…)`、`guidance(…)` | 以替身角色对象单测父操作恢复与提示 |
| `delivery_files.save_delivery(home,…)` | 以临时 home 单测文件名、链接与原子提交规则 |
| 运行时的 `confirmations`、`connection` | 测试直接批准或拒绝确认，或替换控制操作以模拟回执丢失 |
| 原 A2C `Client` 与共用运行时 `SessionTransport` 的方法 | 替换单个协议步骤，模拟网络中断、未知结果与原结果恢复 |
| `candidates.utcnow` | 固定时间核候选有效窗口 |
