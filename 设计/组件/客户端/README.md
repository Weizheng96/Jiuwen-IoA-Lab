# 客户端

参与方本机常驻接入：一个 SDK 包承载共用运行时、两角色模块与 A2C 协议适配，宿主适配实现 `AgentHost` 契约并装配进程。SDK 不导入平台核心与具体宿主；运行于个人电脑或服务环境，保管本账号参与方私钥与协议数据。子模块各有接口、依赖、实现三页；本组共用术语、决策与进展，迁入时建立。

| 子模块 | 代码 | 文件夹 |
|---|---|---|
| 共用运行时 | `src/access/sdk/ioalab_sdk/runtime/`、`adapters/`、`templates.py`、`src/access/skills/_shared/` | 待迁入，现为[本地接入组件](../本地接入组件.md)、[SDK共用机制](../../接入/SDK共用机制.md)、[A2C适配](../../接入/A2C适配.md) |
| 个人助手端 | `assistant/`、`src/access/skills/assistant/` | 待迁入，现为[个人助手端SDK](../../接入/个人助手端SDK.md)、[个人助手技能](../../接入/个人助手技能.md) |
| 服务方端 | `provider/`、`src/access/skills/provider/` | 待迁入，现为[服务方端SDK](../../接入/服务方端SDK.md)、[服务方技能](../../接入/服务方技能.md) |
| 宿主适配 | `src/hosts/jiuwen/ioalab_jiuwen/` | 待迁入，现为[九问网页通知](../../接入/九问网页通知.md) |

组内依赖方向为 宿主适配 → 两角色端 → 共用运行时；共用运行时的 `__main__` 反向导入两角色装配入口，属已知偏离，迁入时登记票据。迁入顺序见[设计文档按模块重组](../../工程/专题/设计文档按模块重组.md)。
