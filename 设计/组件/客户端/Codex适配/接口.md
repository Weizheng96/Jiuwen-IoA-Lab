# Codex适配

## 目的与范围

经用户已有Codex App Server的公开stdio协议实现AgentHost，供两角色SDK调用。只执行固定SDK工具轮次，不接管用户当前桌面聊天，不制定业务规则；产品接入与通知见客户端17。

## 独占数据与配置

| 数据或配置 | 说明 | 存储 |
|---|---|---|
| 宿主配置 | command为Codex可执行argv，model为显式模型名，可选skill_directories为业务技能名到绝对目录的映射；不包含模型密钥 | 本机host区域 |
| 轮次与会话绑定 | requestId、operationId、Session、定义摘要、真实状态与用量；续接核原工作目录与定义 | 轮次目录codex-session.json及runs/ |
| 认证与模型 | 使用已有Codex自身认证；不复制其私有凭据、聊天历史 | 用户已有宿主配置 |

## 接口

### AgentHost实现

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| CodexHost.from_config(value,base_dir) | 显式构造，无进程副作用 | command、model及可选skill_directories；返回CodexHost | 非法字段invalid_input | codex_host |
| probe()、capabilities() | 握手、模型及必要协议能力检查 | available、model、protocol、features、reason；探测不调用模型 | 缺能力或模型not_ready，不自动换模型 | codex_host |
| run(HostTurn) | 创建或恢复原线程并运行一轮 | 返回HostResult；工具回调还原原名称及callId；输出契约保留 | 原定义/Session变化identity_conflict；未探测或未支持能力not_ready；断流unknown，不重发 | codex_host |
| cancel(operation_id) | 中断原操作全部在途轮次 | 是否找到轮次；发送turn/interrupt并等待实际终态 | 找不到false；无法取得终态为unknown，不能当作没有副作用 | codex_host |

probe只证明本机协议与模型目录可用，不证明实际推理授权或业务就绪。原生交互回调首版为false；模型问题不能伪造用户答复，产品层继续使用SDK确认入口。动态工具使用独立ioa_sdk命名空间，实际版本中需保留code-mode host协议承载，同时关闭代码执行功能。工具输出的捕获/显式展示约定纳入固定定义；stdio消息至多4 MiB、入站队列256项、出站队列32项，阻塞写入不得越过轮次期限；关闭只终止本适配器创建的进程。

## 不变量

| 规则 | 说明 |
|---|---|
| 真实绑定 | 必须在首次SDK工具回调前保存并报告真实threadId；续接必须使用原Session及定义摘要，不新建替代线程 |
| 固定工具 | 工具仅来自本轮ToolBinding和冻结技能读取器；禁用shell、联网搜索、应用、插件及无关工具加载；无法落实时不得报告就绪 |
| 有限能力 | 首版不支持原生生产工具，要求启用时必须not_ready；capabilities明确列出限制 |
| 原样结果 | 必须保留原工具JSON、用量和错误；轮次中断/断流不能自动重发；只向on_event转发所属线程事件 |
| 用户边界 | 不得将工具执行批准视为合同/付款批准；缺可信答复保持等待，业务批准只经SDK受控确认入口 |
| 只用公开能力 | 不得读取宿主私有历史库、改全局配置或绕过宿主权限；本机验证只创建本任务线程与文件 |
