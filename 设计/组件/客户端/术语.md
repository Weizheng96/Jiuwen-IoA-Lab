# 客户端 · 术语

只收客户端子模块独有的术语；被两个以上模块使用的术语在[术语地图](../../术语.md)，如宿主接口、收信规则、原操作。

## 共用运行时

**常驻实例**：同一 data_dir 唯一的 SDK 写入进程，持有账号会话、身份、运行库与平台连接。
_Avoid_：守护进程、后台服务。代码：`ResidentRuntime`

**角色模块**：向常驻实例登记操作、作业处理器与就绪 profile 的业务模块，当前为个人助手端与服务方端。
_Avoid_：角色执行器、插件。代码：`bind(runtime)`

**装配入口**：构造宿主、角色模块与业务工具并注入常驻实例的进程入口。
_Avoid_：启动器、bootstrap。代码：`python -m ioalab_jiuwen serve`、`ioalab_sdk.access`

**作业**：调度器持久化的角色工作单元，同交互与同 Session 串行，可等待、续接或停在 unknown。
_Avoid_：任务（与 A2C Task 混淆）。代码：`Scheduler.submit`、`JobHandler`

**执行连接**：心跳租期内有效的平台连接，是调度新作业与发起外部效果的前提。
_Avoid_：在线、TCP 连接。代码：`AgentConnection.connected`

**确认记录**：绑定账号或智能体、原操作、对象摘要、阶段与期限的用户决定，是唯一批准来源。
_Avoid_：用户同意文本、confirmed。代码：`Confirmations`

## 宿主契约

**轮次**：宿主以固定 Agent 定义执行或续接原 Session 的一次受限工具运行，结果为实际状态、Session 与用量。
_Avoid_：调用、回合。代码：`HostTurn`、`HostResult`

**定义摘要**：冻结在交互上的指令、工具策略、技能与原生工具的摘要；续接与恢复须与之一致。
_Avoid_：配置哈希。代码：`definition_digest`

**技能快照**：首轮冻结的所选业务技能文档及摘要清单；续接只读它，缺失或被改即停止恢复。
_Avoid_：技能缓存、技能副本。代码：`FrozenSkills`

**业务工具工厂**：按名称从入口点组 `ioalab.business_tools` 加载、为一个 profile 构造 `BusinessTools` 的可调用对象，构造无副作用。
_Avoid_：工具插件、导入路径。代码：`ConfiguredTools`

**会话接收**：原版公开历史接口已持久化通知的回执状态，不表示主人已读。
_Avoid_：已送达、已读。代码：`session_received`

## 个人助手端

**入站轮次**：按平台受理时冻结的规则修订，为一条来信调用一次宿主；只能调用声明的工具和回复工具。
_Avoid_：收件任务、自动回复。代码：`ioa_reply`

**本地交互句柄**：SDK 提供的本地引用，自动携带已登记的交互 UUID 和修订，避免模型抄写标识。
_Avoid_：交互 ID（指平台 UUID 本身）。代码：`interactionRef`

**委托任务**：一次用户需求在本机的用途、预算与授权范围，跨多家候选共用。
_Avoid_：委托单、scope。代码：`taskRef`

**报价引用**：一家候选的本机征集记录，指有效签名提案或待批准的未签算价卡。
_Avoid_：quote id、候选卡。代码：`quoteRef`

**合同引用**：已确认具体合同的原卡摘要，所有履约操作的唯一句柄。
_Avoid_：订单号、作句柄时的 cardDigest。代码：`contractRef`

## 服务方端

**服务 profile**：本地实例里一个服务身份的配置键，各自有身份、公示、容量与业务状态。
_Avoid_：服务键、服务名。代码：`provider.services.<profile>`

**本单工具**：运行时为一次委托固定身份、交互、Session 与阶段后提供给宿主的 `provider.task.*` 工具。
_Avoid_：任务 RPC、inspect 工具。代码：`ToolBinding('provider.task.quote', …)`

**恢复方式**：生产续接的依据，取运行时核验的宿主终局或所有者审阅之一。
_Avoid_：重跑、重试。代码：`recoveryMode`（`runtime_verified`、`owner_review`）
