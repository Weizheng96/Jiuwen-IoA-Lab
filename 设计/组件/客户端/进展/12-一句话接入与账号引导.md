# 12：一句话接入与账号引导

**目标行为：** 用户给自己的九问 Swarm 一句“参考 GitCode 仓库的 readme_agent.md，帮我接入 IoA Lab”，九问读取平台网页说明、自动下载完整接入包，引导用户加入“我的技能”；用户完成导入和加载后，在会话选择“提供已有账号”或“帮我注册”，完成本机配置、安装、启动及实际就绪核对。

**阻塞于：** 无

**状态：** ready

**验收环境：** 可独立设计和开发，服务器验收使用[新服务器验收基线](../../../工程/实施资料/部署发行.md#新服务器验收基线2026-11-11)。

**范围：** 共用运行时[账号与登录](../共用运行时/接口/账号与登录.md)、[安装与实例](../共用运行时/接口/安装与实例.md)、[配置](../共用运行时/接口/配置.md)、[用户确认](../共用运行时/接口/用户确认.md)，两角色产品技能及宿主适配；依赖平台身份中心[账号注册与登录](../../平台/身份中心/接口.md#账号注册与登录)、web服务[接口](../../平台/web服务/接口.md)、网页UI[接口](../../平台/网页UI/接口.md)。跨模块顺序见[专题](../../../工程/专题/接入易用性与Agent调用效率.md)。

**定向测试：** access_products、background_installation、package_installation、installation_identity、account_enrollment、account_rewards、authentication_recovery、user_browser；设计定稿后补下载引导、账号录入和代注册恢复用例及原生九问实机验收。

## 现状与初始方案

本票为需求登记，尚未变更现行接口或实现。现有技能 ZIP 已携带 SDK、九问适配和安装脚本，用户仍需手动下载、导入及填写配置；SDK已有显式登录恢复机制。实施前按 design 更新所属接口页与流程、升版，再开发。

1. GitCode 主仓根目录新增 `readme_agent.md`，说明九问可执行的接入顺序及平台网页入口；网页提供当前部署的下载信息。实施设计明确地址来源、下载发现、包校验与兼容性契约，用户无需另行下载独立客户端。
2. 未指定角色时默认个人助手；明确提供服务时下载服务方包；双角色增装另一技能并复用原配置、依赖环境和常驻实例。
3. 九问下载后给出包的实际本地位置和原生导入步骤，等待用户加入“我的技能”并实际加载，然后呈现两种账号选项；下载、导入和读取 Skill 分别核对，不伪报启动成功。
4. “提供已有账号”：客户端在未登录、未连接平台时也能打开本机账号输入界面，用户直接输入账号密码，客户端安全保存并认证；密码不经模型、聊天、普通回执或日志传递。
5. “帮我注册”：客户端在本机生成账号名和随机密码，经公开注册接口创建账号并安全保存；九问只获得账号和结果，用户可通过本机界面查看并保管生成凭据。明确重名后可生成新名称；邀请制缺码、关闭注册、限流和网络错误返回具体下一步，不改变平台注册策略。
6. 账号完成后自动推进可确定的配置、安装、绑定、连接及状态检查；无法可靠确定既有九问位置时只询问必要宿主信息。凭据录入不得依赖已经登录的常驻实例。
7. 各阶段保留进度与恢复引用。注册提交前保存原操作和凭据，响应未知先恢复原注册，不换账号重复创建；重复接入复用原账号、身份和实例，不覆盖未知操作或原数据。

## 验收项

- [ ] 从未安装接入技能的已有九问开始，经指定指令、真实 GitCode 引导和平台网页自动下载正确完整包，用户无需查找独立客户端或手写命令
- [ ] 明确等待用户原生导入及实际加载，再呈现“提供已有账号”“帮我注册”；默认个人助手、明确服务方和双角色路径均正确
- [ ] 已有账号路径实际弹出本机输入界面；正确/错误密码、取消和重新输入均正确处理，模型及日志无秘密
- [ ] 代注册实际创建账号、安全保存凭据并接入；重名、邀请制、关闭注册、限流、丢回执及重复调用不产生重复账号或重复赠币
- [ ] 账号、身份、连接、宿主及角色能力分别核对；未完成服务配置、公示和开放接单时不宣称可接单
- [ ] 中断后从原阶段恢复，双角色共用实例，保留既有九问安装、全局配置及运行数据
- [ ] 同步网页、产品技能和发布包；以实际发布的 GitCode 入口及新服务器完成原生九问全过程验收，记录版本、回执和未验证范围
