# 13：Agent流程入口与自动推进

**目标行为：** 委托交易、助手通信、服务发布与接单管理各提供一个 Agent 流程入口，九问 Swarm 只提交业务输入及原流程引用；客户端连续推进确定性步骤，在需要业务判断、补充输入、真实确认或外部等待时返回明确下一步，避免九问自行推导底层接口顺序。

**阻塞于：** 无

**状态：** ready

**验收环境：** 与[客户端12](12-一句话接入与账号引导.md)独立设计和开发，最终组合验收使用[部署05](../../部署/进展/05-新Linux服务器部署与验收基线打通.md)的新部署。

**范围：** 个人助手端、服务方端、共用运行时[操作目录](../共用运行时/接口.md#装配与常驻实例)、[调用与启动](../共用运行时/接口/调用与启动.md)、[本地执行与恢复](../共用运行时/接口/本地执行与恢复.md)、[用户确认](../共用运行时/接口/用户确认.md)及两角色产品技能；平台依赖以[委托交易](../../../流程/委托交易.md)、[助手通信](../../../流程/助手通信.md)、[服务方接入](../../../流程/服务方接入.md)所链接口为准。跨模块顺序见[专题](../../../工程/专题/接入易用性与Agent调用效率.md)。

**定向测试：** assistant_flow_guidance、operation_catalog、access_products、user_confirmations、protocol_operations、inbox_rules、service_publication、task_recovery_receipts；定稿后补流程推进、断点续接与效率对比用例。

## 现状与初始方案

本票为需求登记，尚未变更现行接口或实现。当前已有委托 `begin` 组合调用和部分 `nextActions`，但九问仍需读多份说明、选路、提取引用及查询异步结果。接口粒度和引导复杂度是待验证原因，尚无本轮分阶段耗时数据。实施前先测量、设计并按 design 更新接口与流程、升版，再实施。

1. 固定需求、模型/宿主、服务及版本，测量原生 Skill 读取次数、工具/SDK调用次数、模型轮次、输入输出量及总耗时；区分模型判断、网络、生产、用户等待，保存调用顺序、重试原因及各阶段耗时。
2. 逐步分析三类交互的输入、效果、自动推进条件和等待点；每类只向 Agent 提供一个稳定流程入口，以业务动作和原流程引用启动、补充、观察及恢复。助手通信包含发信、多轮交流及收信设置；服务方包含发布与接单管理，入站本单执行仍由可信运行时调度。
3. 确定性编排归所属角色模块，共用运行时持久化进度并调度恢复；复用原平台接口和 A2C 实现，不建立第二套协议或执行链。底层原子操作按职责保留在内部或诊断面，不以兼容别名增加 Agent 学习负担。
4. 客户端自动处理已确定对象的查询与引用传递、校验、已授权动作的连续调用、结果接收和状态收敛；批量步骤有界。模型无需逐个搬运签名、协议字段和操作标识，也无需为了确定下一接口而新增推理轮次。
5. 业务匹配、规格拟定、候选比较和选择、成果判断等语义工作保留模型或用户决定；返回必要业务证据和明确待办，不用硬编码选择替代判断，不用摘要替代合同及验收器的必要审阅。
6. 回执统一表达稳定流程引用、真实状态、完成摘要、等待原因、所需字段及格式、继续方式；客户端推进到下一个实际等待点再返回。异步任务由后台或推送续接，给出查询时机，避免模型高频轮询和重复读同一说明。
7. 需要批准时准备真实待确认事项并打开现有可信入口，真实决定后恢复原流程；保持任务授权、具体合同、合同环节、验收及付款边界。拒绝、过期及未知结果按原语义处理，不换操作标识绕过。
8. Skill 只保留流程入口、业务输入、等待与恢复说明。与[客户端12](12-一句话接入与账号引导.md)联调接入后的业务使用；不纳入尚未实现的委托分解和悬赏。

## 验收项

- [ ] 完成三类交互的调用图与耗时基线，区分已证实瓶颈和推测，列明每一步自动执行或等待的依据
- [ ] 每类交互经一个入口完成启动、补充、观察和恢复，原生九问无需选择底层操作或手工搬运协议原件及恢复标识
- [ ] 三类各至少一个完整真实场景，另覆盖收信设置、服务暂停/恢复及多期合同；确定性连续步骤之间不调用模型决定下一接口
- [ ] 每个等待点有明确原因、必要字段和可执行续接指引；缺材料、业务选择、真实确认、外部处理及未知结果可区分
- [ ] 逐对象、逐阶段真实确认有效；拒绝、过期、断线、丢回执、重启和重复调用均恢复原流程，无重复签名、收费、生产或通知
- [ ] 服务管理与入站本单执行权限分离，外部消息不能借流程入口改配置、发布或扩大权限
- [ ] 同场景比较优化前后调用次数、模型轮次、读取量和分阶段耗时，确定性串联步骤的 Agent 调用减少；报告实际改善与未改善原因，不以用户等待或生产差异冒充优化
- [ ] 完成定向与链路回归，并在新服务器和原生九问真实模型中验收，记录实际版本、证据及未验证范围
