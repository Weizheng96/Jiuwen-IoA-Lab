## 实现与待验收

通用委托、合同环节、验收付款、解除/争议及服务方发布/接单/原任务管理已实现；实际 HTTP/WSS、文件验收及付款定向通过。真实模型生产质量、完整多期 UI 与新服务器各异常分支未逐项验收。 实际证据见[开发记录](../../../工程/实施资料/MCP接入开发.md)。以下条目继续作为验收范围。

1. 通用需求表达目标、材料、范围、约束、交付、期限、预算和验收；用户提出制作小程序时只填入业务值，不专设小程序协议或生产路径。
2. 按现有 SDK 推进授权、发现、报价/候选比选和合同准备；页面展示原业务证据与真实对象，业务判断仍由模型或用户完成。
3. 任务授权、具体合同、合同环节、验收和付款保留各自依据与所需真实确认；不能把一次表单提交视作整个流程的无限授权。
4. 按既有 A2C/支付边界处理履约、补充材料、交付、验收、付款、结清及拒绝、终止、争议和未知结果；页面不定义另一份状态机。
5. 服务方表单覆盖通用服务规格、报价/容量、生产配置、公示、开放/暂停接单与本单交付；管理权限与入站本单执行分开。
6. 页面分别归 `registry/`、`delegation/`、`payments/` 和 `provider/`，共用 `shared/` 只做页面导航；MCP、浏览器、Skill/CLI 共用同一业务操作。本期不实现悬赏或委托分解。
