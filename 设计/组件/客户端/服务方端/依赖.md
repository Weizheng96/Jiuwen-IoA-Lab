# 服务方端 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../../架构.md#模块表)的依赖图持有。平台各中心只经网络到达，本模块不导入平台、官方服务或具体宿主的代码。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 共用运行时 | [流程日志](../共用运行时/接口/本地执行与恢复.md#本地数据所有权)：`FlowJournal` | 原公示及管理流程检查点、稳定子操作恢复 | 进程内 | 真实运行时及公开IPC |
| 共用运行时 | [配置](../共用运行时/接口/配置.md)、[调用与启动](../共用运行时/接口/调用与启动.md)：`RuntimeFault`、`encode`、`instant`、`stamp`；运行时的 `connection.call/wait`、`account.api/fetch_package`、`store` 检查点与交互、`require_execution`、`stop_requested` | 错误对象、配置、WS 控制调用、HTTP 调用、本地持久化 | 进程内 | 真实运行时配合真实平台 |
| 共用运行时 | [本地执行与恢复](../共用运行时/接口/本地执行与恢复.md)：`JobHandler`、`JobOutcome`、`scheduler.submit/get/resolve/requeue/resumption/records/stop_pending`；`AgentDefinition`、`HostTurn`、`ToolBinding`、`validate_output`；`questions.native_answer`；`observations.model_port` | 作业登记与恢复、宿主轮次、业务工具输出校验、原生提问转用户确认、验收模型端口 | 进程内 | 显式宿主替身（`AgentHost`） |
| 共用运行时 | [操作目录](../共用运行时/接口.md#装配与常驻实例)：`runtime.catalog.PROVIDER`、`fields`、`handled_by` | 登记本角色操作并按目录的输入形状检查参数 | 进程内 | 真实目录 |
| 共用运行时 | [用户确认](../共用运行时/接口/用户确认.md)：`confirmations.find/ensure/claim` | 公示与生产恢复的本机用户确认 | 进程内 | 脚本化浏览器或确认时钟 |
| 共用运行时 | [A2C适配](../共用运行时/接口/A2C适配.md)：`ProtocolStore`、`SessionTransport`、`EndpointSession`、`transport.stable`、`market.read_reputation`、`reports.report`、`arbitration.verify_case`；[本地业务工具](../共用运行时/接口/本地业务工具.md)；`templates.draft_from_terms` | 本单 A2C Provider 的存储与传输、协议回复、稳定操作标识、信誉读取、自测报告、模板起草、案件与裁定文书验签 | 进程内 | 真实适配器 |
| web服务 | [HTTP入口](../../平台/web服务/接口/HTTP入口.md#http-入口)：服务分类、分类预览、发布与状态、原操作查询、验收器包上传与读取；[仲裁接口](../../平台/web服务/接口/仲裁接口.md#仲裁接口)：`GET /api/v1/arbitrations` | 公示、验收器、信誉与恢复查询、按原 admission 读取当前案件 | 自有远端 | 测试进程内真实平台 |
| web服务 | [WebSocket与消息封套](../../平台/web服务/接口/WebSocket与消息封套.md#websocket-帧)：`request.start`、`message.send`、`admission.status/configure/reserve/commit`、`a2c.market`、`arbitration.finish`；系统消息 `contract.ruling` | 接单、策略、回复与市场签认、裁定后结束回执 | 自有远端 | 测试进程内真实平台与真实套接字 |
| 委托中心 | [接单策略与预留](../../平台/委托中心/接口/接单与容量.md#接单策略与预留)、[拟卡费、提案与复签](../../平台/委托中心/接口/接单与容量.md#拟卡费提案与复签) | 容量与策略的实际语义，经 web服务 到达 | 自有远端 | 同上 |
| 注册中心 | [分类目录与预览](../../平台/注册中心/接口.md#分类目录与预览)、[签名发布](../../平台/注册中心/接口.md#签名发布)、[部署发布授权](../../平台/注册中心/接口.md#部署发布授权) | 公示与授权的实际语义，经 web服务 到达 | 自有远端 | 同上 |

## 外部依赖

| 包 | 用途 | 版本来源 |
|---|---|---|
| `a2c`（`provider`、`card`、`template`、`slots`、`jws`、`codec`、`binding`、`common`、`payment.ap2`、`verifier`） | 原 A2C Provider、卡与模板校验、签名、A2A 传输、AP2 退款、验收器包与沙箱 | `src/client/sdk/pyproject.toml` 固定版本，发行锁 `src/client/skills/_shared/requirements.lock` |
| `httpx` | 平台 HTTP 错误类型与公共 A2A 客户端 | 同上 |
| `jsonschema` | 本单工具与报价输入校验 | 同上 |
| `wasmtime` | 验收器语法沙箱的错误类型；经 `a2c` 间接安装，未在 pyproject 直接声明 | 发行锁 |
