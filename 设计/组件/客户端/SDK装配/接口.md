# SDK装配

## 目的与范围

SDK 自带的进程装配与命令入口：`ioalab-access` 与 `python -m ioalab_sdk.access` 由本模块提供，构造两角色模块、提供服务方配置校验和可编辑字段，并把它们注入共用运行时的命令执行函数 `run`。本模块不含业务规则、不建宿主，也不读写数据；共用运行时不导入本模块。九问宿主的装配归[宿主适配](../宿主适配/接口.md#命令行)。

## 独占数据与配置

无。配置与数据都由共用运行时和两角色读取。

## 接口

### 命令装配

| 接口 | 用途 | 输入与结果 | 拒绝与恢复 | 测试 |
|---|---|---|---|---|
| `access.main(argv)`：控制台脚本 `ioalab-access`（`ioalab_sdk.access:main`）与 `python -m ioalab_sdk.access` | SDK CLI 的唯一命令入口：把 `modules`、`validate`、`service_fields` 交给 `runtime.run` | 子命令、输出与退出码同[本机生命周期与调用](../共用运行时/接口.md#本机生命周期与调用)的 `run` | 同共用运行时 CLI | access_products、configuration_boundary、configuration_edit、cli_encoding、resident_runtime、package_installation |
| `modules()` | `serve` 构造的角色模块 | `(AssistantRole(), ProviderRole())`，不注入宿主与业务工具 | 角色构造异常按 CLI 规则 failed | resident_runtime、installation_identity |
| `validate(config)`、`service_fields()` | `validate`、`configuration`、`configure` 的服务方配置校验与可编辑字段 | 调用 `validate_provider(config.provider,config.identities)`；返回 `EDITABLE_SERVICE_FIELDS` | 校验失败 invalid_input | configuration_edit、configuration_boundary |

## 不变量

| 规则 | 说明 |
|---|---|
| 只装配 | 本模块只能导入两角色与共用运行时的入口，不得写业务规则或加命令；新子命令归共用运行时 |
| 命令一致 | `ioalab-access` 与 `python -m ioalab_sdk.access` 是 SDK CLI 仅有的两个入口，子命令、输出与退出码必须与共用运行时 `run` 的契约一致；不保留 `python -m ioalab_sdk.runtime` 等旧入口 |
| 无宿主 | 本模块构造的角色不带宿主，需要模型轮次的装配归宿主适配 |
