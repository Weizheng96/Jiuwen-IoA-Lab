# 共用运行时 · 账号与登录

本页是[共用运行时](../接口.md#接口)的子页。平台凭据契约唯一归[设备会话](../../../平台/身份中心/接口.md#设备会话)。

## 设备登录与凭据

一个账号目录具有稳定设备安装标识；同机不同宿主经显式绑定共用该目录，不复制会话、不改变身份及单执行者租约。配置保存平台、用户名、数据目录及 credential_ref，密码只用于受控登录或旧配置显式迁移。系统凭据组件通过 macOS Keychain、Windows Credential Locker、Linux Secret Service/KWallet 保存加密主密钥，数据目录的 credentials.enc 原子保存加密会话和未决认证输入；密文绑定平台、账号与原绝对目录。无人值守服务可显式使用 CREDENTIALS_DIRECTORY/ioalab-vault-key 受管凭据挂载，要求运行用户独占、普通文件且位于客户端数据目录外；不从业务配置或同目录查找密钥。不可用、已锁定、密钥丢失或密文损坏均返回 credential_store_unavailable，保留原数据，不降级明文或自动重建原密钥。

短期访问凭据仅在客户端内存及加密会话记录存在，普通 SQLite、配置、MCP 回执与日志不包含密码/令牌。账号库仅保存归属、设备标识、公开会话摘要及原请求引用。注册恢复的密码/邀请码等输入也只放加密记录；成功后移除临时输入。自动生成的注册密码仅在受控页面提供一次取回并由用户保管，不能进入模型；用户可明确清除临时恢复信息。

## 公共操作

| 操作 | 输入与输出 | 测试 |
|---|---|---|
| `CredentialVault` 与配置迁移 | 系统密钥、加密会话、密码移除与原归属；失效拒绝明文回退 | device_credentials |
| `account.login` | 显式意图、配置引用；有效会话复用，无效时经受控页面取得密码；普通工具不接受密码 | authentication_recovery |
| `account.refresh` | 无秘密参数；单写者恢复原续期操作，不登录、不赠币；明确撤销/到期要求重新登录 | authentication_recovery |
| `account.setup/status` | 受控注册、登录、重新登录、设备列表及撤销；公开状态只含账号/有效期/阶段 | onboarding |
| `runtime.status` | 身份、连接、队列、等待与认证状态，不返回凭据 | resident_runtime |
| `runtime.stop` | 排空进程，不取消业务、不撤销会话 | resident_runtime |
| `runtime.open_ui`、`confirmations.get` | 用户页及原确认摘要；登录不替代业务批准 | trusted_user_port |
| `operations.get/resume` | 原完整引用，恢复原业务，不因登录或页面重开重复创建 | task_recovery_receipts |

## 恢复与迁移

登录、续期发送前持久保存稳定 operationId；续期状态和凭据在同一加密记录原子更新。超时、5xx、限流或无法识别的回执保留原操作；下次只重传相同凭据及 operationId。先验证不可变账号 ID、平台、设备和会话，再持久新凭据。换号不能覆盖旧目录，错误或撤销不会自动回退密码登录。

旧 password/password_env 配置在显式 account.login、账号页恢复或显式启动原客户端时走同一迁移登录；不另建长期密码认证链。未在线验证的旧配置不能以离线模式完成迁移。迁移持原 client.lock，复核配置摘要，先验证系统凭据库可写、创建/恢复设备会话并在线核对账号，再原子移除配置密码字段、写 credential_ref。清除旧账号库中的凭据及 SDK 自有注册恢复记录秘密；不触碰原身份、私钥、业务数据或用户备份。中断时从加密记录的原操作恢复，不能把失败当作迁移成功。仅持旧平台 Token 的客户端须显式重新登录，不能静默延长旧登录态。

账号页提供设备名称、登录时间、到期与状态及当前会话标识；撤销仅能由受控页面触发，模型工具无通用撤销权限。当前客户端退出须先安全排空并停止实例，再服务端撤销、清除本地会话；网络未知时保留撤销引用供恢复，不宣称远端退出成功。撤销其他设备不删除该设备业务数据。远端撤销后 HTTP 拒绝、长连接失效，本地停止接新业务并保留未决操作；原审批、付款及合同不因重新登录被重复执行。

受控账号页的 `/user/devices` 提供 list、revoke(sessionId)、resume 和 login(password)，均校验本机浏览器会话、Origin、CSRF 和原 client.lock；无通用模型工具入口。撤销前保存目标和原短期授权；丢回执恢复同一目标，授权到期则受控重新登录后恢复，不能静默改目标。`/user/credentials` 只允许一次取回程序生成的注册密码或明确 discard；手输密码不提供查看。尚未领取的生成密码属于待用户保管的加密临时记录，不用于自动登录。

旧版已完成注册记录没有“程序生成”标志，其原密码在清除明文时作为一次性用户取回记录保留；该迁移特例不用于自动认证。新版本手输密码仍不提供取回。

## 首次账号引导

角色 Skill、CLI `account-setup` 与 MCP `ioa_setup` 共用一个账号页控制器及 Onboarding。初始探测默认或显式平台地址，仅失败后询问地址；原账号及未决注册绑定的平台和角色不可被新输入替换。受控页重开复用同一工作进程并发放新的一次性入口，模型只收到公开进度。注册发送前加密保存原操作，未知结果仅恢复同一请求；旧 account-setup.json 在显式恢复时迁移至加密记录并清除 SDK 自有明文，原账号、目录和赠币结果保持不变。

SDK 注册直接复用原注册回执的设备会话，初始设备标识为原注册操作标识；在线核对原账号后加密持久，不追加一次奖励登录或第二个会话。首次登录失败或回执丢失仍恢复同一注册。
