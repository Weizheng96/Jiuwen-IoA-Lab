# 共用运行时 · 调用与启动

本页是[共用运行时](../接口.md#接口)的子页。

## 包结构与调用边界

| 对象 | 规范职责 |
|---|---|
| `ioalab-sdk` / `ioalab_sdk` | 源码归 `src/client/sdk/`，提供 assistant、provider 两个角色入口及共用 runtime |
| 共用运行时 | SDK 的常驻运行方式；唯一持有该实例私钥、SDK 业务数据库及连接 |
| 接入技能脚本 / CLI | 读取非模型配置、发送结构化本地请求、显示真实回执；不再实现签名和业务状态机 |
| A2C 适配 | 复用 A2C Client/Provider、验签、算价及 WASM 验收；IoA transport 接入推送及本地任务视图 |
| `ioalab-jiuwen` / `ioalab_jiuwen` | 源码归 `src/client/hosts/jiuwen/`，实现可选 AgentHost 适配及接入启动装配，通过原版公开接口连接九问 |

项目目录、发行包及 VERSION 归属统一见[架构](../../../../架构.md)。核心 SDK 不导入平台、九问或官方业务工具；九问适配包依赖 SDK，并在启动入口构造宿主对象、注入运行时及角色处理器。宿主能力契约见[模块与依赖](本地执行与恢复.md#模块与依赖)，不建立另一套角色执行器。

九问调用可能附带 call_goal 等已知展示元数据。适配层只在宿主声明中接纳其对应字段，分离后将原业务参数交给 SDK 严格校验；不扩大业务 Schema、不把元数据当作权限或执行指令，也不修改九问源码。业务 Schema 已显式定义的同名字段按业务字段保留，适配不得静默删除。

共用运行时各子页的点分名称是 SDK 能力及脚本操作契约。脚本形式统一为 `python "<skill_directory>/scripts/ioalab.py" <operation> --config "<外置配置文件>" --args-file <UTF-8参数文件>`；具体 Python 类封装不另定义业务含义。参数文件须先实际创建，结果必须来自脚本真实输出。

业务调用经过本机认证的 IPC 或回环 API；CLI 不打开运行时身份库。启动引导可创建运行时，但失败必须返回未就绪，不能退回脚本自行持有私钥执行。长连接由运行时维持，不靠模型循环调用平台收件接口。

## 本机调用与启动

| 项 | 契约 |
|---|---|
| 常驻入口 | SDK 提供运行入口；九问适配包在自己的入口装配宿主及角色处理器，不修改 SDK 的分发器 |
| 配置入口 | start、serve、validate和call均使用--config；SDK统一读取UTF-8 JSON（包括Windows UTF-8 BOM）并解析相对数据目录，不另提供call --home别名 |
| 读取归属 | 产品引导只安装、检查固定产品元信息并转交配置/参数文件路径；不自行解析账号配置。SDK负责共用配置、参数文件和原操作标识；宿主经同一SDK读取配置后校验自己的命名区域 |
| 调用前检查 | 诊断与安全停止仅从配置定位data_dir，不要求密码、角色或宿主业务配置仍完整；普通业务完整校验当前配置、账号、配置摘要和安装，并固定同一bootId再提交 |
| 参数文件 | 独立于账号配置和SDK数据目录；同一实际文件（含硬链接/路径别名）或SDK运行数据不得作可回写参数，拒绝发生在添加operationId或任何业务请求之前 |
| 本机端点 | 只监听 127.0.0.1 的随机端口，POST `/v1/call`；拒绝任意 Origin、非本机 Host、无访问凭据及超限请求；不提供跨域访问 |
| 请求 | operation、operationId、arguments 三字段；显式登记操作，禁止任意反射/执行；默认最大128 KiB |
| 返回 | 使用[统一操作结果](操作与恢复.md#操作返回与恢复)；业务未就绪明确返回，不能因为本机 HTTP 成功而报告委托成功 |
| 端点发现 | CLI 只读 data_dir 中 runtime.json，验证回环地址及实例；不打开 SDK SQLite 或私钥文件，不把本机访问凭据打印给模型 |
| 生命周期 | runtime.start 验证受限配置并启动；runtime.status 查询当前实例；runtime.stop 拒绝新业务、等待当前轮次收敛并关闭连接，保留所有数据及原业务状态 |
| 原操作 | 变更请求的 operationId 在发送前保存；超时返回 unknown，恢复沿用原标识；已持久入 outbox 表示本地接受，不表示平台送达或业务完成 |
| 未知能力 | 没有对应处理器或宿主能力时返回 not_ready；不能落回旧脚本直接执行或接受 confirmed=true 自证授权 |

共用配置用 JSON 保存 platform_url、username、password（或 password_env）、data_dir；相对路径以配置文件目录为基准。data_dir 是 SDK 专用目录，配置及调用参数文件保存在其外；检测到混放的无关数据时拒绝启动，不修改它们的权限。运行目录及凭据文件使用所属用户权限，Windows 使用用户 SID 的 ACL，不能把只读写标志视为 ACL。identities 为本机激活的 profile 列表，每项含 key、role（assistant/service）、name；key 对应本地持久身份，不是账号名或用户手填 UUID。最多一个助手及总计64个身份，默认模型并发2、待处理上限128，分别由 max_model_runs、max_pending_requests 配置。角色业务与宿主配置使用独立命名区域，由相应装配模块校验，SDK 不加载配置中指定的任意 Python 类或脚本。

本机查询声明waitSeconds时，取值为0至30秒；客户端传输预算须覆盖该显式等待及5秒传输余量，不得在服务端允许的等待尚未结束时提前将查询报为unknown。无等待的调用继续使用原传输预算，超时不会授权重做业务效果。

原生技能模型未必能看到宿主返回的目录元数据。产品共用定位页按公开JIUWENSWARM_DATA_DIR，或JIUWENSWARM_HOME下的默认.jiuwenswarm目录，确定当前技能唯一脚本；若目录布局不符则明确未找到并请求实际导入位置，不递归扫描项目或读取私有配置。

本机状态分别列出进程/IPC、认证、身份绑定、平台连接、宿主和角色执行能力。状态查询从当前调用环境复核实际安装；不匹配时保留观测数据并返回明确安装错误，不能以旧实例在线、同名版本号或身份已绑定报告新包就绪。诊断仍可取得实际状态，安全停止不受匹配失败阻断。只收到 WS 消息不能报告业务处理完成；离线、缺宿主或缺规则时可靠保存消息并保持未执行。

脚本、SDK CLI、宿主装配CLI及随附业务CLI的标准输出统一使用UTF-8；结构化结果为JSON，诊断标准错误也使用UTF-8。产品技能脚本将真实结构化结果重新序列化为ASCII转义JSON，使宿主按不同代码页解码时仍保留相同中文值；不更改SDK原记录或根据回显重写业务输入。原SDK结果缺失或结构不可识别时保持unknown，不能伪造明确拒绝或自动重做。参数读取区分文件不可读、非UTF-8、JSON语法及非对象；语法错误只报告行列，不暴露输入内容，也不建议改编码。
