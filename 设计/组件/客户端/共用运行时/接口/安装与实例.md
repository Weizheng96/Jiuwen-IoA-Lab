# 共用运行时 · 安装与实例

本页是[共用运行时](../接口.md#接口)的子页。

## 安装与实例核对

运行状态的installation在启动时冻结，包含format、environment（实际Python安装前缀）、releaseId、versions和assembly。产品安装器在依赖/版本/完整性检查后写入环境根的ioalab-release.json及.ready；前者保存格式ioalab.access-installation/1、清单摘要releaseId和发行包versions，后者保存相同摘要。运行时只读取本机安装元数据，不导入清单中的业务模块。两文件不一致、已安装版本不符或缺必需项时拒绝就绪，不修补正在使用的环境。

runtime.start同时核账号、非凭据配置摘要及installation；旧进程缺该信息、宿主装配不同、安装前缀或发布摘要改变，均返回installation_changed，要求显式安全停止后用原配置/数据目录启动。不能启动第二个写入者或删除状态来消除不兼容。

产品技能/CLI的普通角色或业务调用先核当前受认证运行状态的installation，再将请求固定到同一bootId；核对后实例发生切换时返回instance_changed，不向新实例发送业务。runtime.status、identity.status、confirmations.get、operations.get、runtime.open_ui和runtime.stop保留为旧实例诊断及安全停止入口，不由此开放新的业务效果。停止仍绑定实际bootId。独立serve主线程接收SIGINT/SIGTERM时只设置停止意图，随后通过同一调度器排空；拒绝新业务和新调度，原已运行作业可完成原授权工具。信号处理保持到连接、数据库及执行锁实际关闭，重复信号不强杀；嵌入其他线程的运行时由宿主管理信号。runtime.stop的completed只表示调度器当前无活动作业，不证明IPC、连接和目录写入者已全部释放；升级方仍需核对对应目录的OS锁，不得以答复或描述符消失替代。排空期间，仅由调度器认证为当前运行中、未等待用户的原作业上下文可继续执行工具；上下文须属于本实例且仍在活动集合中，异步工具回调保留该上下文。队列、已结束、等待用户或其他实例的上下文不能取得许可；平台连接、原授权、工具范围和期限照常核验，不通过普通RPC提供排空豁免。

未经过产品安装器的自管环境报告实际安装前缀、SDK及装配包版本，releaseId为空；不得冒充已核验发布。自管环境执行显式停止后升级，不支持对活跃进程原地热替换源码或依赖。安装信息只用于兼容核对，不代替身份认证、用户授权或工具权限。

## 安装与发布

原生流程页通过宿主技能加载接口的相对文件参数读取，不从参与方data_dir拼接技能路径。终端脚本使用原生返回的实际目录；若模型可见结果省略目录，限定在九问工作区定位所选技能，不增加安装搜索服务或修改宿主。

两个产品技能的源文件归 `src/access/skills/`，最小接入样例归 `src/access/examples/`。发布包包含配置模板、通用流程页、确定性脚本，以及清单锁定的 `ioalab-sdk`、`ioalab-jiuwen`、A2C 和九问 Process SDK 的本地 wheels；摘要与安装资源由构建工具生成，不回拷成为第二份源码。九问本体仍按[部署模块](../../../部署/接口.md)保存在 vendor，使用独立宿主环境。

原生通知准备也由引导转交配置路径、独立参数文件和产品角色给九问适配入口；适配使用SDK统一读取，核对profile实际归属与角色，不另写配置解析器。

配置完成后，经随包scripts/ioalab.py执行runtime.start。依赖已安装时校验配置并启动装配；缺依赖时只发起独立安装任务并快速返回waiting，随后按nextAction查询runtime.install.status。安装完成后再调用runtime.start，查询runtime.status与identity.status核身份、连接及宿主。runtime.install用于显式预装/重试已知失败；runtime.install.status仅查询，不触发安装。runtime.validate仅做配置检查；其他业务或诊断操作不得隐式安装，依赖未就绪时返回明确前置条件。runtime.*、assistant.*、provider.*是脚本操作参数，不是九问原生工具或商店动作。

普通依赖使用配置的国内包镜像，不现场拉取GitHub。检查用户已有九问的公开接口，缺少支持能力时返回具体未就绪项，不自动替换用户九问。读取脚本、清单或模型自述不能证明执行成功；须保留真实调用回执及实际状态，不根据源码推演或补写成功报告。

两种技能使用同一接入发布清单固定兼容组合，同账号、同本地实例复用安装环境和常驻组件。导入另一角色技能只增加相应配置；版本不兼容时先报告，不能再启动竞争的身份库写入者。SDK、适配包、技能和示例的设计依据分别按[架构](../../../../架构.md)记录，不把设计版本当成已实现版本。

产品本机配置使用本地运行时格式，两个技能默认读取~/.ioalab/settings.local.json；用户由settings.example.json创建该外置文件，不放在会被原生导入覆盖的技能目录中。脚本可通过--config指定其他配置，第二个技能继续复用同一文件及data_dir。配置与SDK持久数据目录也分开；分发和升级不携带或重建用户本机文件。不再回退读取技能目录中的旧位置。两个技能的公共脚本维护一份源，构建时生成各包的 scripts/ioalab.py；共用源及说明归 src/access/skills/_shared，已生成分发内容不另行手改。公共启动说明维护在_shared/references/shared-runtime.md，构建到两个产品的references/shared-runtime.md；角色setup页只保留自己的配置与业务差异。安装生命周期由共用scripts/installer.py负责，ioalab.py仅路由操作和转交用户文件路径；两脚本各只有一份共用源，随包生成。安装按依赖清单摘要releaseId共用一次尝试，以attemptId区分已知失败后的显式重试；不建立IoA交互或读取账号配置。前台短期启动锁防止重复创建，后台安装锁证明当前所有权；元数据读取与临时文件替换另共用短期元数据锁，不持此锁执行安装。PID/任务文件不能独立证明存活，元数据损坏仍返回unknown，不据锁或重启猜测修复。等待阶段返回stage=installation、原releaseId/attemptId、日志路径和下一步，明确requestSubmitted=false，原业务参数文件不回写。查询不创建任务；前台退出或工具观察超时不终止后台任务，不通过修改九问全局时限解决。后台仅继承必要系统环境和明确的包镜像配置，不继承平台/模型/通知凭据。

完成须核清单、wheels、依赖版本和pip check，再发布安装标记；标记与实际包不符拒绝原地覆盖。安装锁已释放且记录为明确failed时，修正原因后可显式runtime.install重试；记录仍为进行中但无实际所有者时返回unknown，保留环境和日志，不因PID缺失自动重新安装、删缓存或运行SDK。完成和失败的元数据只表达依赖安装，不代表SDK启动或业务就绪。

共用依赖约束在开发环境验证后随源发布，构建不通过读取服务器上已安装的参与方包来推导版本；平台构建技能包无需先把 Process SDK 装进核心环境。更改依赖时更新锁文件并补做隔离安装，两个包仍使用同一份清单。

本机 CLI validate --config 只读取并校验，返回配置摘要、数据目录和身份概要，不登录、签名或打开运行数据库。摘要覆盖账号标识、平台、数据目录、身份、并发及角色/宿主执行配置，排除密码实际值。runtime.status 返回本实例启动时的同一摘要；引导检查预期与实际摘要，存在差异时返回明确配置未生效和安全停止/重启提示，不能以旧实例存在报告新配置就绪。摘要不是登录证明或授权凭证，密码变更不作为此摘要的用途。

不得修改九问源码、全局指令、加载机制或全局 Python 环境。导入技能、成功安装、启动进程和业务就绪分别报告。失败不写就绪标记，升级先保留身份与业务状态，不能靠删库解决迁移。官方会议等业务工具按用户配置选装，不成为通用 SDK 或接入技能的必需依赖。
