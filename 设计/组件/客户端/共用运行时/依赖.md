# 共用运行时 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../../架构.md#模块表)的依赖图持有。角色、宿主与业务工具均由装配入口注入，运行时只经[装配与常驻实例](接口.md#装配与常驻实例)、[宿主契约](接口.md#宿主契约)调用它们；下表只列代码层面实际导入或调用的模块。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 个人助手端 | [`AssistantRole`](../个人助手端/接口.md)（`assistant/role.py`） | `runtime.__main__` 的 `serve` 直接装配助手角色；方向与依赖图相反，见[票据](../进展/01-常驻入口反向导入角色.md) | 进程内 | 真实角色对象 |
| 服务方端 | [`ProviderRole`、`provider.configuration.validate_provider`、`EDITABLE_SERVICE_FIELDS`](../服务方端/接口.md) | `serve` 装配服务方角色；`validate_roles`、`setup_command` 校验服务方配置区域并限定可改字段；同上票据 | 进程内 | 真实角色对象与配置夹具 |
| 宿主适配 | `python -m ioalab_jiuwen` 的 validate、start、configuration、configure、web-extension 子命令；安装器以 `ioalab_jiuwen.process.ProcessHost` 核装配可导入 | `_shared/ioalab.py` 把产品技能的 `runtime.start`、`runtime.validate`、配置与网页扩展操作转交宿主装配 CLI；不导入其代码 | 本地可替身 | 替换 `invoke` 的子进程桩 |
| web服务 | [HTTP入口](../../平台/web服务/接口/HTTP入口.md)（账号、身份登记、交互补查、操作查询、文件、验收器包、信誉与案件读取）、[WebSocket与消息封套](../../平台/web服务/接口/WebSocket与消息封套.md)（`/ws/agents` 连接、控制操作与投递）、[幂等与错误](../../平台/web服务/接口/幂等与错误.md) | 账号会话、常驻连接、原 A2C 与 AP2 报文的中继及恢复查询 | 自有远端 | 测试夹具启动的真实平台（conftest `platform`） |

## 外部依赖

| 包 | 用途 | 版本来源 |
|---|---|---|
| `a2c` | 原 Client、Provider、Store、Transport、签名、模板、AP2 付款与验收器；`cryptography` 经它传递，供本地密钥使用 | `src/access/sdk/pyproject.toml` 固定版本；产品安装用 `src/access/skills/_shared/requirements.lock` |
| `a2a-sdk[http-server]` | A2C 原协议绑定所需 | 同上 |
| `httpx` | 平台 HTTP 与本机 IPC 客户端 | 同上 |
| `websockets` | 常驻平台连接 | 同上 |
| `jsonschema`、`referencing`、`rfc3339-validator` | 工具 output_schema 的结构检查、无远程引用解析与 date-time 校验 | 同上 |
