# 共用运行时 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../../架构.md#模块表)的依赖图持有。角色、宿主与业务工具均由装配入口注入，运行时只经[装配与常驻实例](接口.md#装配与常驻实例)、[宿主契约](接口.md#宿主契约)调用它们；下表只列代码层面实际导入或调用的模块。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 服务方端 | [配置校验](../服务方端/接口.md) | validate_provider与EDITABLE_SERVICE_FIELDS；产品入口的离线配置校验 | 进程内 | 真实配置 |
| SDK装配 | [命令装配](../SDK装配/接口.md#命令装配)：`python -m ioalab_sdk.access` 的 serve、login、call 子命令 | `ioalab_client/commands.py` 把产品技能的 `account.login` 与其余操作调用转交 SDK 命令；`start` 未给 `command` 时以它起常驻子进程；不导入其代码 | 本地可替身 | 替换 `invoke` 的子进程桩；`start(command=…)` |
| 宿主适配 | `python -m ioalab_jiuwen` 的 validate、start、configuration、configure、web-extension 子命令；统一客户端核安装RECORD与组件元数据 | `ioalab_client/commands.py` 把产品技能的 `runtime.start`、`runtime.validate`、配置与网页扩展操作转交宿主装配 CLI；不导入其代码 | 本地可替身 | 替换 `invoke` 的子进程桩 |
| web服务 | [HTTP入口](../../平台/web服务/接口/HTTP入口.md)（账号、身份登记、交互补查、操作查询、文件、验收器包、信誉与案件读取）、[WebSocket与消息封套](../../平台/web服务/接口/WebSocket与消息封套.md)（`/ws/agents` 连接、控制操作与投递）、[幂等与错误](../../平台/web服务/接口/幂等与错误.md) | 账号会话、常驻连接、原 A2C 与 AP2 报文的中继及恢复查询 | 自有远端 | 测试夹具启动的真实平台（conftest `platform`） |

## 外部依赖

统一产品宿主入口依赖[服务方端](../服务方端/接口.md)的validate_provider与EDITABLE_SERVICE_FIELDS，仅作启动前本机配置校验；两角色规则仍由角色模块持有。

产品宿主选择经[ClaudeCode适配](../ClaudeCode适配/接口.md)、[Codex适配](../Codex适配/接口.md#产品配置与常驻装配)或[宿主适配](../宿主适配/接口.md#命令行)的公开命令与配置入口调用，不导入未选择的宿主。

| 包 | 用途 | 版本来源 |
|---|---|---|
| `a2c` | 原 Client、Provider、Store、Transport、签名、模板、AP2 付款与验收器；`cryptography` 经它传递，供本地密钥及包内CA的X.509校验使用 | `src/client/sdk/pyproject.toml` 固定版本；产品安装用 `src/client/skills/_shared/requirements.lock` |
| `a2a-sdk[http-server]` | A2C 原协议绑定所需 | 同上 |
| `httpx` | 平台 HTTP 与本机 IPC 客户端 | 同上 |
| `websockets` | 常驻平台连接 | 同上 |
| `jsonschema`、`referencing`、`rfc3339-validator` | 工具 output_schema 的结构检查、无远程引用解析与 date-time 校验 | 同上 |
