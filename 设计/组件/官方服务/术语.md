# 官方服务 · 术语

只收本模块独有的术语；官方预置服务、ISP、部署发布授权等跨模块术语在[术语地图](../../术语.md)。

**部署协调器**：在核心外按部署配置准备、授权、公示续期、查询与停止全部官方预置服务的命令进程，本身不执行业务。
_Avoid_：官方启动器、官方实例、执行器。代码：`ioalab-official`、`ioalab_services.__main__`

**领域资产**：一个领域一份的包内 JSON，声明唯一 ISP 账号、唯一叶类与该领域全部服务定义，连同所引用的验收器源码。
_Avoid_：官方目录、种子目录。代码：`catalog.load_domains`、`assets/domains/*.json`

**服务定义**：领域资产中的一项服务，经统一验收器写法与默认值补全后，可映射为未签公示与执行配置。
_Avoid_：服务配方、服务模板。代码：`catalog.definitions`、`materialize`

**部署状态**：部署协调器在专用 data_dir 中保存的准备进度、公开身份、原操作与真实引用，绑定配置与资产摘要。
_Avoid_：部署配方、安装记录。代码：`Deployment.state`、`state.json`

**配置绑定**：部署配置、解析后的路径与全部领域资产的摘要；与部署状态记录不同即拒绝继续。
_Avoid_：配置哈希、版本号。代码：`Deployment.binding`

**控制运行时**：prepare 期间为某账号启动、只装服务方角色且不配宿主的同一 SDK 常驻实例，用后即关。
_Avoid_：桩运行时、临时 SDK。代码：`ResidentRuntime(…,modules=(ProviderRole(),))`

**续期**：模板剩余不足 7 天时，以准备时保存的完整服务只替换 `validUntil` 并按部署发布授权重新公示。
_Avoid_：刷新、重签、重新发布。代码：`coordinator.tick`

**释放证明**：可取得某账号 resident 目录的 `client.lock`，表示该目录的 SDK 写入者已退出；不证明整个进程组已退出。
_Avoid_：已停止、进程退出。代码：`lifecycle.released`
