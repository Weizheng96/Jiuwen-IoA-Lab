# 管理员助手 · 预设与准备

本页是[管理员助手](../接口.md#接口)的子页。

## 默认管理员业务助手

预设源位于src/official/admin-assistant/，属于ioalab-official。ioalab-admin-assistant prepare --config <文件>只准备本部署admin的固定预设，status只查询；正常收信使用ioalab-jiuwen serve。该入口不注册为模型工具，不提供任意动作批准能力。

| 项 | 规则 |
|---|---|
| 账号/身份 | 预置admin，唯一assistant profile=admin；不替其他账号配置，不取得核心机构私钥 |
| 运行 | 与核心隔离的同一ResidentRuntime，使用原版ProcessHost；入站上下文、工具、UUID/Session及可靠收发沿用SDK |
| message.forward | 面向全部已登录账号；接受明确的title/text，调用owner.notify提交到同一原生user_id的网页会话；区分排队、网页已收到与用户已读 |
| meeting.request | 面向全部已登录账号；有完整日程/通知配置才启用，否则保留明确停用预设；输入/输出与冲突、邀请语义遵守会议示例 |
| 日程 | 首次显式初始化本地安排；以后不覆盖手工安排或规则；预约/发信回执与SDK状态分别保存 |
| 通知 | 使用九问原生应用扩展和jiuwen-web工厂；不写九问源码、全局指令或历史库；凭据只在自己的配置中 |
| 缺项 | 缺模型或公开能力不就绪；缺邮件时会议停用但留言可用，不用桩、假邀请或默认空日历冒充能力 |

### 初始预设的操作授权

部署者运行安装器并启用admin_assistant时，授权安装器作为本部署admin的配置方设置固定内置预设。受限root准备进程仅在新建、未运行模型的受管实例中，校验账号/目录归属、包资源摘要及两个指定接口，展示/保存实际处理与工具摘要，再通过同一SDK可信本地用户通道确认原rules.publish操作。来源记录为deployment-preset及本部署/预设摘要。

该特权只配置内置接口，不批准委托授权、合同、实名环节、验收或付款；不接受模型提供的任意确认引用/规则/账号，不暴露批量批准RPC。普通用户规则仍通过真实用户确认。准备完成后进程退出、执行锁释放，参与方目录交给其独立账号，长期运行时不持该准备权或管理员口令。

每个预设的原draft、内容摘要、operationId、确认及发布结果持久化；中断先恢复原发布，不新建操作规避结果未知。已准备实例重装不重发确认或发布；人工停用、修改、预约及原消息均保留。缺少原记录、资源失配或未登记旧实例停止并报告，不能用空状态恢复默认。

### 准备记录与命令输入

准备入口只接受安装器生成的`<状态根>/.deployment/admin-assistant/config.json`；不提供账号、接口名、规则或确认引用的命令行参数。其`deployment_id`必须匹配三根的原归属记录；`password`仅为固定admin的本机凭据，使用首次部署生成的原密码，不硬编码试用口令；`platform_url`、原版`host`、回环`web_url`、`recipient`、可选`notification`及`max_model_runs`定义固定实例配置。通知使用工具工厂的凭据文件/变量引用，不把密钥写入模型上下文。

| 项 | 规则 |
|---|---|
| 准备权限 | 仅部署root进程；配置、原归属和准备记录不可被参与方改写。拒绝符号链接、归属冲突或未登记的旧实例，不接管用户已有九问 |
| 固定位置 | SDK配置和本地安排在`<状态根>/agents/admin-assistant/`，原版九问工作区为`<状态根>/agents/swarm-admin/`；原操作与确认摘要在root私有准备记录中 |
| 准备执行 | 创建不装配宿主、不启动连接/调度的同一SDK控制实例，校验并发布两个固定接口；业务工具只用于校验声明，不调用生产、通知或模型；关闭并释放SDK锁后才写完整宿主配置 |
| 已完成 | 只核对原配置/身份仍在，保留人工编辑；不重放初始发布，不把原回执当作当前启用状态。缺少原文件要求恢复，不重建空日程或身份 |
| 中断 | 保存原草稿、操作、确认摘要及原发布结果，继续原操作；确认已过期或被拒绝时停止并报告，不制造新确认绕过决定；已提交但丢回执由SDK查询原操作恢复 |
| 状态 | `status`不创建目录、登录或运行模型；报告准备状态、原发布回执及实际可查询的运行状态，明确区分未查询、未运行与就绪 |

## 独立新建与替换旧助手

新实例只属于admin，身份名称为“管理员的个人助手”。旧ISC_001助手先正常停机、核执行锁释放，由显式替换入口按原准备记录停用旧身份并撤下两个接口，归档旧运行目录与准备记录，然后准备全新admin实例；不迁移身份、密钥、会话、安排或未决副作用。ISC_001账号、余额及其他数据不变，旧历史只供审计，不恢复为admin业务。替换步骤持有部署锁并保存阶段，重复执行继续原替换，不重复新建或重发。

管理员邮箱唯一来源为平台runtime.admin_email（默认zhengw.cc@outlook.com）；网页保存使用原修订和CSRF校验，显示保存值与启动时值。正常停止后由部署配置入口投影到助手配方，下一次启动生效，普通重启保留人工值。个人助手目录标题读取assistantNames，账号名仍来自username。
