# 管理员助手 · 实现

| 项 | 值 |
|---|---|
| 代码目录 | `src/official/admin-assistant/ioalab_admin_assistant/`、`src/official/tools/ioalab_tools/` |
| 产物 | `src/official/VERSION`（`ioalab-official` wheel，`src/official/pyproject.toml`；与官方服务同一发行包） |

## 入口

| 入口文件 | 公开名 | 说明 |
|---|---|---|
| `__init__.py` | `prepare`、`status`、`load_presets` | 包入口；部署环境检查在 participant 环境的子进程内导入 `load_presets`，开发工具 `verify_admin_assistant.py` 核对安装位置 |

## 其他入口

| 文件 | 调用方式 | 说明 |
|---|---|---|
| `__main__.py` | `python -m ioalab_admin_assistant`、`ioalab-admin-assistant` 脚本 | 部署安装器以子进程调用 prepare、status |
| `src/official/tools/ioalab_tools/appointments.py` | 入口点组 `ioalab.business_tools` 的 `calendar`（`configure`） | 只按名动态加载；`ioalab_tools` 不被其他模块导入 |
| `src/official/tools/ioalab_tools/schedule_cli.py`、`agentmail_setup.py`、`outlook_login.py` | `ioalab-schedule`、`ioalab-agentmail`、`ioalab-outlook` 脚本 | 主人在本机运行；开发工具 `check_bootstrap.py` 核对 `ioalab-schedule` 可运行 |

## 内部分区

| 分区 | 文件 | 职责 |
|---|---|---|
| 部署准备 | `__main__.py`、`deployment.py`、`preparation.py` | 命令分派；配方、归属、路径与完整配置；可恢复的发布与确认流程 |
| 固定预设 | `presets.py`、`presets.json` | 包内两条收信接口的声明、处理正文与资源摘要；运行仍用同一 SDK 与九问适配，不另建收件器 |
| 预约 | `ioalab_tools/appointments.py` | 可选工具工厂、输入输出 Schema、预约状态机、主人核对与释放（`settle`）、预约库与建议时段；业务安排和外部回执留在本地，SDK 持有操作键及检查点，未知效果先查原回执 |
| 本地安排 | `ioalab_tools/schedule.py`、`ioalab_tools/schedule_cli.py` | 安排文件校验、修订号、加锁与原子替换；离线命令 |
| 日历与发信 | `ioalab_tools/calendar.py`、`ioalab_tools/outlook_login.py`、`ioalab_tools/agentmail.py` | Graph 只读日历与微软设备码授权及其主人命令；iCalendar 邀请与 SMTP；AgentMail Calendar 邀请 |
| 邮箱注册 | `ioalab_tools/agentmail_setup.py` | AgentMail 注册、所有权验证与凭据文件写入 |

## 存储与迁移

数据位置见[接口](接口.md#独占数据与配置)。准备记录 schema=1，阶段只进不退，binding 绑定配方、三根归属与预设摘要，任一变化 configuration_changed，无升级路径。预约库以 `CREATE TABLE IF NOT EXISTS` 建于首次预约，来源标识格式 `ioalab.appointments/1`，已存在的伴随目录缺标识或库文件时停止，不初始化为空；格式变化须另行设计迁移。安排文件没有 schema 版本号，只按当前 JSON Schema 校验；`replace` 只保留上一份 `.bak`。来源目录下的旧 `mailbox.sqlite` 一律拒绝接管。

## 内部接缝

| 接缝 | 用途 |
|---|---|
| `deployment.operator`、`deployment.owned`、`preparation.operator`、`preparation.owned` | 测试替换系统权限核对，只测固定准备的生命周期 |
| `Appointments(calendar,notification,recipient,rules=,clock=)` | 注入本地安排、假通知与固定时间，断言预留、重发与恢复 |
| `AgentMailNotification(…,http=)`、`AgentMailSetup(home,http=)`、`GraphCalendar(…,http=)`、`OutlookSMTPAuth(…,http=)` | 注入 `httpx.MockTransport`，不访问外部服务 |
| `notification.transport=smtp-capture` | 回环捕获服务，验证真实 SMTP 投递与邀请内容 |
| `importlib.metadata.entry_points` 组 `ioalab.business_tools` | 工厂唯一发现方式；测试经已安装包按名加载 |

`presets.json` 的接口顺序固定为 message.forward、meeting.request，`presets.load` 与 `Deployment.prepared` 各自核对这两个名称，修改时须同步。
