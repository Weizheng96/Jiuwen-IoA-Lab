# 管理员助手 · 术语

只收本模块独有的术语；被两个以上模块使用的术语在[术语地图](../../术语.md)。

**固定预设**：随包发布的 message.forward 与 meeting.request 两条收信接口，是初始部署授权唯一能配置的内容。
_Avoid_：默认规则、内置技能。代码：`presets.json`、`presets.load`

**准备配方**：安装器为本部署生成的固定实例输入，只接受 `.deployment/admin-assistant/config.json` 这一位置。
_Avoid_：管理员配置、preset 配置。代码：`Deployment`

**准备记录**：root 私有的可恢复进度，保存每条预设的原操作、确认摘要与发布结果。
_Avoid_：安装状态、发布日志。代码：`state.json`、`Deployment.state`

**本地安排**：主人可编辑的可用时间文件，含时区、可预约规则与事件；是预约判定的显式依据，不是日历同步副本。
_Avoid_：本地日历、日程缓存。代码：`LocalSchedule`、`schedule_file`

**预约记录**：一条来信决定的预约及其状态，按 agentId、interactionId、messageId 识别，与 SDK 运行数据分开保存。
_Avoid_：会议记录、邀请记录。代码：`Appointments`、`appointments.sqlite`

**伴随目录**：预约依据旁的 `<源文件>.ioa/` 私有目录，保存来源标识与预约库，使同一依据的工具共享一库一锁。
_Avoid_：工具数据目录。代码：`source.json`

**通知邮箱**：作为会议组织者发出邀请的专用邮箱，与收件人和平台账号都分开。
_Avoid_：管理员邮箱、发件人账号。代码：`notification.sender`
