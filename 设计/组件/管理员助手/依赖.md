# 管理员助手 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../架构.md#模块表)的依赖图持有。业务工具（`ioalab_tools`）只被管理员助手静态导入；同时经入口点组 `ioalab.business_tools` 登记为工厂 `calendar`，由宿主适配 `ConfiguredTools` 按本机配置的名称动态加载，因此任何宿主配置都可选用，会议预约场景即如此。该动态加载没有静态导入边。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 共用运行时 | [本地业务工具](../客户端/共用运行时/接口/本地业务工具.md#本地业务工具)：`ToolBinding`、`BusinessTools`（`runtime/host.py`） | `calendar` 工厂的返回值与工具声明 | 进程内 | 真实对象，经 `ConfiguredTools` 加载已安装工厂 |
| 共用运行时 | [装配与常驻实例](../客户端/共用运行时/接口.md#装配与常驻实例)：`ResidentRuntime`；[配置](../客户端/共用运行时/接口/配置.md#配置契约)：`RuntimeConfig` | 准备阶段构造不启动的 SDK 控制实例、校验配方与读取最终配置 | 进程内 | 真实对象配合真实 HTTP 平台与临时目录 |
| 共用运行时 | [用户确认](../客户端/共用运行时/接口/用户确认.md#用户确认)：`Confirmations.get`、`decide`、`user_channel` | 经可信本地用户通道确认固定预设的原 `rules.publish` | 进程内 | 真实对象；中断与过期由 monkeypatch 触发 |
| 共用运行时 | [配置、本机文件与公共值](../客户端/共用运行时/接口.md#配置本机文件与公共值)：`files.private_json`、`private_text`、`read_json`、`restrict`；`lease.Lease`；`protocol.RuntimeFault`、`configure_stdio`；[本机生命周期与调用](../客户端/共用运行时/接口.md#本机生命周期与调用)：`ipc.public_error` | 私有文件、安排与准备锁、错误对象、命令输出 | 进程内 | 临时目录 |
| 共用运行时 | [本机生命周期与调用](../客户端/共用运行时/接口.md#本机生命周期与调用)：经 `ioalab_sdk.runtime` 入口取 `require_configuration`、`LocalClient`；[公共操作](../客户端/共用运行时/接口/账号与登录.md#公共操作) `runtime.status` | `status` 只读查询常驻实例并核对配置、安装与身份 | 进程内（经本机 IPC） | 真实常驻实例与 IPC，宿主为不运行模型的替身 |
| 个人助手端 | [收信规则](../客户端/个人助手端/接口.md#收信规则)：`rules.parse`、`render` 及 `AssistantRole.rules` 的 `draft`、`preview`、`publish`；[装配](../客户端/个人助手端/接口.md#装配)：`assistant.role.AssistantRole(tools=)` | 校验包内预设并走原收信规则流程发布 | 进程内 | 真实对象配合真实 HTTP 平台 |
| 宿主适配 | [AgentHost 实现](../客户端/宿主适配/接口.md#agenthost-实现)：`ProcessHost.from_config` | 校验配方中的 host 区域，不启动进程 | 进程内 | 真实对象；host 命令为不存在的占位符 |
| 宿主适配 | [本地业务工具装配](../客户端/宿主适配/接口.md#本地业务工具装配)：`ConfiguredTools` | 准备阶段构造工具以校验预设声明，不调用工具 | 进程内 | 真实对象，不 `start` |
| 宿主适配 | [原生配置准备](../客户端/宿主适配/接口/九问网页通知.md#原生配置准备)：`prepare_extension` | 为管理员九问工作区准备 IoA 通知扩展 | 进程内 | 真实对象写入临时工作区 |

## 外部依赖

| 包 | 用途 | 版本来源 |
|---|---|---|
| `ioalab-sdk` | 上表 SDK 接口 | `src/official/pyproject.toml` 下限，发行时取同仓 wheel |
| `python-dotenv` | 读取通知 `credentials_file`，改写 AgentMail 凭据文件 | `pyproject.toml` 范围；发行锁 |
| `ioalab-jiuwen` | 上表宿主适配接口，准备时延迟导入 | 本包未声明，由部署的 participant 单元同环境安装 |
| `httpx` | AgentMail、Graph 与微软登录请求 | 经 `ioalab-sdk` 依赖取得，本包未直接声明 |
| `jsonschema` | 工具输入、规则与安排文件校验 | 经 `ioalab-sdk` 依赖取得，本包未直接声明 |
| `a2c`（`codec.digest`、`digest_bytes`） | 资源摘要、绑定摘要、工具修订 | 经 `ioalab-sdk` 依赖取得，本包未直接声明 |
| `tzdata` | `zoneinfo` 时区数据 | 经 `ioalab-sdk` 依赖取得，本包未直接声明 |
| AgentMail API（`api.agentmail.to/v0`） | 通知邮箱注册与 Calendar 邀请 | 外部服务，按 API 路径版本调用；测试用 `httpx.MockTransport` |
| Microsoft Graph、Microsoft 身份平台 | 可选只读日历与设备码授权 | 外部服务；测试用 `httpx.MockTransport` |
| SMTP 服务器 | 标准 iMIP 邀请发送 | 部署者配置；测试用回环捕获服务 |
