# 03：管理员助手 status 区分未查询、未运行与就绪

**目标行为：** `ioalab-admin-assistant status` 在不创建目录、不登录、不运行模型的前提下，报告实例实际可查询的运行状态，使调用方能区分未查询、未运行与就绪。现状：`preparation.result` 把 `runtimeChecked`、`currentInterfacesChecked`、`modelStarted` 写死为 false，从不查询常驻实例，已运行的实例与未运行的实例输出相同，与[预设与准备](../接口/预设与准备.md#准备记录与命令输入)的“状态”一行不符。

**阻塞于：** 无

**状态：** ready

**范围：** 管理员助手。需读[部署准备](../接口.md#部署准备)与共用运行时[本机生命周期与调用](../../客户端/共用运行时/接口.md#本机生命周期与调用)，确定只读查询所用接口及实例未运行时的返回。若判定 status 只报告准备回执即可，改为修正规范并删除本票。

**定向测试：** admin_assistant_preparation

- [ ] 未启动实例报告未运行，运行中的实例报告实际就绪状态，查询失败报告未查询
- [ ] status 仍不创建目录、不登录、不启动模型，既有准备记录不变
