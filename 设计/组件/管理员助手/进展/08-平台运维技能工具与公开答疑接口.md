# 08：平台运维技能、工具与公开答疑接口

**目标行为：** 为 admin 账号的管理员助手配置平台运维相关 Skill 和工具，能够阅读平台 log、定位问题并基于实际证据答疑；新增“运维答疑”对外消息接口，面向所有接入方开放。

**阻塞于：** 07

**状态：** ready

**范围：** 管理员助手[接口](../接口.md)、[预设与准备](../接口/预设与准备.md)、[实现](../实现.md)；依赖个人助手端[收信规则](../../客户端/个人助手端/接口.md#收信规则)、宿主适配[本地业务工具装配](../../客户端/宿主适配/接口.md#本地业务工具装配)、平台[观测接口](../../平台/观测/接口.md)、部署[进程与数据](../../部署/接口/进程与数据.md)。前置工作见[管理员助手07](07-admin账号后台助手与会议预约接口.md)。

**定向测试：** admin_assistant_preparation、business_tools；设计定稿后补日志读取、公开答疑、权限裁剪与敏感数据保护的针对性验证。

## 初始方案与实施前决策

本票为需求登记，尚未变更现行接口或实现。运维 Skill 属于产品运行资产，与 `.agents/skills` 中的开发技能分开；工具经现有宿主业务工具装配，答疑经现有消息链路处理。实施前按 design 定义工具权限与公开接口并升版。

- 按 grilling 明确可读取的日志来源、范围和保留规则，答疑接口的正式名称、输入输出、调用方可见范围，以及除读取日志和答疑外是否包含其他运维动作；未明确的写入、重启或配置变更不纳入默认权限。
- 后台诊断可用数据与对外可公开数据分别定义；所有接入方可调用答疑接口，不代表取得其他账号私有日志、消息、凭据或管理员权限。

## 验收项

- [ ] admin 管理员助手装配可安装、可升级的平台运维 Skill 和工具，具备阅读平台 log 和定位问题的真实能力
- [ ] “运维答疑”接口发布并面向所有接入方开放，可经公开消息流程发现、调用并收到答复，与会议预约、消息转发接口并存
- [ ] 使用实际故障日志完成定位，答复引用可核对的证据；缺日志、权限不足或无法确定时如实说明
- [ ] 工具按定稿权限读取日志，外部消息不能扩大权限；对外答复按调用方权限裁剪，不泄露密钥及其他账号私有数据
- [ ] 验证正常日志、缺失日志、读取失败、并发咨询及恶意日志/消息内容，日志或来信中的指令不能越权触发工具动作
- [ ] 运维答疑运行于07的长期后台管理员助手，遵守定稿资源边界；本期不引入优先级调度，后台重启后保留原身份、会话与接口
