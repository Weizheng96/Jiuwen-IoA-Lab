# 身份中心

## 目的与范围

提供账号认证、智能体身份与公钥归属，回答“谁在操作、可以代表哪个智能体”。不创建个人助手实例，不保管参与方私钥，不决定外部消息是否获得业务授权。系统边界见[架构](../架构.md)。

## 职责与数据

| 对象 | 权威记录与约束 |
|---|---|
| 账号 | 稳定账号 ID、唯一用户名、密码验证信息、启停状态及网页角色；无需手机号 |
| 用途标签 | ISP 表示内部服务提供者，ISC 表示内部服务使用者；不限制账号同时拥有两种业务角色 |
| 智能体 | 每账号一个逻辑个人助手及多个专业服务；各自具有稳定 `agentId`、能力与归属 |
| 公钥绑定 | 按委托方/用户/付款、服务方/收款等协议用途记录公钥及归属；不保存参与方私钥 |
| 认证凭据 | 登录态、绑定 challenge、连接票据及其有效性；执行租约由[消息中心](消息中心.md)管理 |

邮箱形式用户名仅用于定位账号，不提供邮箱归属证明或隐含域名授权。账号、智能体、服务、交互和合同的所属检查必须在服务端执行，不能依赖页面隐藏。

## 账号与默认身份

| 行为 | 规则 |
|---|---|
| 注册 | 用户名密码注册；创建账号不启动九问或自动生成参与方私钥 |
| 预注册 | 幂等创建 `ISP_001` 起的领域账号及配置数量的 ISC 账号；未启动接入组件时保持空闲 |
| 默认管理员 | `ISC_001` 具有管理员网页权限；试用部署生成或配置强口令，不使用编号口令 |
| 内部演示账号 | 普通内部账号可按编号配置演示口令；部署范围与配置见[部署](../工程/部署.md) |
| 角色切换 | 同一账号可访问其获准的个人助手、服务方和管理员视图；浏览器角色不扩大收信处理器的工具权限 |
| 登录成功 | 发布持久登录操作结果；登录赠币由[支付中心](支付中心.md)按同一操作幂等执行 |

默认领域与服务内容由[注册中心](注册中心.md)定义，账号数量随实际领域配置生成。官方预置服务和管理员助手使用普通账号及公开 SDK，不获得协议后门。

注册/登录使用稳定 operationId，绑定规范化用户名、操作种类及参数；服务器不保存明文密码，参数绑定使用服务端密钥 HMAC。账号创建或登录事实与登录赠币在同一应用事务完成；相同操作返回原结果，同键异参数拒绝。成功的认证重传不再消耗新的登录次数或重新发币；密码已变更时旧操作不能恢复新的认证权限。旧客户端未提供标识时按一次新操作处理，当前浏览器及 SDK 必须在发送前保存标识并用于未知结果恢复。

浏览器登录态默认7天，SDK Bearer 默认30天。有效 Bearer 可换取新的受限 SDK Bearer，不形成密码登录或赠币；过期、撤销或无法认证时明确要求重新登录，不用密码循环探测来维持在线。用户显式重新登录建立新操作，可按配置发币。注册自动登录不再额外调用一次密码登录来补发。

## 网页管理与审计权限

网页admin角色允许全景监控与账号角色管理；auditor是需另行授予管理员的私人消息正文审计权限，不自动随admin获得，不单独授予普通账号。受限SDK凭据不能取得这两项网页管理能力。服务和个人助手的业务归属不由此改变。

管理员以目标账号ID、当前角色集合及要设置的新集合修改admin/auditor；服务器原子比较当前集合，冲突拒绝，相同目标结果不重复修改。权限变化记录操作者、目标及前后集合，不保存私人正文。账号不存在时不创建占位账号；特殊部署管理登录仍可管理角色，不因普通管理员角色被撤销而产生无管理入口。

正文审计同时要求当前非受限登录态、admin和auditor角色；一般管理权限不能替代。每次读取记录审计人、消息ID和时间，不把正文复制到行为日志。一般管理员只得到消息元数据与是否可审计，不显示不可用的正文按钮。

## 身份绑定与地址

1. 已登录参与方向身份中心获取一次性限时 challenge。
2. 本地签署包含 challenge、账号、平台地址、智能体身份及用途公钥的绑定对象。
3. 平台验签、核对归属并原子消费 challenge，保存绑定结果；重复操作恢复原结果，不覆盖另一身份。

| 边界 | 规则 |
|---|---|
| 重复绑定 | 原账号、智能体与公钥必须一致；不同账号不能占用同一身份或付款公钥 |
| 公共地址 | 由平台公共基址与 `agentId` 组成，与 IP、连接和九问会话无关 |
| 独立服务绑定 | 本地先生成稳定服务 agentId 和签名/收款密钥，平台派生 protocolId；证明密钥持有后绑定，不创建个人助手、不抓取公网 Agent URL |
| 改址 | 平台公共基址初始化后锁定；改址是显式迁移，不重写旧签名对象中的地址 |
| 多设备 | 每智能体只允许一个有效执行者；换设备须迁移身份、业务状态与必要会话资源，不因再次登录换钥覆盖旧合同 |
| 密钥迁移 | 保留旧协议原件的验证与履约能力；无法安全接管的业务先结束或人工核实，不静默遗失 |

绑定操作用同一 operationId 依次申请 challenge 和提交证明；challenge 固定角色、agentId 与 protocolId，默认120秒有效。证明签署绑定对象完整摘要；平台核验全部用途公钥、密钥归属及挑战后原子保存结果和消费挑战。相同已成功证明在挑战或签名过期后仍可恢复原绑定，但不同参数不能替换。每账号最多一个逻辑个人助手，多服务各自绑定；新设备不能凭账号重置原密钥。

## 认证与权限边界

| 入口 | 规则 |
|---|---|
| 浏览器 | cookie 登录态，检查 Origin/CSRF；网页只读订阅不能领取或确认业务消息 |
| SDK | 使用 Bearer，凭据保存在本地受限配置，不交给模型 |
| 智能体连接 | 短时、一次性票据绑定账号及获准操作的智能体集合，首帧认证；不将凭据放入 URL 或观察日志 |
| 发信身份 | 从连接内已认证的智能体上下文确定；客户端正文不能自报任意发送者 |
| 归属变更 | 先核实活动业务和密钥迁移，不以新归属冒充旧签名主体 |
| 管理权限 | 管理页面权限与参与方业务授权分别检查；管理员身份不自动允许读取私人正文或执行付款 |

具体接口、认证报文与错误见[平台接口](../接入/平台接口.md)。

连接票据仅由 SDK Bearer 认证入口签发：绑定账号及 1—64 个已登记、未停用的所属智能体，默认 60 秒有效，原文只返回一次，平台仅存摘要并原子消费。网页观察 cookie 不能直接领取票据。票据只授予建立连接的资格，不授予业务执行或接单权限。

## 异常与恢复

| 情况 | 处理 |
|---|---|
| 登录响应丢失 | 使用原操作标识查询或重试，返回原登录与赠币结果 |
| challenge 过期或签名不符 | 拒绝绑定；不得根据同名、相同 URL 或旧登录推定密钥所有权 |
| 凭据续用与 WS 重连 | 复用有效凭据或刷新连接票据，不重新执行用户名密码登录 |
| 账号/智能体被停用 | 拒绝新的认证、投递与执行授权；已发生业务按证据保留，不能删除既成合同或付款记录 |
| 本地状态丢失 | 报告需迁移/恢复；不能仅凭平台观察副本重建原私钥与九问会话 |
