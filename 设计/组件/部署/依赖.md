# 部署 · 依赖

本模块调用的其他模块接口。被谁依赖由[架构](../../架构.md#模块表)的依赖图持有。部署代码只用标准库，运行在系统 Python 或 build 环境中，不导入平台与参与方包；下表除开发工具外都是经已安装环境解释器执行的命令、`-c` 检查片段或文件约定。

| 依赖模块 | 接口 | 用途 | 类别 | 测试替身 |
|---|---|---|---|---|
| 开发工具 | `install_swarm.py` 先 `sys.path.insert(0, 仓库根)` 再 `from tools.check_vendor import validate`；`Installation.candidate` 在 build 环境以 `-c` 执行 `from tools.build_deployment import build`（其又导入 `tools.build_packages`、`tools.check_vendor`、`tools.deployment_dependencies` 并运行 `tools/build_access_skills.py`）；`repair.CONTROLLER_FILES` 列 `tools/check_scope.py`；`jobs.SOURCE_DIRECTORIES` 含 `tools` | 随仓 vendor 校验、Linux 候选发行构建、修复允许变化的文件与来源摘要；偏离见[票据](进展/01-部署链导入开发工具.md) | 本地可替身 | `install_swarm.installation_plan` 打桩；替换 `Installation.command` 返回发行回执 |
| web服务 | [进程与命令](../平台/web服务/接口.md#进程与命令)：`python -m ioalab --config <platform.json> serve`、`python -m ioalab.readiness --url --expected-public-url`；环境检查导入 `ioalab.web.app.create_app` | 核心单位命令、本地与公共入口的就绪探针、core 环境导入核验 | 本地可替身 | 替换 `Installation.command`、`Local.core_ready` |
| 平台基础 | [配置](../平台/平台基础/接口.md#配置)、[部署与保留](../平台/平台基础/接口/平台配置.md#部署与保留)：`ioalab.platform-config/1` 文件与 `platform.json.example`；[存储与所有权](../平台/平台基础/接口.md#存储与所有权)：`状态根/core/.core.lock`；环境检查导入 `ioalab.config.Settings` | 创建平台 JSON 并读取部署投影；停止后以核心数据目录锁证明释放 | 本地可替身 | 临时 JSON 与临时锁文件 |
| 共用运行时 | [本机生命周期与调用](../客户端/共用运行时/接口.md#本机生命周期与调用)：`python -m ioalab_sdk.runtime login`、`call runtime.status`、`call runtime.stop`，`-c` 片段中的 `RuntimeConfig.load`、`require_configuration`、`LocalClient`、`installation.current`；[安装与实例核对](../客户端/共用运行时/接口/安装与实例.md#安装与实例核对)：`ioalab-release.json`、`.ready`；SDK 执行锁 `client.lock` | 受管 SDK 登录、管理员助手就绪与排空、安装身份核对、升级前执行权证明 | 本地可替身 | 替换 `Installation.sdk`、`Local.run`；临时锁文件 |
| 宿主适配 | [命令行](../客户端/宿主适配/接口.md#命令行)：`python -m ioalab_jiuwen serve --config`；环境检查导入 `ioalab_jiuwen.process.ProcessHost` | 管理员助手单位命令、participant 环境核验 | 本地可替身 | 只断言单位命令行，不启动 |
| 个人助手端 | [产品技能](../客户端/个人助手端/接口.md#产品技能)：发行内 `ioalab-delegate` 包与 `scripts/ioalab.py runtime.status` | Windows 本机经原版网页导入技能并核对同一常驻实例 | 本地可替身 | 替换 `assistant_skill.upload`、`sdk_status` |
| 官方服务 | [部署协调命令](../官方服务/接口.md#部署协调命令)：`prepare`、`authorize`、`serve`、`status`、`stop`；环境检查导入 `ioalab_services.catalog.definitions`；协调器 `deployment.lock` 与 `state.json` 账号映射 | 官方实例准备与授权、单位命令、就绪判定、Windows 停止、升级前执行权 | 本地可替身 | 替换 `Installation.installed`、`Local.run` 返回固定回执 |
| 管理员助手 | [部署准备](../管理员助手/接口.md#部署准备)：`prepare --config`、`presets.load`、`local_owner.owned` | ISC_001 准备、participant 环境核验、Windows 属主与 ACL 核对 | 本地可替身 | 替换命令回执；windows_local_owner 用真实 ACL |
| 在线试用 | [控制器与部署入口](../在线试用/接口.md#控制器与部署入口)：`python -m ioalab_trial --config <配置>` 与 `--verify-stopped`，网关 `/health`；控制目录的 `shutdown.json`、`coordinator.lock`；平台配置与试用配置的准入配对见[试用入口端口变更](../在线试用/接口/试用规则.md#试用入口端口变更) | 可选试用单位、停止前核验整轮资源、就绪判定 | 本地可替身 | 替换 `subprocess.run` 与 HTTP 打开函数 |

## 外部依赖

| 包 | 用途 | 版本来源 |
|---|---|---|
| CPython 3.11 标准库（`venv`、`fcntl`、`pwd`、`grp`、`msvcrt`、`ctypes`） | 全部部署代码；不引入第三方包 | 部署者系统解释器 |
| systemd、`systemd-run`、`systemctl`、`useradd`，统一 cgroup v2 | Linux 安装任务、受管单位、账号与组判空 | 目标主机 |
| Windows kernel32 Job 对象、`icacls` | 本机所属进程分组、中断与目录 ACL | Windows x64 |
| `pip`、`packaging`、`setuptools` | build 环境与各单元环境安装 | `deploy/locks/build.lock` 与各目标单元锁；普通包来自部署者配置的 HTTPS 镜像 |
| 原版九问 `workswarm`（`jiuwenswarm.common.utils.prepare_workspace`、`common.config.update_config`、`load_models_config`、`upsert_model_resource`，三个原版服务模块） | 部署方九问工作区准备与模型配置、原版九问单位 | `vendor/` 固定 wheel；swarm 单元锁 |
