# 管理员控制台（`/admin`）

口令登录（`IOALAB_ADMIN_PASSWORD`）；数据来自 `/api/admin/*` 与 WebSocket `/ws/admin`（先补最近 100 条事件，再实时推）。事件只是报文的影子。

| 页签 | 内容 |
|---|---|
| 全景 | 实时拓扑：左列账号与助手（`isc` · `external` 分组，标明驾驭方式），中列交易中心（注册中心 · 分类树 · 模板公示 · 信誉 / 仲裁）与支付中心，右列服务方按领域成块（每块 ≤ 10 小卡，ISP 账号名在块头），外部服务方单独一列。每条事件画成节点状态变化与节点间脉冲 |
| 实时交易流 | 一行一事件（时间 · 标签 · 发起方 → 接收方 · 卡 · 期 · 金额 · 结果），可按卡聚合展开签名链；自由文本过滤 |
| 泳道 | 每张卡一行：助手 → 服务方、阶段芯片（发现 · 定约 · 开工 · 交付 · 验收 · 结清）、签名链、状态 |
| 组件 | 注册中心（服务数 · 类目数 · 树状态 · 最近检索模式）· 模板公示数 · 支付中心（今日笔数 / 额 · 流通量）· 服务运行时（队列 · 窗口内接单）· 助手运行时（进行中需求）· 模型（调用与 token 汇总 · 型号 · key 已配置）· 沙箱闸 · 事件总线（run · seq · 连接数）· `PUBLIC_URL`；5 s 轮询 |
| 用户与钱包 | 按 `kind` 分组：用户名 · 显示名 · 余量 · 名下智能体；发放 / 扣减；创建临时账号；邀请码 |
| 注册表 | 服务 · 领域 · 成约方式 · 价 · 状态 · 信誉 |
| 投放 | 从需求池按账号 / 领域 / 条数投放给 `isc` 助手；流量生成器开关与档位 |
| 需求 · 订单 | 表 + 订单详情（参与方 · 签名链 · 裁定 · 逐事件时间线） |
| 回放 | `?replay=<run>&auto=1`：同一套渲染，从 `data/runs/<run>/events.jsonl` 取事件，JS 虚拟时钟推进 |

## 聚焦高亮

点任一助手或服务方 → 按其**账号**聚焦：该账号名下所有智能体与相关事件高亮，其余节点 / 行变淡（`opacity .25` + 去色）；全景 · 实时流 · 泳道 · 用户 · 注册表同步；再点一次或 Esc 还原；`?focus=<账号 id>` 深链。
实现：`Names.owner`（任何智能体 id → 账号 id），事件按 sender / receiver / 卡所属归到账号；过账事件的双方本来就是账号 id。

## 双屏试用

`/admin?view=panorama`：隐藏页签，全景居中、右侧滚动实时流、底部组件条，大字号；另一屏是用户自己的九问 swarm。
