# 账号与钱包

## 账号

| 项 | 规则 |
|---|---|
| 登录名 | 用户名 `^[A-Za-z0-9_.-]{3,32}$` + 密码；不要手机号、不发短信 |
| 种类 `kind` | `isp` 内部服务提供者（Internal Service Provider）· `isc` 内部服务使用者（Internal Service Consumer）· `external` 外部用户 · `virtual` 管理员临时创建。种类只是**用途标签**：任何账号名下既可有个人助手，也可有专业服务 |
| 内部账号 | 部署时自带，幂等：`ISP_001…ISP_{N}` 密码 `001…{N}`（N = `ioalab/seed/domains/` 文件数，每个 ISP 负责一个领域）；`ISC_001…ISC_{M}` 密码 `001…{M}`（`IOALAB_ISC_COUNT`）；`display_name` 如「内部服务方 · 医疗健康」「内部用户 001」 |
| 注册 | `IOALAB_REGISTRATION`：`open` 用户名密码即可 · `invite` 还需管理员一次性邀请码 · `closed` 不开放。trial 模式密码 ≥ 8 位、按 IP 限速（5 次 / 小时） |
| 会话 | HMAC 签名 token（`IOALAB_SECRET` 或首次生成 `data/secret`）：浏览器走 cookie `ioalab_session`（HttpOnly · SameSite=Lax · HTTPS 时 Secure）；脚本走 `Authorization: Bearer <token>`（登录接口在 JSON 里也回 token，30 天）。users / agents / needs / orders 全带 `owner_id`，每个请求与工具调用先核归属；状态修改只收 POST 并校验 Origin |
| 管理员 | 不走用户名：`IOALAB_ADMIN_PASSWORD`（trial 必填 ≥ 12 位；dev 未设则首次生成到 `data/admin.secret` 并打印）；`/api/admin/*` 与 `/ws/admin` 全受保护；管理员会话不是用户会话 |
| 身份 | 一个账号：**一个**个人助手（`asst-<uid>`）+ 多个专业服务（`external` ≤ 3，内部不限） |
| 密钥 | 助手：Ed25519 委托方密钥 + 用户亲签密钥 + ES256 付款密钥（公钥指纹登记到钱包）；服务：Ed25519（带 kid，入 `Directory`）+ ES256 收款密钥。全部 `data/keys/<party>.json`，0600。**用户亲签 = 用户在页面 / swarm 确认后由平台以用户密钥代签，证据力依赖会话认证** |
| 配额 | 每账号每日需求 ≤ `IOALAB_NEEDS_PER_DAY`（默认 20），同一助手同时进行 ≤ 1；提案型 `proposalFee ≥ 1`；`needs` 表记每条需求的模型调用次数与 token |

## 钱包（虚拟币账本，协议外）

| 事 | 规则 |
|---|---|
| 登录赠币 | 登录成功赠 `IOALAB_LOGIN_CREDIT`（默认 100），同账号每自然日一次（`wallet_log.kind='login'`）；注册不另赠 |
| 内部用户补币 | `isc` 账号的背景流量由流量生成器投放，钱包余量低于阈值时由它补（`kind='grant'`，by=traffic），防止只增不减或投不出去 |
| 过账 | `SimPaymentProvider.op_ap2_pay` 顺序固定：mandate 头 jwk → 钱包（未登记则拒）→ 模板 `provider` → 收款账号（未登记则拒）→ 读卡核用途与金额 → 余量不足即拒（**不进 `paid`、不签凭证**）→ 签凭证 → 同一 SQLite 事务扣付款方、加收款方。`paid` 持久化，凭证号 uuid |
| 支付方拒绝付款的后果 | 拟卡费：提案卡不发。定金：`startWithin` 内可补余量重试，过期卡失效（定时器调各服务方 `purge_lapsed()`）。第 i 期款：签7(i) 已在卡上，委托方可补付（AP2 付款 + `payment.notify`），服务方 `respondWithin` 内未收到凭证即申请仲裁 |
| 普通转账 | 裁定后付款（`ruling:<文书摘要>`）、协商解除退差额（`refund:<卡摘要>`）：**由责任方自己发起**的不读卡转账，写明用途；平台与市场都不触发。市场服务费首版 0 |
| 管理员 | 发放 / 扣减是记录（admin · 原因 · 时间，只追加），不是交易 |
| 不做 | 不按裁定划转；不冻结；不代任何一方收付 |

## 表

`users(id, username UNIQUE, pw_hash, kind, display_name, created, last_login, note)` · `wallets(user_id, balance, payer_thumbprint)` · `wallet_log(at, user_id, delta, balance, kind, ref, by, note)` ·
`invites(code, created, used_by)`；助手与服务在 `agents(id, owner_id, role, name, definition, status, created, meta)`。
