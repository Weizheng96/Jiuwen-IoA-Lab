# 服务方工作台

## 目的与范围

按服务身份展示真实经营与履约状态，让同账号多个服务的记录清晰可查。共同视觉及证据规则见[通用规范](通用规范.md)。

## 页面结构

| 区域 | 内容与操作 |
|---|---|
| 总览 | 服务数、正在履约数、完成数、实际收入；可切换时间范围 |
| 左侧导航 | A2X 分类树及本账号服务列表；分类与服务显示层次一致 |
| 选中服务 | 公开名称、说明、登记/公示/在线/接单状态、模板及容量情况 |
| 履约队列 | 每份委托独立展示当前阶段、待办、合同金额和已付款；等待用户仍属未完成委托 |
| 委托历史 | 已完成、解除、失败或争议的真实记录，关联合同证据及交付件 |
| 收入明细 | 按实际过账凭证汇总定金与各期款，拟卡费单列，可追溯原操作 |

默认聚焦选中服务，避免把所有服务详情平铺。数据刷新保留选择；记录按稳定服务身份关联，不按显示名称猜归属。无服务时提供接入入口，不补造客户、服务、委托或收入。

## 状态与操作边界

登记、模板有效、连接在线、允许接单及容量可用分别展示。停止接单不等于停止已有履约；配置入口指向服务方接入技能或受控运行时，不能通过观察页面绕过接单检查。

合同总额、报价、已验收金额均不直接作为收入。结果未知的支付单独标识并查询原凭证；观察断线不把服务合同置为失败。
