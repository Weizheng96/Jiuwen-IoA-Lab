# 管理员工作台

## 目的与范围

让管理者理解整个智能体网络正在发生什么，并能追溯业务证据。共同布局、协议标注和动效以[通用规范](通用规范.md)为准。

## 页面结构

| 区域 | 内容与操作 |
|---|---|
| 全景网络 | 所有已登记助手、公开服务和平台组件；可按账号、智能体或组件聚焦 |
| 行为日志 | 网络右侧显示实际事件时间、参与方、动作及关联标识；最近 200 条，支持暂停/继续自动滚动 |
| 组件详情 | 职责、健康状态、相关活动与历史；委托中心可查看合同认证、存证、信誉、仲裁能力 |
| 业务详情 | 委托阶段、合同证据、付款凭证、消息投递状态；按合同摘要或交互 ID 跳转 |
| 运维详情 | 连接、队列、进程、异常与观察状态，和网络业务节点分开 |
| 历史查询 | 按时间、账号、服务、业务类型与状态筛选，查询结果不回放成新事件 |

保留双屏展示入口 `/admin?view=panorama`，另一屏可打开真实九问。浏览器使用观察通道，不消费智能体收件消息或推进游标。

## 权限与异常

默认管理账号按[身份中心](../组件/身份中心.md)初始化。一般全景权限不包括所有私人消息正文；审计入口独立鉴权并记录操作。行为日志不包含正文和凭据。

断线后先展示观察中断，再用获准快照补齐。空闲时不补造活动；需要活跃网络演示时由独立实验客户端产生真实、可标识的委托与消息，允许两者并发。
