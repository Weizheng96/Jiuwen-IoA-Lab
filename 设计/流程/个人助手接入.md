# 个人助手接入

## 目的与范围

用户在Claude Code CLI、Codex桌面或Windows九问Swarm通过根README的一句话指令（部分克隆GitCode仓库后参考其中的README_AGENT）自动下载、配置、启动统一客户端；个人助手与另一角色共用原账号、配置及实例。专业业务能力、连接、Skill发现及真实业务分别验收，不以安装冒充可执行。

## 接口级步骤

| 步骤 | 公共接口及归属 | 下一步条件 |
|---|---|---|
| 固定来源下载/复用/升级 | [安装与实例](../组件/客户端/共用运行时/接口/安装与实例.md) P01/P02/P03 | 固定commit/依赖/资源/摘要；活跃写入安全停止后才升级，保账号数据 |
| 配置与账号 | [配置](../组件/客户端/共用运行时/接口/配置.md) P06、[账号](../组件/客户端/共用运行时/接口/账号与登录.md) P17/P42/P43 | 仅选适配器，复用已有有效账号；SDK受保护页面处理必要交互 |
| 启动或复用 | [调用与启动](../组件/客户端/共用运行时/接口/调用与启动.md) P11/P12 | 原安装/配置/IPC/OS锁核对，无host prepare/check门禁 |

## 拒绝与恢复

原生必要资源未启用返回当前宿主准确动作，不改后台日志/替代聊天；配置冲突、原安装缺失修原件，不重注册。断线未知查原请求/效果，不重签、付款或生产；停止前排空真实工作并保存。服务或私人接口缺专业定义绑定/资源时保持未就绪，不声称发布即可处理。实际原生能力与三宿主完整验收仍待票36，196仅目标规范。

## 端到端验收

三宿主新聊天自动发现双角色、实际ID注入与原实例复用分别实测；四业务完整后续及跨宿主、定义版本/快照、工具与提案同效果去重、跨端文件、原会话busy和回调竞争统一归[36](../组件/客户端/进展/36-Windows三宿主四流程统一验收.md)。已有脚本/安装/连接不代新原生验收；当前均待验。
