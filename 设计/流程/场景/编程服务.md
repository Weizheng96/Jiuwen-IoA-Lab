# 编程服务

## 目的与范围

可复用编程能力、规格、生产说明、交付及验收资源唯一归官方服务资产，场景专属店名、价格、台词和账号留在Demo。服务资源经配置构造及公开SDK加载，通用SDK无行业分支，官方包不导入Demo。

## 能力与选择

码上飞提供微信小程序，快搭提供网站，极速APP工坊提供Android源码；同载体可有基础与可靠覆盖不同的候选。能力取实际声明、规格、材料、判据与notCovered，不从名称推断。先逐项匹配载体、必要功能、材料及所需证明，区分合格、缺材料、不合格，再向合格者征集并比较；无足够合格者明确说明，不凑数量。

规格使用通用业务名称和实际功能参数，生产说明与验收同步消费同一资产。美甲只是业务参数之一，非美甲案例至少覆盖其他业务及网站载体；不能只改名称或以声明true代替真实行为。

## 交付与验证

| 证据 | 证明范围 |
|---|---|
| 源码/文件结构 | 文件完整、载体结构与规格对应，不证明运行 |
| WASM核心行为 | 原交付核心在A2C沙箱执行规定行为；不等于前端实际执行 |
| 客户端行为 | 实际隔离客户端运行原交付页面及操作的证据，未执行明确未验证 |
| 构建 | 固定依赖、真实命令退出码及产物摘要，不以源码结构替代 |
| 安装/部署 | 目标环境真实安装或访问，不由前面层级推出 |

验收器仅在A2C python.wasm运行并先核包摘要，不在宿主import/exec交付代码。需构建或运行客户端的专项在独立隔离环境进行，不能混称WASM自动证明。保留预约容量、取消、幂等及拒绝反例；增加非美甲实例、载体不符、材料缺失、功能不覆盖、损坏源码与跨场景残留反例。
