# 术语

| 本仓 | 含义 | 对应 A2C 主仓术语 / 代码 |
|---|---|---|
| 九问IoA仿真平台 · Jiuwen IoA Lab | 本平台；Python 包 `ioalab`，环境变量前缀 `IOALAB_` | 由 A2C 主仓原「仿真平台」目录拆出（旧包名见 变更记录） |
| 交易中心 | 注册中心 + 市场 + 认证 · 信誉 · 仲裁 | Agent 交易市场（`a2c.market.Market` + A2X registry） |
| 注册中心 | A2X 注册与分类树检索 | A2X registry（库，进程内） |
| 支付中心 · 模拟支付方 | 虚拟币账本 + AP2 读卡过账 | 持牌支付方的替身（`a2c.payment.psp.PaymentProvider` 子类） |
| 个人助手 | 账号名下的委托方智能体 `asst-<uid>` | 委托方（client）；`urn:ioalab:client:<asst-id>` |
| 平台驾驭 / 九问 swarm 驾驭 | 助手第一轮由平台内 ReActAgent 还是用户的九问 swarm 驱动（`needs.driver = hosted｜external`） | — |
| 专业服务 · 服务方 | 账号名下的服务智能体 `svc-<id>`（外部 `ext-<slug>`） | 服务方（provider）；party id = `<PUBLIC_URL>/a2a/providers/<id>` |
| ISP · ISC | 内部服务提供者 / 内部服务使用者账号（`users.kind`） | — |
| 领域 | 一个 ISP 负责的服务类别，对应分类树一个叶类 `cat_<slug>` | A2X taxonomy category |
| 需求 | 用户给助手的一句话 + 连接授权 `scope` | 委托范围（`delegationScopeDigest`） |
| 订单 | 一张合同卡在平台里的记录（`orders`，主键卡摘要） | 合同卡（contract card） |
| 确认 | 上升到用户的决定：定约亲签 · 验收亲签 · 环节授权 · 是否仲裁（`confirmations`） | 亲签条款 `signers` · 环节授权 `step.authorize` |
| 余量 · 过账 | 钱包里的数 · 按卡载金额划转 | 不用资金类禁用词（AGENTS.md §一） |
| 拟卡费 · 定金 · 期款 | 过账的三种用途 | `proposalFee` · `deposit` · `periods[].amount` |
| 已接满 | 服务方窗口内接单达 `capacity` 的拒绝理由 | 待批准型拒绝复签 / 提案型退回提案卡 |
| 牌子 | （旧）只挂牌不接单的服务；本仓内部服务全部可接单，不再有牌子 | — |
| 事件 | 报文的影子：`seq · run · kind(a2c｜ap2｜platform) · op · sender · receiver · cardDigest · period · amount · outcome · detail` | — |
| 运行 `run` | 一次服务进程生命周期的事件分组 `YYYYMMDD-HHMMSS`，回放单位 | — |
| 签1…签7(i) | 合同卡签名链 | 见 A2C 主仓 设计/委托流程.md |
