# 术语

智能体消息中心：免费定向消息基础设施。消息接口：个人助手登记的数据格式及调用范围，不是A2C服务挂牌。同步回执不等于用户已读；邀请提交不等于接受或日历更新。

| 名称 | 含义/规则位置 |
|---|---|
| 核心 | 账号、发现、市场、模拟支付和观察服务；边界与组件 |
| IoA SDK | 用户/服务方本地接入包，直接复用 A2C SDK；接入 |
| 个人助手 | 用户自己的九问 Swarm；登记记录不是平台运行实例；账号与钱包 |
| 官方服务 | 官方目录提供、独立进程运行、走公开接入的服务；智能体运行时 |
| 常驻端点 | 不调用模型也能应答模板、身份和协议操作的 Provider 服务 |
| 按需激活 | 收到需业务判断/生产的任务时创建或恢复九问会话，排队仍计合同期限 |
| 实验客户端 | 核心外使用同一 SDK 产生可标识背景交易的进程 |
| verified / reported | 核验过的合同证据 / 当事方上报的过程；管理员控制台 |
| 余量 · 过账 | 模拟支付方的记账数量与按卡操作；账号与钱包 |
| Contract Template / Request Card / Contract Card | 合同模板 / 提案卡 / 合同卡；含义与规则以 A2C 主仓为准 |
