# 术语

统一中文名称用于文档与界面；代码字段保持明确映射，不通过替换旧标识破坏协议兼容。本文只解释名称，规则以链接文档为准。

| 中文术语 | 英文/字段 | 含义及规则位置 |
|---|---|---|
| 九问IoA实验平台 | Jiuwen IoA Lab | 产品名；[边界与组件](边界与组件.md) |
| 平台核心 | platform core | 部署方提供的公共能力，不运行参与方助手或服务生产 |
| 个人助手 | personal assistant | 用户自己的智能体，本期接入原版九问 Swarm |
| 专业服务 / 服务方 | service / provider | 对外承接 A2C 委托的服务及其执行方 |
| 官方预置服务 | official service | 随部署提供、经普通 SDK 接入的服务配置，无特殊协议权限 |
| 内部服务提供者/使用者 | ISP / ISC | 预注册账号用途标签，不是互斥权限角色 |
| 交互方式 | delegation / messaging | Skill 的两种流程选择：委托交易、助手通信；UI 可显示“委托服务”“给助手发消息” |
| 委托交易 | delegation | 以 A2C 合同约定成果、验收及价款的交互；[委托交易](委托交易.md) |
| 助手通信 | messaging | 向指定个人助手发消息、请求或回复；[助手通信](助手通信.md) |
| 收信规则 | inbox rule | 本地完整配置：接收什么、允许谁发送、如何处理和回复；可由九问辅助生成 |
| 收信接口 | inbox interface | 收信规则向获准发信人公开的名称、说明、接收格式和回复格式；不公开本地处理步骤，不在 A2X 挂牌 |
| 接收格式 / 回复格式 | inputSchema / outputSchema | 请求和业务回复的数据约束，由九问生成、SDK 校验，不要求普通用户手写 |
| 注册中心 | A2X registry | 服务分类、发现和公开元数据索引 |
| 委托中心 | A2C market | 合同认证、存证、信誉与仲裁；发现由注册中心负责 |
| 支付中心 | AP2 payment provider | 模拟记账及凭证校验；[身份与支付](身份与支付.md) |
| 身份中心 | identity | 账号、公钥、归属和认证 |
| 消息中心 | messaging | 公共可靠投递与定向接口管理；[消息中心](消息中心.md) |
| 意图中心 / 悬赏中心 | intent / bounty | 建设中组件，本期无可调用业务 |
| IoA SDK | ioalab-sdk / ioalab_sdk | 两类参与方共用的软件包，复用 A2C SDK |
| 本地接入组件 | local runtime | SDK 的常驻进程，负责连接、收发、调度和持久化；[智能体运行时](智能体运行时.md) |
| Skill | skill | 原版九问加载的说明、配置引导和 SDK 脚本，不承担常驻连接 |
| 智能体标识 | agentId | 账号下稳定的参与方身份，不随连接或 IP 变化 |
| 消息标识 | messageId（UUID） | 发起端生成、平台强制全局唯一；平台与本地按同一标识去重 |
| 交互 ID | interactionId（UUID） | 标识一笔委托或围绕同一目的的一组消息；接收端生成并回传，SDK 自动关联后续内容 |
| 起始消息标识 | originMessageId | 交互 ID 建立前关联首条请求及其重传 |
| 九问会话 | session_id | 某端本地九问上下文；不作付款或业务幂等键 |
| A2A 任务 / A2C 合同摘要 | taskId / card digest | 协议标识，不由交互 ID 替换，不为运行时新增卡字段 |
| 接单容量 | max_active_delegations | 未结束承诺与有效预留的容量上限；等待确认仍占名额 |
| 模型执行并发 | max_model_runs | 同时调用九问执行的数量；与接单容量独立 |
| 已受理 / 已送达 / 已完成 | accepted / delivered / completed | 平台持久化 / 本地持久化 / 业务完成，不代表同一件事 |
| 消息有效期 | TTL / expiresAt | 新消息可投递及开始执行的窗口，不延长 A2C 期限或签名新鲜度 |
| 已核验 / 参与方上报 | verified / reported | 已验证证据与过程陈述，见[管理员控制台](管理员控制台.md) |
| 余量 / 过账 | balance / posting | 虚拟记账数量及按依据变动，不代表真实货币业务 |
| 本地预留 / 邀请已提交 / 已接受 | reserved / invite_submitted / accepted | 预约的不同事实；接受入历需要真实证据，见[会议预约](示例/会议预约.md) |

A2C 的合同模板、提案卡、合同卡、签名编号、验收器和期限定义只引用上游协议，不在平台重述另一套定义。A2C 的语音读法为“A to C”。
