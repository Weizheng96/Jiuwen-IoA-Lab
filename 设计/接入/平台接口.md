# 平台接口

## 目的与范围

定义平台与 IoA Lab SDK 之间的网络契约：HTTP 入口、WebSocket 帧、消息封套和恢复查询。消息投递及收信权限规则由[消息中心](../组件/消息中心.md)定义，合同与签名规则直接复用 A2C。本文是接口设计，不表示所有入口均已实现；实现差距见[开发计划](../工程/实施资料/开发计划.md)。
