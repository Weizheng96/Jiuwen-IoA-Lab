# IoA Lab 服务方端 SDK

## 目的与范围

服务方端 SDK 为用户自己的九问提供登记、上线、接单与履约能力。它与个人助手端共用一个 IoA Lab SDK 包和[公共运行机制](SDK共用机制.md)，主动连接平台，不要求公网 IP。普通服务和官方服务使用相同入口。

本文定义服务配置与 SDK 能力；角色实现归 `src/access/sdk/ioalab_sdk/provider/`，共用连接、持久化和调度归运行时。接入过程见[服务方接入](../流程/服务方接入.md)，容量及承诺状态以[委托中心](../组件/平台/委托中心/接口.md)为准，目录与依赖边界见[架构](../架构.md)。
