# 部署

目标环境：Linux（Debian / Ubuntu / CentOS 均可）· Python 3.11 · 无 Docker。单进程单 worker（SQLite WAL），一台 2 核 4 GB 的机器足够。

## 一、配置（全部环境变量，`/etc/ioalab/ioalab.env`）

| 变量 | 默认 | 说明 |
|---|---|---|
| `IOALAB_MODE` | `dev` | `dev` 本机开发 · `trial` 服务器（限速 · 关 `/api/docs` · 口令与 key 必填） |
| `IOALAB_BIND` · `IOALAB_PORT` | `127.0.0.1` · `8750` | 监听地址；Nginx 反代时保持回环 |
| `IOALAB_PUBLIC_URL` | `http://<bind>:<port>` | 浏览器与 swarm 访问的地址；**首次运行后锁定**（`data/public_url`），改动须 `ioalab reset` |
| `IOALAB_DATA` | `<repo>/data` | SQLite · 私钥 · 交付件 · A2X 数据集 · 回放 · 日志 |
| `A2C_CACHE_DIR` | `~/.cache/a2c` | 验收器沙箱 wasm 运行时解压处（随 a2c wheel 入库，约 14 MB，`install.sh` 预热） |
| `IOALAB_ADMIN_PASSWORD` | （dev 自动生成） | trial 必填 ≥ 12 位 |
| `IOALAB_SECRET` | `data/secret` | 会话签名密钥 |
| `IOALAB_LLM_API_KEY` · `IOALAB_LLM_BASE_URL` | — · DashScope 兼容端点 | 部署方自己的 key；任何 OpenAI 兼容端点；助手 · 服务方 · A2X 共用（A2X 的 `llm_apikey.json` 由平台生成到 `data/a2x_home/`） |
| `IOALAB_LLM_MODEL` · `IOALAB_A2X_MODEL` · `IOALAB_EMBED_MODEL` | `qwen3.7-flash` · `qwen-flash` · `text-embedding-v4` | 助手与服务方 · A2X 导航 · 嵌入 |
| `IOALAB_LLM_CONCURRENCY` · `IOALAB_ROUND1_ATTEMPTS` | 4 · 5 | 并发闸 · 第一轮网络抖动重试次数 |
| `IOALAB_REGISTRATION` | `open` | `open` · `invite` · `closed` |
| `IOALAB_LOGIN_CREDIT` · `IOALAB_NEEDS_PER_DAY` | 100 · 20 | 每日首次登录赠币 · 每账号每日需求上限 |
| `IOALAB_ISC_COUNT` | 10 | 内部服务使用者账号数 M；ISP 数 N = `ioalab/seed/domains/` 文件数 |
| `IOALAB_AUTOSEED` · `IOALAB_TRAFFIC` | 1 · `off` | 首次启动自动注入种子 · 背景流量档位 |
| `IOALAB_STUB` | — | `1`：不调模型，交付件用样件（测试用） |

`ioalab check-config` 核对必填项并打印生效配置。

## 二、安装

```bash
sudo apt install python3.11 python3.11-venv git nginx          # nginx 可选
sudo git clone --recursive https://github.com/Weizheng96/Jiuwen-IoA-Lab.git /opt/ioalab
sudo /opt/ioalab/deploy/install.sh        # venv · 依赖 · /etc/ioalab/ioalab.env（生成口令与密钥）· /var/lib/ioalab · systemd 单元 · wasm 预热
sudo vi /etc/ioalab/ioalab.env            # 填 IOALAB_LLM_API_KEY，核对 IOALAB_PUBLIC_URL
sudo systemctl enable --now ioalab && journalctl -u ioalab -f
```

首次启动自动注入内部账号（ISP_/ISC_）、48 个服务、分类树；也可先 `ioalab init` 离线预置。升级：`sudo /opt/ioalab/deploy/upgrade.sh`（停服 → 备份 → 拉代码 → 依赖 → 重启）。

| 路径 | 内容 |
|---|---|
| `/opt/ioalab` | 代码 + `.venv`（`install.sh` 默认；可用 `IOALAB_APP_DIR` 改） |
| `/etc/ioalab/ioalab.env` | 配置（root:ioalab 640） |
| `/var/lib/ioalab/data` | 运行期数据；`/var/lib/ioalab/a2c-cache` wasm 运行时；`/var/lib/ioalab/backups` 备份 |
| `/etc/systemd/system/ioalab.service` | `WorkingDirectory=/var/lib/ioalab`（openJiuwen 往当前目录写 logs/）· `ExecStartPre=ioalab check-config` · `ExecStart=ioalab serve` |

## 三、Nginx（可选）

`deploy/nginx.conf`：反代到 `127.0.0.1:8750`，`/ws/` 升级 WebSocket，`client_max_body_size 25m`，`proxy_read_timeout 300s`。
HTTPS 用 certbot；此时 `IOALAB_PUBLIC_URL` 要写 `https://域名`，且须在首次启动前决定。

## 四、运维

| 事 | 命令 |
|---|---|
| 备份 | `systemctl stop ioalab && ioalab backup --out /var/lib/ioalab/backups && systemctl start ioalab` |
| 清交易数据保留账号 | `systemctl stop ioalab && ioalab reset --keep-accounts && systemctl start ioalab` |
| 恢复出厂 | `systemctl stop ioalab && ioalab reset && systemctl start ioalab`（重新自动注入） |
| 日志 | `journalctl -u ioalab` · `data/logs/ioalab.log`（滚动 20 MB × 5） |

## 五、安全口径

内部账号口令极弱（`001…`），平台**只在内网 / VPN 暴露**；trial 模式有口令、限速、Origin 校验、每账号配额与材料上传限额；私钥 0600；
`/a2a/providers/*` 只放行回环。不要把 `ioalab.env` 或 `data/` 放进仓库。
