# 设计 · 唯一事实来源

定位：九问领导演示、IoA 技术实验、用户低门槛 playground。本文与本目录定义目标架构；实现进度只记在 [变更记录.md](变更记录.md)，不把未完成实现写成已通过验收。

版本唯一入口：[VERSION](VERSION)。Codex 可自动递增最后一位，倒数第二位及更高位仅由用户明确决定，不自动进位。改设计先更新本文档体系、版本与变更记录，再开发；产物 VERSION 如实记录实际符合的设计，不以重新打包冒充迁移完成。

依据的 A2C 设计版本：v0.0.19（协议规则在 [A2C 主仓](https://github.com/Weizheng96/AgentContractProtocol/tree/main/设计)，wheel 来源见 [SOURCE.json](../vendor/wheels/SOURCE.json)）。平台版本与协议版本独立。
