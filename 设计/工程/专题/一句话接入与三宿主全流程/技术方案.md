# 一句话接入与三宿主全流程 · 技术方案

目标：用户在Claude Code CLI、Codex桌面或Windows九问Swarm说根README中的一句话（部分克隆GitCode仓库后参考根目录README_AGENT.md接入，见D41），自动下载/配置/启动同一持久客户端及账号；自动优先、手动完整交付两角色Skill及所需入口/扩展，新聊天原生发现后完成发起委托、发布并履行服务、发布并处理私人接口、发起并继续私人交互。本期Windows本机连接远程平台，正式GitCode来源和develop候选分别验收。

## 分层与接口

公共Skill→P14目录/绑定调用器→公共运行时/两角色业务→P20/S01宿主适配→原生会话。仅公共接口向Skill开放；S/P编号是职责映射，不是额外对外API。公共/适配独立演进，原生queue/Mods/stdio/用户渠道等细节在适配内部，中性execution/文件/回调不承载原生协议参数。

S01—S05与来源、队列、文件、工具回调及生命周期完整规则唯一归[宿主提交](../../../组件/客户端/共用运行时/接口/宿主提交.md)；逐项现状和负责票见[47接口映射](接口覆盖映射.md)。不新增42个空函数、不保留公共run/deliver双链、不增加prepare/来源解析等第六方法。

## 一句话接入及会话

固定来源安装/安全升级→原账号配置及SDK必要页面→启动或复用原实例→导出完整双角色/原生资源→可选S03自动安装或准确手动动作→新聊天发现与真实会话注入→脱敏摘要。Skill安装前引导即可配置启动，不能形成循环。仅选择已提供适配器；命令/模型/目录由适配内部定位并复用。无宿主check/probe/prepare接入、保存或启动门禁；原安装完整性/账号/平台/锁校验保留。

主动业务绑定真实原会话，外部每笔委托/每次私人交互按当时默认新建独立可见会话，后续不随默认改变。原聊天busy默认排队，不steer/打断/换聊天。当前调用直接返回可得结果，迟到事件排队；SDK回调/引用绑定/确认走控制路径，不申请第二同SID模型名额。排队不延长TTL/授权/合同。
