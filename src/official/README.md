# 官方参与方资源

可选业务工具按项目[架构](../../设计/架构.md)与通用 SDK 分开安装。`pip install ./src/official` 安装 `ioalab-official`；包版本继承迁入工具的原实际依据，不读取设计 VERSION。

`ioalab_tools.handlers.AssistantHandlers` 为原管理员助手的显式日程/通知处理器，现有后台脚本和原回归使用它。它依赖参与方 SDK，SDK 和平台不反向导入官方工具。旧轮询收件器还未切换，不能据此声称官方助手已使用新长连接。

官方服务资源、日程与邮件工具及其新运行时装配仍按[开发计划](../../docs/开发计划.md)迁移；本目录不建立官方专用执行引擎。默认九问宿主不自动启用邮箱或日程权限。
