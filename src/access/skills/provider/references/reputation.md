# 结清与信誉

只在真实交付、验收与应付款凭证齐全后结束合同。常驻 SDK 复用原 A2C Provider.close 提交结清卡，平台核真实付款、登记信誉并释放接单容量；不是模型自报评分或累计次数。

使用 provider.status（profile）查看所属服务和实际状态，必要时在平台服务方工作台查看原合同记录。没有原结清/信誉回执就保留未完成或结果待核状态，不因模型结束、消息 TTL、服务重启而释放名额。

用户要求手动补交信誉时，先核 SDK 当前是否已完成原结清；若指定操作尚未配置，明确报告缺项，不编造一次提交，不通过私有数据库或 HTTP 绕过 SDK。重复恢复只认原合同和原结果，不新增信誉次数。
