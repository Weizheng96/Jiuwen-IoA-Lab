# 脚本定位

使用宿主原生加载本技能时提供的实际技能目录或安装回执中的脚本入口，只检查该目录下的 scripts/ioalab.py。两角色脚本已绑定同一个客户端和账号配置；不用填写客户端路径或凭据，也不从配置目录推断技能目录。

宿主没有提供实际目录或脚本入口时，保持发现/定位未就绪，按当前宿主安装回执完成原生接入后重试。回执应只给当前宿主所需步骤。不要扫描用户目录、历史库、依赖缓存或项目，不使用另一角色、旧示例或其他安装的脚本。

按[公共调用](calling.md)运行实际脚本。薄脚本转交安装时绑定的客户端解释器，不要求修改宿主环境。客户端绑定缺失时保留原目录和数据，按原安装回执修复。
