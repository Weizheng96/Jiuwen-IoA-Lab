# Claude native entry resources — partial S01 implementation

This bundle contains both role entry wrappers and the private native submission transport. It is required even when automatic Skill installation (S03) is unavailable. The public role Skill text belongs to the common client package.

P07/P08 must copy this whole bundle to its owned extension directory. The adapter's static `native_skills.resource_files(binding)` exports all assets and the hydrated `entry-binding.json`, without reading runtime grants or invoking a CLI. Its format is `ioalab.native-entry/1`, with `hostRef`, the common catalog's static `sourceOperations` list, `setupOperation` from the SDK declaration, and `profiles.assistant` / `profiles.provider`. Each ready role has four fields: `profile` containing the actual SDK profile key, `descriptorFile` from the SDK locator, and the installation-bound `ensureCommand` / `callerCommand` argument vectors. An unselected role stays explicitly unready; do not guess its profile. The binding file holds non-secret keys, paths and fixed arguments, never grant values. Do not put runtime descriptors, credentials or grants into Skills, exported packages or logs.

Load the installed copy using Claude's native plugin mechanism. A newly opened native session can use `claude --plugin-dir <installed-extension-directory>`. In an existing chat, enable the plugin through `/plugin`; if the current build requires reload/restart, preserve the original session ID and use its native resume after normal exit. Complete that directory's real trust/plugin confirmation; do not change permission mode to bypass it. Keep the original model, credentials, tools and workspace. Managed policies may refuse Mods; report that exact missing capability rather than editing managed settings.

The role entry calls obtain actual session ID/cwd from the Mods API; business arguments cannot override route metadata. Native submissions use `$.prompt.submit` with its original plugin attribution, and wait for idle. No development Channel or `asUser` is used.

The explicit `native_adapter` factory exports this bundle's handler/resource maps. Only operations in the common catalog's `sourceOperations` declaration run the fixed ensure command, then read the fresh descriptor and register the actual native SID/cwd. Controls and diagnostics go directly to the same fixed caller with null context, without starting the client, reading a grant or capturing a source. The common caller owns installation/account/role checks and ordinary IPC; the model cannot select a routing mode. No direct business HTTP fallback or host-specific operation list is retained. Waiting startup never sends business input, and the background poller never wakes the client. A missing caller receipt preserves the original operation ID as unknown. This source integration is not completed native onboarding acceptance.

Explicit setup is the separate exception declared by `setupOperation`, with empty arguments. It uses the same fixed caller to request the SDK intent. Only then does fixed packaged code capture the native process's actual project, CLI path and the set/unset `CLAUDE_CONFIG_DIR` pointer. The authenticated native resource calls the injected SDK permission delegate, saves the original claim and launch facts atomically under an OS lock, and acknowledges the saved receipt. Neither ordinary hello nor a model-supplied claim grants permission. Lost ACK recovery uses the original saved receipt; another chat cannot replace its project. New sessions naturally load the original persistent native settings without freezing a model name or copying credentials. Transient source-process environment credentials are not persisted, and their availability after that process disappears remains unverified.

The strict event observer can link only a machine-attributed prompt, its exact original input row with pinned UUID, the stored whole-text digest and one matching core turn. Only that turn's core completion can produce terminal evidence. Unknown framing, missing fields, interrupted transport or SDK boot changes retain uncertainty. Stop, prompt return, model acknowledgements and quiet time never prove completion. The private SDK tool bridge verifies actual stream tool IDs and arguments, waits for request binding, and drains callbacks before reporting terminal. These boundaries have fixture coverage; this build has not been loaded in a real native session.
