## 检查与交付

1. 先更新职责页、设计 VERSION 与变更索引，再实现；产物完成相应迁移后才更新其 VERSION。
2. 执行 `python 设计/check.py`、`python tools/check_docs.py`、`python -m pytest -q tests`、`python tools/selfcheck.py`。
3. SDK/技能发布补做干净安装、独立性和双入口验证；按[验收](../设计/工程/验收.md)补架构边界、故障竞争及端到端场景。
4. 视频按先剧本后录制的流程制作；旧视频不作为新架构验证。证据迁移前仍从本页现有入口查阅，迁移时保留原实测事实并同步链接。
5. 对应仓提交、推送，核对远端提交和设计标签；temp、运行数据、凭据、原始私人消息不提交。
6. 各旧入口在新链路完整验收并替换引用后整组归档到历史备份；内部开发不做旧格式兼容。旧官方服务、管理员收件和录制入口的替换尚未完成，继续按迁移表收敛为单一路径。
