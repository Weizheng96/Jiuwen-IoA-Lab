# 开发与验收入口

本页记录实现与[现行设计](../设计/README.md)之间的差距，不定义另一套产品规范。各产物实际依据见各自 VERSION；历史见[设计变更](../设计/变更/README.md)，实测证据见[验证记录](../demo/verification/README.md)和[部署依赖验证](../deploy/verification/dependencies.json)。

## 重构范围与实施顺序

现行设计已采用统一长连接、两种 Skill 共用运行时，以及九问辅助收信设置。业务代码仍使用原 HTTP/轮询及公网服务端点路径；下表均为待开发和验证项，不能据文档发布宣称已支持。

| 顺序 | 交付 | 替换范围与完成条件 |
|---|---|---|
| 1 | 公共标识与投递 | 稳定 agentId、连接票据、WS、持久 outbox/inbox、开始许可、UUID 建立/回传/补查/关闭；通过断线及竞争场景 |
| 2 | 本地接入组件 | 单独持有身份与数据；脚本经本地 API 调用；按交互与实际 Session 串行、跨交互并发；原生九问续接通过 |
| 3 | 助手通信与收信设置 | 自然语言起草、SDK 无副作用检查、摘要确认、幂等发布；Schema/权限/修订、首消息到多轮及结束闭环 |
| 4 | 委托接入与容量 | 服务不需公网 IP；平台权威 admission 与 AP2 事务协调；拟卡费前预留、承诺窗口、失败与未知结果恢复 |
| 5 | 双 Skill 与官方配置 | 通用流程和确定性脚本；官方服务/管理员助手复用同一运行时；删除被替换的执行路径，不保留两套长期运行链路 |
| 6 | 观察、部署和场景 | 统一状态映射、运行单元与设置；无 GitHub 安装；两类交互真实九问闭环和相应视频复验 |

原 HTTP 登录、查询、文件传输和观察快照继续承担各自职责。迁移已有合同前备份并核实承诺/付款状态，不删历史订单或私钥；尚不能安全接管的合同先按原流程结束，不能同时运行两个活动执行器。

## 产品接入契约与代码位置

设计将 IoA Lab SDK 分为个人助手端与服务方端，底层共用运行时；方法与包结构见[SDK共用机制](../设计/接入/SDK共用机制.md)。接口表描述目标契约，不代表当前代码已提供同名方法。

| 产物 | 实际位置与差距 |
|---|---|
| 个人助手技能 | `connector/ioalab-client/skills/ioalab-delegate/` 已有产品入口；需补统一长连接、接入配置、收信规则辅助定义和新流程契约 |
| 服务方技能 | `official-services/skills/ioalab-provider/` 是官方任务执行说明，尚不是完整的用户服务方接入产品；需按设计移入产品发布体系并复用任务说明 |
| 两角色 SDK | 现有 SDK 仍需按角色模块与共用运行时整理，替换轮询和公网端点路径；发布前核对每项设计调用及错误恢复 |
| 文档组织 | 分层规范及技能内容定义已整理；业务产物 VERSION 保持实际依据，不随文档更新 |

## 需要实证的适配能力

| 能力 | 开发前后需要取得的证据 |
|---|---|
| 原版九问会话 | 固定 Agent/技能/工具定义续接；后台会话与原生网页可见性分别验证 |
| 用户确认 | 原生答复如何关联真实对象与阶段；未支持时敏感动作保持待确认，不以模型 confirmed 自证 |
| 原生 ASK 等待 | 验证真实回调与进程生命周期；不能假定结束子进程等于可恢复暂停 |
| AP2 门禁 | 核实签名/有效期、预留与付款原子性、重复操作返回原凭证；不能仅依赖底层 JWT 解码 |
| 真实通知 | 本地预留、邀请提交及用户接受分别记录；保留原有真实验收入口，不因文档整理发邮件 |
| Linux 部署 | systemd、Nginx、WS 断线恢复与升级实机验证，不能用 Windows 回归替代 |

## 检查与交付

1. 先更新职责页、设计 VERSION 与变更索引，再实现；产物完成相应迁移后才更新其 VERSION。
2. 执行 `python 设计/check.py`、`python tools/check_docs.py`、`python -m pytest -q tests`、`python tools/selfcheck.py`。
3. SDK/Skill 发布补做干净安装、独立性和双入口验证；按[验收](../设计/工程/验收.md)补故障竞争及端到端场景。
4. 视频仅按先剧本后录制的流程制作；旧视频不作为新架构验证，实际成片状态见验证记录。
5. 对应仓提交、推送，核对远端提交和设计标签；运行数据、凭据、原始私人消息不提交。

原十个测试文件保留。仅设计与维护工具变更不得删除原测试、启动真实委托或发送邀请；回归继续用显式测试桩。
