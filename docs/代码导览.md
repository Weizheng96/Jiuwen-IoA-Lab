# 代码导览

本文件只说明当前代码的阅读路径和模块职责；长连接及统一运行时的设计尚待实现，差距见[开发计划](开发计划.md)。架构约束见[设计](../设计/README.md)，运行结果与未验收项见[验证记录](../demo/verification/README.md)，不在此重复状态表。

## 从入口追踪一笔活动

| 活动 | 阅读路径 |
|---|---|
| 部署准备 | `deploy/install.sh` → `tools/check_vendor.py` → 本地A2X/A2C依赖；`personal-assistant/install_swarm.py`安装独立九问，来源入口见[vendor](../vendor/README.md) |
| 核心启动 | `ioalab/__main__.py` → `ioalab/platform.py` → `ioalab/web/`、`market/`、`psp/`、`runtime/` |
| 用户发起委托 | 产品技能主入口 → `references/delegation.md`（通用流程）→ `sdk/ioalab_sdk/cli.py` → `scope.py`（本地限额）/`client.py` → 锁定A2C wheel；签字、取件和WASM验收在调用方 |
| 官方服务 | `official-services/serve.py` → `sdk/ioalab_sdk/provider.py` → `official-services/swarm.py` → 四个本单host工具 → `provider_capability.py`；输入来自合同，交付由SDK签名 |
| 留言与预约 | 技能`references/private-interaction.md` → `message_cli.py` / `messaging.py` → 核心`ioalab/messaging.py` → 独立`personal-assistant/assistant.py` → `assistant.py`处理器 → `swarm_web.py`或`agentmail.py` |
| 本地日程 | `schedule_cli.py` → `schedule.py`；显式文件、修订校验与备份；不代表已同步私人Outlook |
| 界面 | `ioalab/web/workbench.py`投影本人数据，`static/index.js`与`network.js`展示本人网络；管理员页另走审计与聚焦入口 |
| 全景展示 | `static/network-map.js`与`network-map.css`共用组件、布局及短连接；`panorama.js`投影真实事件，`demo/global_web/scene.js`仅执行有限讲解计划；`tools/check_panorama.py`离线检查历史恢复和收发边界 |
| 实验流量 | `experiments/`经同一本地SDK生成experiment活动，核心不创建背景个人助手 |

`sdk/`不依赖核心Python包，核心不导入用户Client、Provider或九问运行时。服务验收器只在A2C WASM沙箱执行。协议实现来自[wheel来源](../vendor/wheels/SOURCE.json)，不在本仓复制规则。

## 检查入口

```powershell
python 设计/check.py
python -m pytest -q tests
python tools/selfcheck.py
python demo/script_documents.py --check
```

自检不调用模型、不发送邮件。真实端到端录制须显式运行demo入口并使用本地配置，不能因文档整理启动真实委托或重发邀请。可选录制依赖在`demo/requirements.txt`，与平台运行依赖分开。

旧delegate编排只用于恢复已有受管理任务与外部声明计划；美甲计划和台词在examples/nail-booking，不随主skill分发。主skill不依赖九问全局指令或工具开关覆写。
