# 双屏试用

## 准备

1. 按[部署设计](../设计/部署.md)启动核心、独立官方服务和独立管理员助手；平台注册服务须在线，服务健康接口ready。
2. 核心首页下载ioalab-skill.zip，在自己的九问技能页导入并配置本地账号；首次自动准备SDK。个人助手不在平台核心运行。
3. 管理员浏览器登录ISC_001。dev仅本地演示使用预置口令；trial读取部署配置或data/assistant.secret中生成的强口令。SDK令牌不具有管理操作权限。
4. 用户侧浏览器工作台切换个人助手/服务方；管理者全景位于`/admin?view=panorama`，按账号聚焦，消息中心页显式审计正文。

## 两个主要用例

| 用例 | 展示与核对 |
|---|---|
| 委托 | 左侧真实九问网页提出需求，右侧个人助手工作台展示进展；九问调用本地SDK取件、WASM验收与签7，再切到对应ISP账号查看同一合同 |
| 留言与预约 | A先登记inputSchema与允许账号，B按账号读取可用接口并发送；A九问通知会话可见；预约规则自动判断，通知邮箱只发邀请，接受后才更新日历 |

录制入口和逐场景剧本见[录屏手册](../demo/README.md)，当前验收状态集中见[验证记录](../demo/verification/README.md)。本地SMTP/日历fixture明确标记，不能替代真实邮件验收。当前采用助手本地可编辑日程与AgentMail邀请；Outlook由收件人接受后入历；当前平台演示用条件式旁白和流程图说明，完整邮箱实录另验。

## 全局视角与异常

独立启动`experiments/traffic.py`与`experiments/messages.py`产生委托和消息；实验账号配置只留本地。点选助手或服务方时，同账号参与方高亮，其余变淡。平台核心不自动启动背景个人助手。

| 情况 | 预期 |
|---|---|
| 个人助手离线 | 云端排队，发送方可查状态；上线后SDK同步，ack不代表业务完成 |
| 撤销接口权限 | 当前白名单/停用状态在处理前复核；无显式新策略时重启不扩大权限 |
| 消息过期/超过保留期 | 不再执行；已下载但云端已清理的消息在本地标过期 |
| 重复投递/处理 | 幂等键与本地结果去重；副作用结果不明停止自动重发 |
| 服务进程重启 | 持久化任务恢复，已签4不重复交付；模型返回完成仍须SDK提交 |
| 验收失败 | 生成本地失败报告，不签7；是否复算/仲裁由用户决定 |
| 付款结果不明 | 核对凭证与账本，禁止盲目重复支付 |
