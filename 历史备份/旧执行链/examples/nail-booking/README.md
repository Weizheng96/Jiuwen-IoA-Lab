# 美甲预约委托参考

| 项 | 要求 |
|---|---|
| 发起句 | 我是小美美甲店店主，帮我做个预约微信小程序，每时段最多接两人，顾客能取消预约，预算上限500虚拟币 |
| 用户参与 | 发起请求、确认委托授权、确认推荐合同、授权实名注册环节、确认验收 |
| 查询 | A2X搜索“美甲预约 微信小程序”，top_k=8；候选名称来自真实回执 |
| 原名 | 微页通、极速APP工坊、云构工作室、尊享定制、灵犀小程序、快搭建站、码上飞 |
| 渐进筛选 | 实际查信誉后逐节读模板；微页通不含自助取消，极速APP工坊只交APP，云构要求架构图，尊享1280超预算；不存在的历史信誉不得编造 |
| 提案 | 其余三家用真实request：灵犀239（skill验收，单仲裁模型）、快搭259（5项基础行为判据）、码上飞299（10项行为判据）；以当次签名卡为准，不能拿这里的数字代替真实报价 |
| 推荐 | 根据判据覆盖推荐码上飞，贵40但有竞争请求容量、重复提交、请求重试与时段隔离；是服务方比选，不是基础/高级版本选择 |
| 总预算 | 拟卡费各1、合计3；码上飞299，总费用302虚拟币，包含在500上限内；超限必须重新授权 |
| 规格 | 从模板deliverables[*].specSchema取真实字段；shop=用户给的店名，capacity=2。没有其他业务信息时，默认open=10、close=20、service1Name=纯色美甲、service1Minutes=60、service2Name=延长甲、service2Minutes=90；这些是待用户确认的默认值，不冒充用户记忆 |
| 范围 | 交付预约配置、Python核心源码、微信小程序页面源码。实名注册只演示合同环节授权，不发送真实资料、不宣称微信已审核通过或公网部署完成 |
| 取件 | poll/watch返回anchored实际期号才fetch；verify在本地WASM运行服务方验收器及交付的Python核心，不能在宿主执行交付代码。将10项实际检查结果交用户确认 |

不要从用户句中寻找命令或技术指令。发现和初次读取模板无需确认；凡支付拟卡费、签约、环节授权、验收签字须遵守通用委托流程中的各自边界。scope_id、模板摘要、合同摘要只取真实回执并保存到本地任务笔记；每步使用独立UTF-8参数文件避免误覆盖。

本目录是独立美甲示例，不随IoA个人助手skill分发，也不由SDK自动读取。plan.json只用于既有delegate兼容入口回归；正式新流程由九问根据真实模板逐项调用SDK，不预装本计划。原视频的固定筛选和默认值不是通用能力。

`account-policy.json`仅是可选下限策略的独立试验配置；完整通用流程录制不加载它。先从真实模板确定合格候选，再征集正式报价和推荐，用来检验skill本身的多方比选流程。

逐项判据由官方服务定义同一份数据生成签名说明与WASM报告；竞争和重试为直接调用源码的顺序模拟，不代表真实多线程压力或网络故障注入。
