# 本地预约工具

官方美甲服务交付`booking.json`，内容由独立Swarm按本单需求生成；A2C验收器在WASM内核对配置判据。运行器为仓库固定代码，不执行服务方源代码。

```powershell
python examples/booking_app.py --config <SDK取件返回的booking.json> --database data/booking-demo.sqlite --port 8768
```

打开`http://127.0.0.1:8768`，可登记预约、查看记录及取消。SQLite事务限制同时接待数；相同请求标识重试返回原预约，内容不同则拒绝。仅回环访问，供本地体验，不用于公网部署；不包括微信注册、发布或审核。
